## ☸️ Cloud / DevOps / Infra

**Kubernetes v1.37 metrics สดใจ — histogram support graduate เป็น Beta** — Kubernetes 1.37 ขับเคลื่อนเป้าหมาย metrics observability ด้วยการให้ histogram support graduate เป็น Beta และเปิดใช้งานโดยค่าเริ่มต้น ช่วยให้ container orchestration จัดการข้อมูลเมตริกซ์ได้ดีเยี่ยมขึ้นระดับ scale ใหญ่ ([KubeConf + CloudNativeCon North America 2026](https://cncf.io/blog/2026/10/01/kubecon-cloudnativecon-north-america-2026-build-your-infrastructure-engineer-journey))

**WebAssembly บน server — lightweight sandbox runtime เป็น game changer** — WebAssembly โผล่มาเป็นเทรนด์ใหญ่สำหรับ server-side computing ด้วย lightweight sandbox runtime ที่เร็วเกือบ native performance และ polyglot language support ทำให้จัดการ resource efficiency ได้อีกขั้นสำหรับ use case เฉพาะ ⚠️ ([Beyond Kubernetes: Platform Engineering Trends for 2026](https://medium.com/@orlando1409/beyond-kubernetes-platform-engineering-trends-for-2026-8f82e09e27e0))

→ **ภาพรวม:** Observability ส่วนที่ฝัง + WASM alternatives เป็นขุมทรัพย์ infra ใหม่

## 🌐 Web / Frameworks / Languages

**TypeScript ครองภาษา #1 — React ecosystem เข้าสู่ type-safe era** — Next.js v16 และ meta-framework ตัวอื่นๆ (SvelteKit 2, Astro 3) ยึดตำแหน่งผู้นำด้วย full-stack capabilities ขณะเดียวกัน TypeScript ขึ้นมาเป็น contributor language #1 ซึ่งบ่งบอกว่า type-safety เข้ามาเป็นพื้นฐานของงานเขียน modern web ([React Libraries for 2026](https://www.robinwieruch.de/react-libraries/), [Web Frameworks 2026](https://dailyaistudio.substack.com/p/web-frameworks-2026))

**Astro "zero-JS by default" — performance-first web matured** — Astro framework ทำให้ "zero-JS by default" strategy ขึ้นมาเป็นสถานะ production-ready ด้วย support React, Vue, Svelte, Preact อย่างครบถ้วน พยุงให้ framework นี้ยึดระดับสูงในเรื่อง speed และการลด carbon emissions ของ web ([5 Frontend Frameworks That Will Dominate 2026](https://medium.com/@hashbyt/frontend-frameworks-2026-9b7dc5e3a955))

→ **ภาพรวม:** TypeScript → application layer, performance = ลำดับแรก, React/Next.js ครอบ enterprise
