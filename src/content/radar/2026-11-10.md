## 🌐 Web / Frameworks / Languages

- **TypeScript 7.0 with Go Compiler** — TypeScript 7.0 ออกเมื่อ 8 ก.ค. 2026 เปลี่ยนจาก TypeScript compiler เป็น Go-based compiler เร็วขึ้น 8–12x [official] ([BestHub](https://www.besthub.dev/articles/2026-frontend-toolchain-rewritten-in-go-and-rust-what-changed-7c3c338ba937))
- **React Compiler: Rust Edition Integration** — Meta ผนวก Rust port ของ React Compiler เข้าไปใน main repository หลังจากทดลองตั้งแต่ March 2026 Rust port ลดเวลา build และเพิ่ม optimization precision ([LogRocket](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **Vite 8 + Rolldown (Rust Bundler)** — Vite version 8 ใช้ Rolldown bundler ที่เขียนด้วย Rust ลดเวลา build ลงอย่างมาก ได้มาจากการพัฒนา Rust-based tooling ⚠️ ([BestHub](https://www.besthub.dev/articles/2026-frontend-toolchain-rewritten-in-go-and-rust-what-changed-7c3c338ba937))
- **Topcoat: Rust Server-Side Rendering Framework** — Topcoat ปล่อยให้ Rust render server-side web applications ทำให้ full-stack Rust web development เป็นจริง (เปิดตัว 30 ต.ค. 2026) ([DevClass](https://www.devclass.com/development/2026/10/30/topcoat-enables-rust-to-render-server-side-web-apps/5306490))
- **Oxfmt: Rust Formatter 30x Faster than Prettier** — VoidZero เปิดตัว Oxfmt formatter ที่เขียนด้วย Rust เร็วกว่า Prettier มากกว่า 30 เท่า part of the larger shift to Rust tooling ([InfoQ React](https://www.infoq.com/React/news))

→ **ภาพรวม:** Rust โครงสร้างเครื่องมือ JS/TS ecosystem · TS 7.0 Go compiler ตัวใหม่แสดงนัยว่า compiled-language tooling ชนะ
