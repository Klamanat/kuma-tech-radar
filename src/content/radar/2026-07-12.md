## ☸️ Cloud / DevOps / Infra

- **etcd v3.7.0 ออก (8 กรกฎาคม)** — SIG etcd ปล่อย v3.7.0 ซึ่งเป็น minor release ล่าสุดของส่วนประกอบ Kubernetes ที่ใช้ข้อมูล ([Kubernetes Blog](https://kubernetes.io/blog/)) [official]
- **Meta ทำ cloud infra เพื่อขาย AI compute** — Meta ตั้งธุรกิจคลาว์ใหม่เพื่อขายสิทธิ์ใช้ compute surplus ของบริษัท โปรยมแปลงมงฟูดจิให้กลายเป็นฝ่ายแข่งขัน AWS/Azure/GCP ([Cloud-Native's Interest Payment Just Came Due](https://cloudnativenow.com/contributed-content/cloud-natives-interest-payment-just-came-due/)) ⚠️
- **K8s adoption ทะลุ 68% แต่เสี่ยง serverless** — Kubernetes ขึ้นอยู่ที่ 68% ของ production workloads ลงจากสูงสุด 2024 เพราะทีมแยกไปใช้ serverless (Cloud Run/ACI/Fargate) แต่ edge computing เพิ่ม 34% ([2026 Kubernetes Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth)) ⚠️
- **CloudNativePG 1.30.0 + Platform Engineering formae** — CloudNativePG ปล่อย v1.30 ด้วย declarative database role; Platform Engineering Labs ปรับ formae ให้ support K8s + Helm + .tfvars ([Kubernative software digest: July 10th, 2026](https://faun.dev/co/stories/shurup/kubernative-software-digest-july-10th-2026/)) [official]
- **Google GKE Labs เปิด OpenRL** — Google แนะนำ OpenRL project ให้ host เอง API สำหรับ post-training/fine-tuning LLMs บน Kubernetes clusters สตอบ ([2026 Kubernetes Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth)) [official]

→ **ภาพรวม:** Kubernetes ที่เปิดขึ้นมาเป้า AI scale workloads; meta เจาะตลาดคลาว์ใหม่ด้วย GPU/AI compute
