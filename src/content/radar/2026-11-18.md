## ☸️ Cloud / DevOps / Infra

- **Kubernetes 1.38 Code Freeze วันนี้** — 17–19 พฤศจิกายน (UTC) ตามตาราการปล่อยของ k8s.dev [official], Feature Freeze ต่อเนื่อง, ปล่อย final v1.38.0 วันที่ 16 ธันวาคม 2026 ([k8s.dev — v1.38 schedule](https://www.k8s.dev/resources/release/))
- **Kubernetes v1.37 "Garhwal" ปัจจุบัน** — ปล่อยแล้ว 26 สิงหาคม เพิ่ม GPU scheduling native (Workload Aware + DRA), fine-grained Kubelet auth [official] ([kubernetes.io/releases](https://kubernetes.io/releases/))
- **Pre-release ของ 1.38** — alpha.1 และ alpha.2 ผ่านไปแล้ว, rc.0 มาตรวจสอบ 3 ธันวาคม ⚠️ ([groups.google.com — Kubernetes dev](https://groups.google.com/a/kubernetes.io/g/dev/c/NWBYedCSm64)) milestone นี้ติดตามผ่าน Last Week In Kubernetes Development

→ **เกี่ยวกับงาน:** ให้ priority ทดสอบ alpha ของ 1.38 GPU features ตอนนี้

## 🌐 Web / Frameworks / Languages

- **React 19.3.1 ล่าสุด** — 14 ตุลาคม 2026 [official], ไม่มี breaking changes ตั้งแต่ 19.2.x ⚠️ ([buildwithmatija.com](https://www.buildwithmatija.com/blog/md/react-ecosystem-2026-frameworks-platforms-typescript-stack)) react foundation transition เสร็จแล้ว 24 กุมภาพันธ์ 2026
- **Next.js 16 / Meta-frameworks** — Next.js ยังเป็น top choice ของ 2026, Svelte 5 + SvelteKit 3.0 ปล่อยแล้ว 1 ตุลาคม [official], Nuxt 3 end-of-life 31 กรกฎาคม — Nuxt 4 ใช้งาน ⚠️ ([tech-insider.org](https://tech-insider.org/?p=49793))
- **TypeScript 7.0 กำหนด** — ปกติมา mid-2026 แต่ยังไม่เห็นใน release schedule สำคัญ, ตรวจสอบ typescript.org สำหรับ update ([buildwithmatija.com](https://www.buildwithmatija.com/blog/md/react-ecosystem-2026-frameworks-platforms-typescript-stack))
- **Rust tooling (rolldown, swc)** — ไม่มี breaking update ใหม่เดือนนี้ แต่ยังคงเป็น standard choice สำหรับ bundling performance

→ **ภาพรวม:** React 19.x ยังคง stable, Svelte 5 เสนอ alternative ที่ reactive, TypeScript ยังระหว่างขยาย
