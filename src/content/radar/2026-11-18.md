## 🌐 Web / Frameworks / Languages

- **React Compiler ไปยัง Rust** — March 2026 Joseph Savona เปิด PR #36173 ส่งออก TypeScript → Rust port ของ compiler logic ด้วย AI ตัวช่วย, สัญญา "coming soon" สำหรับ production release ⚠️ ([LogRocket — Frontend H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
