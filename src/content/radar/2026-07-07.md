## ☸️ Cloud / DevOps / Infra

- **Kubernetes = OS สำหรับ AI ตอนนี้** — AI มีบทบาทสำหรับเนื้องาน production, 82% ของทีม IT รัน K8s production แล้ว, GPU ก็เป็น default hardware paradigm ([pulumi.com/blog](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))
- **Platform Engineering แทน DevOps** — คาด 80% องค์กรใช้ PE แล้ว (ขึ้นจาก 45%), GitOps เป็นค่าเริ่มต้น, cluster ops เข้าสู่ AI-assisted mode ([fairwinds.com](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- **FinOps + GreenOps เข้ามาใจกลาง** — ธรรมาภิบาล cost + carbon footprint, carbon-aware autoscalers ชีฟ workload ไปสู่พื้นที่พลังงานหมุนเวียน ([loginline.com](https://www.loginline.com/en/blog/2026-kubernetes-trends))
- **Nebius AI Cloud Aether 3.6** — ตัวอย่างของโครงสร้าง AI cloud ใหม่ที่เน้น production efficiency ([nebius.com](https://nebius.com/blog/posts/ai-cloud-aether-3-6))

→ **เชื่อมกับชีวิต:** Kubernetes ก็ไม่ใช่ container orchestrator อีกต่อไป, มันเป็นฐานโครงสร้างทั่วทั้งโลกสำหรับ AI
