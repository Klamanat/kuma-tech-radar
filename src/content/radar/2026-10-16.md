## 🌐 Web / Frameworks / Languages

- **React Compiler Rust Port (เสร็จ June 2026)** — ทีม React ย้ายโค้ดจาก TypeScript ไป Rust ส่วนใหญ่แล้ว · สตถานะยังเป็น experimental แต่โปรแกรมค่อยมีรูป ([LogRocket H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/)) [official]
- **TypeScript 7.0 Compiler → Go** — ไมโครซอฟท์เปิดเผยพอร์ต compiler ไปยัง Go ไม่ใช่ Rust · เป้า mid-2026 บรรลุแล้ว · ยังคง TypeScript ภาษาแอปพลิเคชั่นที่ใช้บ่อย ([LogRocket](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/)) [official]
- **Rust-based JS tooling ขยายตัว:** SWC, Biome, Rspack, Turbopack, Oxc ครอบคลุมทุกขั้นตอน parsing, transpilation, bundling, linting, formatting ([PkgPulse guide](https://www.pkgpulse.com/guides/rise-of-rust-in-javascript-tooling-2026)) ⚠️
- **Vite 8 + Rolldown 1.0** — Rust-powered build-tool shift ยังต่อ · React Server Components นำทีมสถาปัตยกรรม frontend · Next.js ยังครอบชาติ meta-framework ([LogRocket](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))

→ **ท้องเสียง:** Rust ยึดเครื่องมือที่ต้องการความเร็ว · ภาษา application ยังคงเป็น TypeScript/JavaScript และ Go
