## 🤖 AI / LLM / Agents

**OpenAI ปล่อย GPT-5.6 (Luna, Terra, Sol) 9 กรกฎาคม [official]** — โมเดลเฟลกซิเบิลใหม่สามตัว ช่วยงาน reasoning, knowledge, speed เพิ่มเติม เป็นส่วนของแนวโยบายออกตัวใหม่ทุก 2-3 วัน ([llm-stats.com/llm-updates](https://llm-stats.com/llm-updates))

**Anthropic Claude Sonnet 5 ได้ใจ coding [official]** — ประสิทธิ์เทียบ Opus-class แต่ราคาแค่ 1/3 ทำให้เข้าใจ code/ด้านโปรแกรมมิ่งได้ลึก เคลื่อนตัวดีสำหรับ agents ([aiflashreport.com/model-releases.html](https://aiflashreport.com/model-releases.html))

**Google ปล่อย Gemini 3.2 Pro (2M context) [official]** — บันทึกข้อมูลยาว 2 ล้านโทเคน ดีสำหรับ document analysis แบบหนัก Moonshot Kimi K3 และ Alibaba Qwen-Audio-3.0 ก็ออกหรือไปในช่วงนี้ ([pricepertoken.com/news/model-releases](https://pricepertoken.com/news/model-releases))

**โมเดลใหม่เชื่อแต่ละ 2 วัน ⚠️** — ข้อมูลรวม 11 โมเดล release ในนาทีสุดท้ายนี้ได้ขึ้น leaderboard Claude Fable 5 นำ (100/100 composite quality) ตามด้วย Qwen 3, DeepSeek R1/V3 ([techsy.io/best-open-source-llms-2026](https://techsy.io/en/blog/best-open-source-llms-2026))

→ **เกี่ยวกับเรา:** เมื่อ claude-fable-5 ยังเป็น leader ต่อการอัปเดต agent/skill logic ของ Claude Code

## ☸️ Cloud / DevOps / Infra

**Kubernetes 1.36 release เสร็จ — 70 enhancements [official]** — ความสนใจใหญ่: User Namespaces, Mutating Admission Policies, Fine-Grained Kubelet API Authorization (ทั้งหมดขึ้นเป็น GA), เน้นความปลอดภัยและ AI workloads ([kubernetes.io/releases](https://kubernetes.io/releases/))

**Microsoft สร้างส่วนเสริม AKS สำหรับ AI [official]** — ปลายกรกฎาคมนี้ Microsoft ร่างขยายตัว Azure Kubernetes Service (AKS) ให้เป็น first-class platform สำหรับ AI training, inference, และ cloud-native applications ประสิทธิ์ที่ compute-heavy workloads ([kloudping.com/cloud-computing-trends-july-2026](https://kloudping.com/cloud-computing-trends-july-2026))

**Google GKE เปิดตัว OpenRL (LLM fine-tuning API) [official]** — โปรเจกต์โอเพนซอร์ส post-training/fine-tuning LLM บน Kubernetes clusters มาตรฐาน ทำให้สถาบันขนาดกลางคิดเครื่อง AI ได้ ([shyam.kubeify.com/latest-devops-cloud-news-16-july-2026](https://shyam.kubeify.com/2026/07/latest-devops-cloud-news-16-july-2026.html))

**Agent Gateway ไม่ใช่ AI สี่เหลี่ยม เป็นควบคุม enterprise [official]** — Palo Alto ซื้อ Portkey, Solo.io บริจาค agentgateway แก่ Linux Foundation ทำให้ agent workflows ใน production ควบคุมได้ดีกว่า ([tech.hub.ms/devops/roundups/weekly-devops-roundup-2026-07-27](https://tech.hub.ms/devops/roundups/weekly-devops-roundup-2026-07-27))

→ **ภาพรวม:** Kubernetes นำ AI workload / MLOps ขึ้นเป็นฟีเจอร์มาตรฐาน แต่พฤติกรรม adoption ปั่น 68% (เงิบลงจาก peak 2024) เมื่อทีมแยก workload ไปเซิร์ฟเวอร์เลส

## 🌐 Web / Frameworks / Languages

**React Compiler (v1.0 เสร็จแล้ว, Rust edition มาเร็ว) [official]** — React ได้ v1.0 แล้ว (ยืนยันใน 2025) ทีม optimize component/hook อัตโนมัติ; ขณะนี้ port ส่วนใหญ่จาก TypeScript → Rust ด้วย AI, ยังอยู่ phase "coming soon" ⚠️ ([react.dev/blog/2025/10/07/react-compiler-1](https://react.dev/blog/2025/10/07/react-compiler-1))

**TypeScript 7 + WebStorm 2026.2 [official]** — TypeScript 7 เข้ามา (ลักษณะเป้า mid-2026) compiler ใจเขียนด้วย Go, strict-by-default, ตัด ES5 target + AMD/UMD/SystemJS; WebStorm 2026.2 ส่งรองรับ TS7 และ React 19 ใน Buddy ด้วย ([blog.jetbrains.com/webstorm/2026/07/webstorm-2026-2/](https://blog.jetbrains.com/webstorm/2026/07/webstorm-2026-2/))

**React ใช้ Server Components พร้อม framework (Next.js 16.3) [official]** — render UI บนเซิร์ฟเวอร์ ลดขนาด JS โปรแกรม; Next.js 16.3 มี Turbopack improvements (memory eviction, persistent build cache), Rust React Compiler support, import.meta.glob ([nextjs.org/blog](https://nextjs.org/blog))

**rolldown (Rust bundler) เข้าระบบ Vite mainstream [official]** — นำเสนอจาก Nuxt/SvelteKit/Astro ให้ rolldown เป็น default แทน esbuild/Rollup; build time ผลมาตรการลดเป็น 40 วิ (เดิม 2.5 นาที) ⚠️ ([blog.mean.ceo/hacker-news-trends-july-2026](https://blog.mean.ceo/hacker-news-trends-july-2026/))

→ **ภาพรวม:** Rust ยึดตำแหน่ง tooling performance-critical; React/TS คง core application languages; AI ช่วย refactor/compile (Rust port)
