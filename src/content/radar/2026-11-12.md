## 🌐 Web / Frameworks / Languages

- **Rust + TypeScript hybrid stack ครองใจ ecosystem 2026 ⚠️** — JetBrains และ dev community เห็นว่า Rust (compiled to WASM) สำหรับ performance-critical logic + TypeScript สำหรับ web layer เป็นรูปแบบมาตรฐานมากขึ้น framework เช่น Ultimo (Rust → TS bindings) และ ts-rs (TS ← Rust types) เติบโตขึ้น ([blog.jetbrains.com Rust vs TS](https://blog.jetbrains.com/rust/2026/01/27/rust-vs-javascript-typescript/))
- **Backend framework ecosystem: Actix Web, Axum, Rocket ครองใจ [official]** — ทั้งสาม framework ยัง leading choice สำหรับ Rust web backends; Leptos + Yew อำนาจ full-stack Rust alternatives สำหรับองค์กรที่ต้องการ type safety ครบวงจร ([topdevguide.pages.dev — Rust frameworks](https://topdevguide.pages.dev/article/rise-of-rust-web-development))
- **TypeScript compiler การเขียนใหม่ → Go [official]** — ทีม TypeScript ศึกษา Go rewrite เพื่อ strict-by-default semantics + ตัด ES5 support ช่วยให้ compiler เร็วขึ้นและ maintain ง่ายขึ้น ([blog.logrocket.com state of TS 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))

→ **ภาพรวม:** Rust ยึดชั้น performance tooling + type-safe Rust↔TS bindings ยังเพิ่มขึ้น · TypeScript architecture ฟื้นตัวด้วย compiler modernization
