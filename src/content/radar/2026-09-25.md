## ☸️ Cloud / DevOps / Infra

- **Kubernetes 1.37.0 เปิดตัว 26 สิงหาคม** — เวอร์ชันล่าสุดที่เสถียรรอบนี้ลงมาพร้อมการปรับปรุง scheduler และมาตรการรักษาความปลอดภัย [official] ([Kubernetes.dev Releases](https://www.kubernetes.dev/resources/release/))
- **swampUP DevOps Conference 1–3 กันยายน** ที่นิวยอร์ก รวมตัว developers, DevOps teams, security engineers, SREs พูดคุยเรื่องแนวทางบริหาร infra ในยุคบหุ่นและ multi-cloud ([CNCF News](https://www.cncf.io/news/))
- **ผู้ให้บริการ Kubernetes แบบจัดการในยุโรป 8 ราย** — OVHcloud MKS, Scaleway Kapsule/Kosmos, Exoscale SKS, Infomaniak, StackIt SKE, Open Telekom Cloud CCE, UpCloud, IONOS กำลังแข่งดุเดือดเพื่อตำแหน่งสระชน ⚠️ ([Qovery Blog EU Cloud Providers](https://www.qovery.com/blog/eu-cloud-providers-managed-kubernetes-2026-sovereignty-checklist))
- **แนวโน้ม 2026:** AI-assisted DevOps, multi-cloud strategies, FinOps, observability, internal developer platforms (IDPs) เป็นจุดแข็งยั่งยืน ([Splunk DevOps Conferences 2026](https://www.splunk.com/en_us/blog/learn/devops-conferences-events.html))

→ **ภาพรวม:** K8s เข้าช่วงเพิ่มมติกรรมใหม่หลังปี 2026 ครึ่ง, governance ผ่าน policy automation (Kyverno) คืออนาคต

## 🌐 Web / Frameworks / Languages

- **Rolldown บันดลเป็นเครื่องมือบิลด์ Rust ของ Vite ecosystem** — ภาค Rust ยกระดับประสิทธิภาพ 10–30x เร็วกว่า Rollup เดิม [official], ใช้ใน Vite 8 (มีนาคม 2026) และเป็นทางไปหน้าสำหรับ Next.js, Nuxt, SvelteKit, Astro ([Rolldown May 2026 Release](https://strapi.io/blog/best-javascript-frameworks))
- **TypeScript ยังนั่งปลอดภัยที่ 48.8% ของ developers มืออาชีพ** ตามสำรวจ Stack Overflow 2025 · 58% ของผู้ใช้ยังชื่นชมภาษาแม้เมื่อเทียบกับ JavaScript ([Rust vs JavaScript & TypeScript](https://blog.jetbrains.com/rust/2026/01/27/rust-vs-javascript-typescript/))
- **Next.js ยังเป็นกระดานสำเร็จอาจารย์ที่สุด** ของ React Server Components, Server Actions, และโดเมนเซิร์ฟเวอร์-เฟิร์สต์ · ใช้โดยบริษัทเช่น Netflix, TikTok, Notion ([Next.js Wikipedia](https://en.wikipedia.org/wiki/Next.js))
- **Rust web frameworks Leptos, Actix Web, Axum** เดือดร้อนเลือดของ full-stack development ใน Rust ส่วนผู้สนใจใหม่โปรแกรมอย่างพยายาม Leptos เป็นเลือก 2026 ([Leptos Full-Stack Rust 2026](https://rustify.rs/articles/rust-leptos-fullstack-web-2026))

→ **สรุป:** Rust ถูกแต่งตั้งเป็นตัวเลือกหลักสำหรับเครื่องมือบิลด์และ tooling ที่ต้องการประสิทธิภาพสูง, TypeScript/JavaScript ยังคงเป็นคำภาษาของแอปพลิเคชัน
