## 🤖 AI / LLM / Agents

**Claude Fable 5 ของ Anthropic — frontier model ใหม่ยกระดับ 2x** — Anthropic เปิดตัว Claude Fable 5 เป็น Mythos-class frontier model ที่ "smartest publicly available LLM" ขณะนี้ โดยแสดงความก้าวหน้าที่มีนัยสำคัญในเกณฑ์มาตรฐาน แม้ว่าแพงกว่าโมเดล Opus ประมาณ 2 เท่า ([llm-stats — AI updates](https://llm-stats.com/llm-updates))

**OpenAI GPT-5.6 family — ขยายให้ครบสามขนาด Luna/Terra/Sol** — OpenAI เปิดตัว flagship model ใหม่ 3 ขนาด ราคา $1–$5 ต่อ million tokens โดยรับบัน 1 million token context window และมี knowledge cutoff กุมภาพันธ์ 2026 อ้างว่าเอาชนะ Fable 5 ในงาน agentic benchmarks ยาว ๆ และขาด API ใหม่เช่น programmatic tool calling และ multi-agent orchestration ([aiflashreport — model releases](https://aiflashreport.com/topics/new-ai-model-releases.html))

**Inkling ของ Thinking Machines — open-weight frontier model ตั้งท้าย** — Mira Murati ของ former VP ที่ OpenAI เปิดสถาบัน Thinking Machines และปล่อย Inkling เป็น open-weight model สำหรับ reasoning และ coding เพื่อแข่ง closed models กระดับเดียวกัน ที่สามารถ download weights ได้ (~15 กรกฎาคม 2026) ([dentro.de/ai — new releases](https://dentro.de/ai/news/))

→ **เกี่ยวกับเรา:** รุกแรงสุดของ frontier models ไป open-weight เปิดหน้าต่างใหม่สำหรับ agents และ chain-of-thought ในอ่านเรียน

## ☸️ Cloud / DevOps / Infra

**Platform Engineering แทนที่ DevOps — 80% orgs จะยอมรับ** — ปี 2026 นี้ Platform Engineering (ระบบลดความยุ่งของ developer) เพิ่มจากแค่ 45% ไปยัง 80% ของบริษัทท่วง ข้อคิดหลักคือลด cognitive load ให้ devs มุ่งเขียนโค้ดแล้วปล่อยให้ platform team ดูแล infra ([fairwinds — 2026 K8s playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

**Kubernetes เป็น OS สำหรับ AI — MLOps เหนือสื่อ** — Kubernetes ขึ้นเป็นระบบปฏิบัติการตั้งแต่สำหรับ AI workloads หนักท่ีสุด โดยเน้น ML operations platforms ที่ต้องประสานจำนวน bursts-heavy Jobs กับ continuously-running Services วัตถุรูป self-driving/self-healing clusters ที่ AI ดูแลงานประจำ มนุษย์เข้ามาเฉพาะ exception ([fairwinds — K8s playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

**Serverless Kubernetes ทำรีบาลแนว** — ปี 2026 Serverless Kubernetes เป็นตัวเลือก default ของ devs ที่ deploy code โดยไม่ต้อง configure Worker Nodes จำหน่อย ยังคงเป็น trend ที่ขยายตัว ([loginline — 10 K8s trends](https://www.loginline.com/en/blog/2026-kubernetes-trends))

→ **เกี่ยวกับ Platform Engineering ของเรา:** ลดความซับซ้อน + ปรับ ML workloads ไป K8s/Serverless เป็นแนวไปข้างหน้า

## 🌐 Web / Frameworks / Languages

**React ผ่าน server-first — framework ไม่ใช่ UI library** — ปี 2026 React เปลี่ยนคิดฉากใหญ่ จากเป็น "UI library" ไปเป็น "application framework" โดยมุ่ง server-first rendering และแนะ devs ให้ render มากที่สุดที่เซิร์ฟเวอร์ ส่วน React Compiler v1.0 (ตั้งแต่ตุลาคม 2025) อัตโนมัติดู memoization และสร้าง 12% faster initial loads + 2.5x faster interactions ใน Meta production ([nucamp — JS Framework Trends 2026](https://www.nucamp.co/blog/javascript-framework-trends-in-2026-what-s-new-in-react-next.js-vue-angular-and-svelte))

**TypeScript 78% adoption ใน React projects — core of modern dev** — TypeScript adoption ใน React projects โดย professional developers ถึง 78% (State of JS 2025) และ August 2025 ทำให้ TypeScript โผล่เป็น most-used language บน GitHub by contributor count — สัญญาณว่า typed ecosystems ใกล้จากศูนย์กลาง production software แล้ว ([medium — TypeScript best practices](https://medium.com/@mernstackdevbykevin/typescript-with-react-best-practices-2026-78ce4546210b))

**JavaScript frameworks รวมเอา 4 theme — fine-grained reactivity + server-first + compiler optimization + AI-assisted** — ตั้ง frameworks ชั้นนำ (React, Vue, Svelte, Angular, SolidJS) มาหาไปจนเบ็ด fine-grained reactivity (บ้าง), server-first rendering (บ้าง), compiler-driven optimization (ล้วนหมด), และ AI-assisted workflows (เกือบทั้งหมด) ([strapi — best frameworks 2026](https://strapi.io/blog/best-javascript-frameworks))

→ **ภาพรวม:** React server-first + TypeScript ทำหลัก · JavaScript frameworks บรรจบเข้าเบิกรูปแบบใหม่ · AI assist เข้าวัฒนาฟรอนต์เอนด์อย่างจริง
