## 🤖 AI / LLM / Agents

- **Google Gemini 4 Carbon ออกเมื่อ 10 พ.ย.** — ตลาด AI ยังเร่งปล่อยโมเดลใหม่ตามลำดับสัปดาห์ กำหนดราคา API เปิด $2/$10 จนสิ้นเดือนพ.ย. แล้วเพิ่มเป็น $4/$20 ([blog.mean.ceo — November AI releases](https://blog.mean.ceo/new-ai-model-releases-news-november-2026/))
- **Anthropic Claude Fable 5.2 และ Mistral Large 4** — ออกในช่วงแรกของพฤศจิก ข้อมูลจาก aggregator ต่างเห็นต่างกันในเรื่องวันที่และรายละเอียด ⚠️ Mistral Large 4 เปิด weights ([Various LLM trackers](https://thursdai.news/releases/2026-11))
- **22 โมเดล AI ในสัปดาห์แรกของพฤศจิก** — ห้องแล็บ 13 แห่งปล่อยโมเดลใหม่ รวมถึง Tencent Hy4, Moonshot Kimi K3.1 Pro, และ OpenAI GPT-6 Cyber (ข้อมูลบางส่วนขัดแย้ง) ⚠️ ([aitoolsrecap.com](https://aitoolsrecap.com/Blog/upcoming-ai-models-2026-release-tracker))

→ **เกี่ยวกับเรา:** หลากหลายรุ่นของโมเดลหมายความว่าความเชี่ยวชาญเฉพาะด้านเพิ่มมูลค่า ตัวเลือก สตริง coding/agent ได้เปิดตัวใน 90 วันที่ผ่านมา

## ☸️ Cloud / DevOps / Infra

- **KubeCon North America 9–12 พ.ย. ที่ Salt Lake City** — งานใหญ่ของชุมชน cloud native โฟกัส AI agents ได้รับลำดับความสำคัญ ปัญหากู้คืนและความเชื่อถือของ AI agents บน Kubernetes ถูกยกขึ้นมา ([CNCF/CloudNativeNow — KubeCon coverage](https://cloudnativenow.com/))
- **Buoyant เปิดตัว control plane สำหรับ AI workloads** — ตอบสนองต่อความต้องการในการปรับแต่ง Kubernetes สำหรับการเรียกใช้ agentic AI ที่เชื่อถือได้ เสริมด้วย initiatives ของ CIQ (Kubernetes distro สำหรับ AI) และ Hyperlight sandboxing ([CloudNativeNow — November 2026](https://cloudnativenow.com/))
- **Broadcom ส่งมอบ API สำหรับ Virtual Machines ให้กับ CNCF** — ป้องกันการรันเวิร์กโหลดเชื่อถือได้ ส่วน Cosmonic ผลักดัน Wasm บน Kubernetes เพื่อเพิ่ม sandbox density ([CNCF — November announcements](https://www.cncf.io/))

→ **ภาพรวม:** AI agents มาถึงคิวรองต่อให้ความทั่วไปของเทพนโยบาย sandbox ของ Kubernetes ผลิตภัณฑ์ใหม่โผล่ที่ไม่มีตัวอักษร

## 🌐 Web / Frameworks / Languages

- **TypeScript 7.0 ส่งมอบ Go compiler** — สร้างใหม่ด้วย Go เพื่อเพิ่มความเร็วการสร้าง ตัดเป้าของ strict-by-default รหัส กำหนดเป้าหมาย ES5 และ AMD/UMD/SystemJS ที่จะลบออก ([TechInsider — TypeScript 7](https://tech-insider.org/?p=49793) [InfoQ](https://www.infoq.com/Web-Development/news/45/))
- **React 19.3.1 ออกเมื่อ 14 ตุลาคม** — React Foundation (ขยับจาก Meta ในเดือนกุมภาพันธ์ 2026) ยังคง React 19 ปล่อยการอัปเดตเซกชันโปรแกรม ส่วน Meta's React Compiler 1.0 ทำงานใน production ([TechInsider — React ecosystem](https://tech-insider.org/?p=49793))
- **Next.js 16, SvelteKit 3, Remix 3 — landscape แตกตัว** — Next.js ยังเป็นตัวเลือกหลักของ React teams SvelteKit 3 ออกเมื่อ 1 ตุลาคม Remix 3 ย้ายออกจาก React ไปสู่ web standards primitives ([BuildWithMatija — React ecosystem 2026](https://www.buildwithmatija.com/blog/md/react-ecosystem-2026-frameworks-platforms-typescript-stack/))

→ **แนวโน้ม:** Rust ผ่านผ่านโลกแห่ง tooling (TypeScript compiler, Next.js bundlers) TypeScript ยังคงเป็นภาษาแอปพลิเคชันที่เด่น
