## ☸️ Cloud / DevOps / Infra

- **Kubernetes 1.36 เสถียรพร้อม GPU scheduling native** — เวอร์ชัน 1.36 ออกเมื่อ 22 เมษายน 2026 [official] พร้อมฟีเจอร์ความปลอดภัยใหม่ includeiding Workload Aware Scheduling และ DRA (Dynamic Resource Allocation) ([Sysdig - Kubernetes 1.36](https://sysdig.com))
- **Ingress NGINX เกษียณอายุ ย้ายไปยัง Gateway API** — ทีม NGINX ประกาศ deprecation ของ Ingress NGINX เพื่อสนับสนุนการเปลี่ยนไปยัง Gateway API ซึ่งเป็นมาตรฐานใหม่ของ Kubernetes [official] ([Kubernetes Gateway API](https://kubernetes.io/docs/concepts/services-networking/gateway/))
- **Volcano v1.14 สำหรับ unified scheduling** — Volcano ปล่อยรุ่น 1.14 ที่รวม scheduling สำหรับ training, inference, RL, และ agent workloads โดยเพิ่ม dynamic node sharding (Alpha) ⚠️ ([Volcano Project](https://www.volcanoframework.org))

→ **ภาพรวม:** Kubernetes evolution มุ่งไปยัง unified orchestration สำหรับ ML pipelines และ production agents

- **React Native พร้อม TypeScript first-class** — ในปี 2026 React Native ได้รับการปรับปรุง first-class TypeScript integration พร้อมนิยามประเภทที่ดีขึ้นสำหรับการพัฒนาที่ปลอดภัยมากขึ้น ⚠️ ([React Native 2026 Overview](https://www.euroshub.com/blogs/react-native-2026-whats-new-and-what-to-expect))
