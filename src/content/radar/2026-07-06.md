## ☸️ Cloud / DevOps / Infra

- **Kubernetes In-Place Pod Resizing GA** — feature ที่ขอมา years ยาว ถึง GA ปี 2026 ทำให้ปรับขนาด pod ได้โดยไม่ต้อง restart ช่วยลด downtime อย่างมีนัยสำคัญ [official] ([kubernetes.dev — K8s 2026 features](https://www.kubernetes.dev/resources/release/))

- **Sidecar Containers ถึง GA** — lifecycle management ที่เหมาะสมสำหรับ init containers มา stable แล้ว ทำให้การจัดการ sidecar ง่ายและเชื่อถือได้ [official] ([kubernetes.io — releases](https://kubernetes.io/releases/))

- **Dynamic Resource Allocation (DRA) ไปถึง beta** — ด้วยการปรับปรุง structured parameters สนับสนุนสำหรับการจัดสรร resource ที่ซับซ้อน [official] ([kubernetes.dev — release schedule](https://www.kubernetes.dev/resources/release/))

- **containerd 1.x support สิ้นสุด** — เตือน: Kubernetes version ถัดไปจะต้อง containerd 2.0+ ขึ้นไป องค์กรที่ยังใช้ 1.x ต้องวางแผน upgrade [official] ([CNCF news](https://www.cncf.io/news/))

→ **ภาพรวม:** In-Place Resizing และ DRA GA นำเสนอความสามารถใหม่ที่เป็นประโยชน์กับ infrastructure ที่ต้องการ high availability

## 🌐 Web / Frameworks / Languages

- **Node.js native TypeScript type stripping** — Node.js 22.18.0 เปิด type stripping by default ตั้งแต่มิ.ย. 2026 และ v24.3.0/22.18.0 ลบ warnings ทำให้รัน TypeScript native ได้โดยตรง ลดความจำเป็น build step [official] ([devnewsletter.com — state of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/))

- **TypeScript 6.0 เป็นรุ่นสุดท้าย JavaScript-based** — Microsoft วางแผน TS 6.0 เป็น major release สุดท้าย ที่ใช้ JavaScript บางที่ TS 7.0 อาจเขียน compiler ด้วย Go หรือภาษาอื่นสำหรับ performance ⚠️ ([devnewsletter.com — state of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/))

- **Rust web frameworks ecosystem maturity** — Axum 0.8.8, Actix Web 4.12.1, Salvo 0.89.1, Loco.rs (batteries-included) ที่ใช้ production ได้ Leptos 0.9 alpha มาแล้ว แสดงว่า Rust web development ถึง maturity level ที่เหมาะสำหรับ high-performance services [official] ([libs.tech — Rust web frameworks](https://libs.tech/rust/web-frameworks))

→ **ภาพรวม:** TypeScript native execution ใน Node.js เร่งขึ้น, Rust web ecosystem mature สำหรับ performance-critical applications
