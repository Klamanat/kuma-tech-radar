## 🤖 AI / LLM / Agents

- **DeepSeek v4-flash-0731 ขึ้นแท่น** — โมเดลใหม่จาก DeepSeek ออกมาวันที่ 5 พฤศจิกายน ตามเทรนด์ยังคงเป็นผู้เล่นแรนด์ AI ที่นำเสนอโมเดลประสิทธิภาพสูง [official](https://llmgateway.io/timeline)
- **Google ADK 2.0 และการเปลี่ยนแปลงใหญ่ของ Agent Framework** — Google ประกาศเปิดตัว ADK 2.0 (Agentic Development Kit) ที่มีสถาปัตยกรรมพื้นฐานแบบ graph-based หนึ่งคนดำเนินการ agent ได้เอง ซึ่งแสดงการเปลี่ยนแปลงที่สำคัญจาก chat-based ไปยังการทำงานจริงของ agents ในปี 2026 [official](https://www.shakudo.io/blog/top-9-ai-agent-frameworks)
- **Agent-to-Agent Protocol ที่ช่วยให้ vendors ทำงานร่วมกัน** — ServiceNow ได้ embed "Agent2Agent (A2A) Protocol" เป็นมาตรฐานอุตสาหกรรม ซึ่งเปิดให้ agents จากผู้ขายต่างๆ สามารถติดต่อสื่อสารกันได้ แสดงความพยายามเข้าสู่ยุคของ interoperability ⚠️ ([ServiceNow agent protocol](https://www.shakudo.io/blog/top-9-ai-agent-frameworks))
- **Stanford HAI: OSWorld success rate เพิ่มจาก 12% ขึ้นไป 66%** — AI agents ดีขึ้นเรื่อยๆ ในการทำงานจริง ตามรายงาน AI Index 2026 จาก Stanford ⚠️ ([AI Index 2026](https://kanerika.com/blogs/recent-developments-in-ai/))
- **Google Co-Scientist เพื่อส่งเสริมการค้นหาวิทยาศาสตร์** — Google DeepMind, Cloud, Labs และ Research ออกมา multi-agent AI research partner ที่จะช่วยเพิ่มความเร็วในการค้นหาวิทยาศาสตร์ [official](https://kanerika.com/blogs/recent-developments-in-ai/)

→ **เกี่ยวกับเรา:** Production agents กำลังเป็นจริง · Interoperability protocol ที่สำคัญสำหรับ agent orchestration

## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.38 ตาม Code Freeze November 16–17** — Release beta v1.38.0-beta.0 ออกมาวันที่ 4 พฤศจิกายน และทำ code freeze แล้ว เตรียมพร้อมสำหรับ GA ในวันที่ 16 ธันวาคม 2026 โดยจะสอดคล้องกับ KubeCon North America (ณ วันที่ 9–12 พฤศจิกายน) [official](https://www.kubernetes.dev/resources/release/)
- **Google AlloyDB Express และ cross-cloud interconnect เปิดใช้** — Google Cloud ประกาศเปิดตัว AlloyDB Express เมื่อวันที่ 4 พฤศจิกายน ที่มี free tier 50 free compute units ต่อเดือน พร้อมกับสนับสนุน cross-cloud interconnect สำหรับ AWS และ Azure [official](https://docs.cloud.google.com/release-notes)
- **AWS Step Functions เป็น Agent Tool ได้แล้ว** — ประกาศเมื่อวันที่ 2 พฤศจิกายน ว่า AWS Step Functions (orchestrates 220+ AWS services) สามารถเรียกใช้เป็น tool ของ agents ได้แล้ว แสดงให้เห็นการผลักดันของ cloud vendors ในการรองรับ agentic workflows [official](https://dev.to/nadtakanfuthoem/serverless-aws-roundup-week-of-2026-11-06-1k29)
- **AI-Driven DevOps เข้าถึง mainstream: Azure Autofix, IBM Terraform Portal** — Microsoft Azure DevOps ออก Autofix ฟีเจอร์ที่ใช้ AI ขอให้เสนอแก้ไขให้อัตโนมัติ IBM ออก Terraform Developer Portal (public preview) ที่มี policy-as-code และ PR review automation [official](https://devblogs.microsoft.com/devops/)
- **Microsoft Ignite Conference (17–20 พฤศจิกายน)** — อีก 10 วันจากนี้จะเป็นการประกาศหลักของ Azure และ DevOps [official](https://devblogs.microsoft.com/devops/)

→ **เกี่ยวกับเรา:** Kubernetes ecosystem ยังแข็งแรง · Agents ที่สามารถเรียก AWS/GCP services ระบบจะโอเปน

## 🌐 Web / Frameworks / Languages

- **TypeScript 7.1 คืน Compiler API ที่หาย ตั้งแต่ v7.0** — TypeScript 7.1 จะออกมา 24 พฤศจิกายน 2026 โดยฟื้นคืน Compiler API ที่เอาออกไปในเวอร์ชัน 7.0 โดยแยกเป็น entry points แยกกัน ซึ่งโครงการ Vue, Svelte และ Angular ยังคงต้องการ Release Candidate มาถึง 10 พฤศจิกายนแล้ว [official](https://www.infoq.com/news/2026/11/typescript-7-1-beta/)
- **.NET 11 ออกมาในเดือนนี้** — Microsoft .NET 11 มีกำหนดออกมาในเดือนพฤศจิกายน 2026 นี้ ตามเส้นทางปกติของการ release ในทุกเดือนพฤศจิกายน โดยจะรองรับจนถึง พฤศจิกายน 2028 [official](https://realpython.com/python-news-november-2026/)
- **Python 3.15 Release + Ecosystem Updates (Polars 2.0, pandas 3.1)** — Python 3.15 ออกมาแล้ว โดย Python 3.16.0a2 จะมา 10 พฤศจิกายน พร้อมกับ ecosystem updates สำคัญ เช่น pandas 3.1 และ Polars 2.0 ที่ให้ประสิทธิภาพการประมวลผลข้อมูลที่ดีขึ้น [official](https://realpython.com/python-news-november-2026/)
- **Chrome DevTools November Update: CSS for AI Agents** — Chrome เพิ่มการสนับสนุน CSS style inspection สำหรับ AI agents โปรแกรมสำรวจแบบ interactive position-area editor สำหรับ CSS anchor positioning และการวินิจฉัย Web Install manifest ⚠️ ([Chrome DevTools](https://developer.chrome.com/blog/new-in-devtools-november-2026))
- **Node.js Security Updates (11 พฤศจิกายน)** — มีการประกาศปล่อย security updates สำหรับ Node.js 26.x, 24.x และ 22.x ในวันที่ 11 พฤศจิกายน 2026 โดยมีการแก้ไข HIGH severity [official](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases)

→ **ภาพรวม:** TypeScript healing จาก 7.0 · Python 3.15 ออกมา · AI agents ได้ first-class support ในการพัฒนา
