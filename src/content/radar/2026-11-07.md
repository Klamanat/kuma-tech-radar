## ☸️ Cloud / DevOps / Infra

- **KubeCon + CloudNativeCon North America 2026** — จัดขึ้น Nov 9-12 ที่ Salt Lake City, Utah [official], อีเวนต์ใหญ่ประจำปีของ CNCF ที่คาดหวัง ([CNCF News](https://www.cncf.io/page/2/?post_type=post))
- **Kubernetes รองรับ AI** — CIQ ประกาศบรรจุ Kubernetes AI components ทั้งหมดเป็น single binary (Nov 2) [official], ลดความซับซ้อนของการตั้ง AI workloads ([Cloud Native Now](https://cloudnativenow.com/tag/gpu-infrastructure/))
- **Dynamic Resource Allocation ใน K8s v1.37** — เพิ่มการจัดสรร GPU และทรัพยากร custom อย่างไดนามิก ([kubernetes.dev](https://www.kubernetes.dev/resources/release/))

→ **เกี่ยวกับงาน infrastructure:** KubeCon ต้องติดตามเพื่อข้อมูลเกี่ยวกับ GPU scheduling และ Kubernetes for AI

## 🌐 Web / Frameworks / Languages

- **TypeScript 6.0 เป็นรุ่นสุดท้ายของ JavaScript compiler** — ออกแล้ว March 2026 [official], เตรียมทางสำหรับ TypeScript 7 (Go rewrite) ที่ปฏิสัพท์เร็วขึ้น ~10x ([Medium](https://medium.com/@mernstackdevbykevin/typescript-6-0-for-react-developers-what-actually-changed-a0215ac68a57))
- **TypeScript 7 / Project Corsa กำลังเข้ามา** — เขียนใหม่ด้วย Go, ลดการใช้หน่วยความจำและเวลา compile อย่างมหาศาล, คาดเร็ว 10x จาก TS 6.0 ⚠️ ([State of JavaScript 2026](https://devnewsletter.com/p/state-of-javascript-2026/))
- **React Ecosystem กำลังมีการปรับปรุง** — React Hook Form 7.81/7.82 (July 2026) เพิ่ม setValue option และ FieldArray component [official], React Router 8.2/8.3 ใช้ Web Streams ([Medium React Ecosystem](https://medium.com/@onix_react/whats-new-in-react-ecosystem-october-edition-a78b18f62c0c))

→ **ภาพรวม:** TypeScript ขาดขาเข้า Go era, React ecosystem ยังคงพัฒนา smooth ดีเด่น
