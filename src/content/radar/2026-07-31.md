## 🌐 Web / Frameworks / Languages

**TypeScript 7.0 ออก — Go compiler เร็ว 11.9x** [official] — TypeScript 7.0 compiler ด้วย Go มา 8 ก.ค. เร็ว 11.9 เท่า (VS Code ลดจาก 125.7s → 10.6s) และ drop ES5/AMD/UMD/SystemJS targets ทำให้ adopt mandatory ขึ้น ([ecorpit.com](https://ecorpit.com/nextjs-16-3-typescript-7-rust-go-toolchain-2026/))

**React Compiler ย้ายไป Rust — 3x เร็วกว่า TS** [official] — Meta ย้าย React Compiler logic จาก TypeScript → Rust merged ใน main repo ตอน July ด้วยความช่วยเหลือ AI และ Rust version เร็ว 3x (transformation logic ถึง 10x บางกรณี) ([infoq.com — Meta ports React Compiler](https://www.infoq.com/news/2026/07/meta-react-compiler-rust/))

**Rolldown 1.0 + Turbopack stable — Rust bundlers ชนะ esbuild/Rollup** [official] — Rolldown เข้า 1.0 สถาบัน (พฤษภาคม) และเป็น default ใน Vite, เร็ว 10–30x กว่า Rollup ส่วน Turbopack stable ใน Next.js 16 อยู่แล้ว (2–5x faster production builds, 10x Fast Refresh) ([cssauthor.com](https://cssauthor.com/best-rust-tools-for-javascript-developers/))

→ **ภาพรวม:** Rust ยึด JS tooling อย่างถาวร TS 7.0 บังคับใจ adopt ส่วน React Compiler ฝั่ง Rust เป็น signal ใหญ่
