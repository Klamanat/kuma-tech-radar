- **GKE Agent Sandbox, Maintainer Summit CFP (ปิด 19 ก.ค.)** — Google ขึ้น Agent Sandbox production-ready (May), CNCF เรียกข้อเสนอนัดแรม; steering committee election มีชื่อสัตว์พูดคุยเพิ่มเติม ([kubeify.com — 30 July 2026](https://shyam.kubeify.com/2026/07/latest-devops-cloud-news-30-july-2026.html))

## 🌐 Web / Frameworks / Languages

- **React Compiler 1.0 ผสมเนื้อเนื้อ TypeScript 7.0 (เป้า mid-2026)** [official] — React ที่ release ตุลา 2025 ได้เข้าสู่บ้านเป็นส่วนหนึ่งของ Meta production workload; TS compiler rewrite ไปด้วย Go + strict-by-default ตั้งแต่ 7.0 (type-check parity ~99.6%) ⁰³ ([react.dev/blog/react-compiler-1](https://react.dev/blog/2025/10/07/react-compiler-1))

- **rolldown Rust bundler ขึ้นแท่น default ของ Vite ecosystem** — Nuxt, SvelteKit, Astro เดินเหาะไปใช้แทน esbuild/Rollup ขณะบางทีมกล่าว build time ลดจาก 2.5 นาทีลงมา 40 วินาที ⚠️ ([strapi.io — Best JS Frameworks 2026](https://strapi.io/blog/best-javascript-frameworks))

- **React Server Components, Partial Pre-Rendering (PPR) ลดเวลา render** — React 19 Compiler ตัดใจ unnecessary re-renders ~25–40%, Server Components โกนเวลา TTL จาก ~2.4s เหลือ 0.8s ใน Next.js ([nucamp.co — Framework Trends 2026](https://www.nucamp.co/blog/javascript-framework-trends-in-2026-what-s-new-in-react-next.js-vue-angular-and-svelte))

→ **บทสรุป:** Rust ยำ tooling ตำแหน่ง build/compiler, TypeScript ปูพื้น application layer, React ยังเป็นชั้นสูงในชั่วคราว
