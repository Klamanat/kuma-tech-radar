## 🌐 Web / Frameworks / Languages

- **Topcoat ออกมา (Tokio team, July 2026)** — Rust framework สำหรับ full-stack reactive web apps ที่เน้นแบบ server-rendered แล้วเพิ่ม reactivity ผ่าน HTML snippets คล้าย HTMX หลังจาก Toasty ORM ใช้ได้ตั้งแต่ April 2026 ([tokio.rs — topcoat](https://tokio.rs/blog/2026-07-22-announcing-Topcoat))

- **Rust ฟรอนต์เอนด์เข้ามาแข่งขัน TypeScript ⚠️** — Leptos, Yew, และ Dioxus เติบโตขึ้นในเวลาเดียวกับ TypeScript ยังคงครองตำแหน่งในส่วนใหญ่ของโปรเจคใหม่ ([reintech.io — leptos-vs-yew-dioxus-2026](https://reintech.io/blog/leptos-vs-yew-vs-dioxus-rust-frontend-framework-comparison-2026))

- **TypeScript เป็นทางเลือก default ในเว็บ 2026** — โปรเจคใหม่เลือก TypeScript โดยค่าเริ่มต้น อย่างไรก็ตาม Rust frameworks ขยายตัวสำหรับ performance-critical components ⚠️ ([wpreset.com — best-languages-2026](https://wpreset.com/the-best-languages-for-web-development-in-2026/))

→ **ภาพรวม:** Rust ขยายเข้าฟรอนต์เอนด์อย่างแต่ง แต่ TypeScript ยังครองเวทีหลัก
