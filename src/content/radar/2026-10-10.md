## 🤖 AI / LLM / Agents

- **Claude Opus 5.5 ขึ้นมา 22 ก.ย.** — Anthropic ปล่อย Opus 5.5 ตั้งแต่เลย ขณะเดียวกัน AWS Bedrock เพิ่ม GPT-6 Sol และ GPT-6 Luna ให้บริการได้ ([Anthropic Claude updates](https://www.anthropic.com/news)) [official]. ท่าทีหนึ่งเหนือหลากหลาย vendor บุกเข้ามา.

- **โมเดล AI ออก ~23 ตัว ใน 4 เดือนแรก** — ตั้งแต่เริ่มปี vendor นับได้ 23 โมเดลใหม่จาก 15 providers, Alibaba ปล่อย Qwen3.8 Max (3 ส.ค.), xAI มี Grok 4.6, Google track ได้ Gemini 3.8 Flash สำหรับ production ความเร็วสูง ([LLM Release Tracker](https://llmgateway.io/timeline/2026)) ⚠️.

- **Gemini 4 คาดอยู่ในพัฒนา** — Google post-training ส่วนหนึ่ง Gemini 4 และคาดปล่อยเสร็จสิ้นก่อนสิ้นปี ยังไม่มีวันที่เจาะจง แต่ trend บ่งว่า momentum ยังแรง ([Google AI announcements](https://ai.google.dev/)) [official].

→ **เกี่ยวกับเรา:** AI ยังเร็ว แต่ขณะนี้ vendors โฟกัสไปทีซ้อมหนาแน่นของ inference ลดต้นทุนและเพิ่มประสิทธิ.

## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.36 — GPU scheduling เป็น stable** — Spring 2026 K8s ปล่อย 1.36 เข้าสเตเบิล DRA (Dynamic Resource Allocation) + Workload Aware Scheduling ให้ GPU ใช้ได้ตามน้ำหนักงาน, fine-grained Kubelet authorization ก็ขึ้น stable ([kubernetes.io/releases](https://kubernetes.io/releases/)) [official].

- **v1.36.2 latest stable release** — ตัวล่าสุด v1.36.2 ปล่อย 11 มิ.ย. 2026, v1.37.0 ยังอยู่ alpha ซึ่งหมายถึง 1.36 ยังอยู่ในวัฏจักรเสถียร ([Kubernetes version tracker](https://versionlog.com/kubernetes/)).

- **Ingress NGINX ออกจากวง** — CNCF ย้ายจาก Ingress NGINX ไปทาง Gateway API และขยายการใช้ Envoy Gateway ส่วนเครื่องมืออย่าง Argo CD (v3.2.12+), Volcano v1.14 ก็ทำให้ unified scheduling (training/inference/RL/agents) ([CNCF news](https://www.cncf.io/news/)).

→ **เกี่ยวกับงาน tune-keycloak:** GPU scheduling + Envoy Gateway มีความสำคัญเพิ่มขึ้นจากเศษปีที่แล้ว.

## 🌐 Web / Frameworks / Languages

- **React 19.2 — RSC ได้เร็วขึ้น** — React 19.2.8 ปล่อย 21 ก.ค. 2026 เพิ่มความเร็ว decode สำหรับ React Server Components, version 19.2 ขณะนี้ตั้งต่ออยู่และมี production use ที่ Meta ([react.dev](https://react.dev/blog)) [official].

- **Next.js เป็นทางเลือกหลัก** — Next.js ส่วนใหญ่โปรแกรม ใช้กันกว้าง ที่ TikTok, Twitch, Shopify เนื่องจาก RSC support เต็มตัว, Vercel ยังส่งฟีเจอร์ใหม่ เช่น partial pre-rendering ([Next.js docs](https://nextjs.org/docs)) [official].

- **TanStack Start — full-type-safe บริเวณราคาแพง** — ทีม TanStack ทำ TanStack Start ทำให้เป็นตัวเลือก handmade สำหรับท่ีต้องการ type safety ดีๆ, RSC production-ready ยังมาไม่ถึง ([TanStack](https://tanstack.com/)) ⚠️.

→ **ภาพรวม:** React ecosystem ยังอิง RSC, build tooling เลื่อนไป Rust (rolldown, esbuild ↙︎) เพื่อเร็วขึ้น.
