## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37 GA** [official] — เปิดตัว 4 ก.ย. 2026 พร้อม Dynamic Resource Allocation (DRA) Extended Resource เข้า GA และ KubeletInUserNamespace promoted to beta ([kubernetes.io/blog](https://kubernetes.io/blog/)) รองรับ autoscaling workloads ลงไปถึง zero replicas ลดความเสี่ยงของ non-root node operations

- **DataAgent $10M Pre-seed** — ออกจาก stealth พร้อมทุนระดมทุนเพื่อ agentic AI platform แก้ปัญหา production ใน Kubernetes โดยอัตโนมัติ ([shyam.kubeify.com](https://shyam.kubeify.com/2026/09/latest-devops-cloud-news-03-september.html)) ลดการรอ SRE intervention ด้วย AI-driven remediation

- **CrowdStrike Falcon 2026** — ขยายให้บล็อก malicious open-source packages ที่ endpoint ก่อนรัน embedded code ([techstartups.com](https://techstartups.com/2026/09/03/venture-capital-startup-funding-roundup-september-3-2026-base10-partners-gradient-ventures-point72-y-combinator-more/)) เสริมเข็มขัดความปลอดภัยสำหรับ supply chain

→ **ภาพรวม:** K8s 1.37 มี zero-replica + non-root capabilities, DataAgent ตัวใหม่นำ self-healing cluster operations ด้วย AI

## 🌐 Web / Frameworks / Languages

- **Rolldown 1.0 ขยับ Vite 8** [official] — Rust bundler เปิดตัว May 2026 ทำให้ build เร็วขึ้น 10–30 เท่า เทียบกับ Rollup ([daily.dev](https://daily.dev/posts/rust-on-the-web-is-starting-to-look-quite-good--yfe0t5npg)) ขับเคลื่อน Vite ecosystem (Next.js, SvelteKit, Astro) ไปสู่ performance ระดับใหม่

- **TypeScript 48.8% ใน Professional Developers** — สำรวจปี 2025 ชี้ว่านักพัฒนา professional ใช้ TypeScript เกือบครึ่งแน่ (Stack Overflow 2025 survey) ([strapi.io](https://strapi.io/blog/best-javascript-frameworks)) ยืนยัน static typing เป็น default ใน modern JavaScript ecosystem

- **Leptos นำ Rust Web Frameworks** — Rust web framework ได้รับ momentum leader ใน 2026 สำหรับ full-stack Rust projects ([rustify.rs](https://rustify.rs/articles/rust-leptos-fullstack-web-2026)) Yew ยังมั่นคงที่ 30k+ GitHub stars แต่ Leptos ให้ DX ที่ดีกว่า

→ **ภาพรวม:** Rust เข้ามาครองชั้น web tooling (Rolldown) และ full-stack frameworks (Leptos), TypeScript คง dominant ที่ application layer
