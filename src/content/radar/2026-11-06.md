## ☸️ Cloud / DevOps / Infra

- **Codefresh เก็บ $27 ล้าน** — บริษัทชี้ตัวเอง DevOps software delivery ที่มี Kubernetes เป็นหัวใจ ได้ funding นำโดย Red Dot Capital Partners [official] ([Codefresh Funding](https://pulse2.com/codefresh-27-million-funding/amp/))
- **Kubernetes ยังเป็น base สำหรับ CI/CD และ autoscaling** — แนวโน้มยังไป enterprise-grade tooling สำหรับความเป็นอัตโนมัติ/security และโครงสร้าง cluster ที่ซับซ้อน ([Kubernetes in Modern DevOps Workflows](https://dev.to/routeclouds/the-essential-role-of-kubernetes-in-modern-devops-workflows-1bk1))

→ **ข่าวเดือนนี้ยังเบา:** รอการประกาศจากเฉพาะเรื่อง KubeCon/CNCF

## 🌐 Web / Frameworks / Languages

- **Rust + React/TypeScript เป็นคู่มาตรฐาน** — Full-stack frameworks ที่นิยมขึ้นจับคู่ React/TypeScript บนหน้าบ้าน กับ Axum/Rust บนเซิร์ฟเวอร์ ([Tuono: React + Rust Full-Stack](https://github.com/SHA888/Awesome-Rust-TypeScript))
- **NoApi 0.1.43 (ก.พ. 2025)** — framework ที่ให้ Server Functions (เรียก Rust จากหน้าบ้านได้โดยตรง) ใช้ Axum + React + TailwindCSS ([NoApi on docs.rs](https://docs.rs/noapi))
- **Rapid และ RPRT** — Projects type-safe อื่นๆ ที่ใช้ React/TypeScript + Rust backend, แต่ project บางตัวอาจ stale (Rapid เข้า October 2023 ล่าสุด)

→ **แนวโน้มที่ชัด:** Rust ขึ้นเรือสำหรับ backend ไว้ performance + type safety
