## ☸️ Cloud / DevOps / Infra

- **Cloud conversation เปลี่ยนไป: adoption ✓ → efficiency ✓** — ตลาดเลิกถกว่า "ต้องไปแนว cloud-native" และ "ต้องมี Kubernetes" มาเป็น "efficiency, economic predictability, infrastructure at scale" ⚠️ ([devopsdigest.com](https://www.devopsdigest.com/)) · focus shift จาก "ต้องมี cloud" เป็น "optimize non-cloud workload"
- **Multi-cloud management นำค่า** — Kubernetes across AWS/GCP/Azure ต้องมี single pane of glass; ไม่ต้องสวิตช์ระหว่าง console · fleet management เป็นมาตรฐาน enterprise ⚠️ ([cncf.io](https://www.cncf.io/))

→ **ภาพรวมเดือน:** โฟกัส shift จาก adoption มา operational efficiency

## 🌐 Web / Frameworks / Languages

- **React ecosystem August 2026: version 19.2, Compiler stable** — React Compiler ลดการ manually memoize; ใช้ production ที่ Meta แล้ว · build optimization ด้วย AI ([builder.io — React AI Stack 2026](https://builder.io/blog/react-ai-stack-2026))
- **TypeScript เป็น baseline** — ครึ่งกว่า developer ใช้ TypeScript กับ React; end-to-end type safety (frontend → backend) เป็นเทรนด์ · Next.js นำในสำรวจและ job postings ⚠️ ([atakinteractive.com — Best Web Technologies 2026](https://www.atakinteractive.com/blog/best-web-technologies-2026))

→ **ภาพรวม:** TypeScript-first, type-safe baseline; Next.js + Vite + tRPC stack ชัด
