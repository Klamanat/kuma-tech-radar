## ☸️ Cloud / DevOps / Infra

**Kubernetes v1.36** — Production Readiness, native GPU scheduling ผ่าน Workload Aware Scheduling + DRA (Device Resource Allocation), fine-grained Kubelet authorization ขึ้น stable [CNCF announcement ⚠️](https://www.cncf.io/mail/u/0/page/13/)

**Envoy Gateway replaces ingress-nginx** — CNCF เลิกใช้ ingress-nginx ในโปรเจกต์내부ตัวเอง, ส่ภัยเขาไป Envoy Gateway ที่ทำงานชั้น L7 ได้ดีกว่า [Cloud Native Now August 2026 ⚠️](https://cloudnativenow.com/topics/cloudnativeplatforms/the-good-the-bad-and-kubernetes-ugly/)

**K8s for ML/GPU pipelines** — จาก Yandex Cloud meetup: Kubernetes ถูกกำหนดใหม่เป็น "operating system สำหรับ digital products" ไม่ใช่แค่ deployment tool, มีการใช้งานส่วนใหญ่เพื่อ ML training และ GPU orchestration [Yandex Cloud meetup May 2026 ⚠️](https://astanahub.com/en/blog/meropriiatie-kuber-meetup-2026-ot-yandex-cloud)

**FinOps integration** — DevOps และ FinOps teams รวมตัวแก้ปัญหา cloud cost governance ใน Kubernetes ผ่าน automated allocation tools [Cloud Native Now March 2026 ⚠️](https://cloudnativenow.com/tag/cloud-spend-visibility/)

→ **ภาพรวม:** K8s 1.36 คือ release ที่ขยายเข้าไป ML/GPU world อย่างจริงจัง; Envoy Gateway แทน ingress-nginx = future of API gateway layer

## 🌐 Web / Frameworks / Languages

**React 19.2.8** — ปรับปรุง React Server Components, decoding ได้เร็วขึ้น, released July 2026 [React ecosystem blog ⚠️](https://medium.com/@onix_react/key-web-development-trends-for-2026-800dbf0a7c8c)

**Next.js 16 current production** — Major version 16 ของ Next.js เป็นมาตรฐานของ production teams ในช่วงกลาง 2026, support สำหรับ React Server Components ในแบบ built-in [React ecosystem guide ⚠️](https://www.buildwithmatija.com/blog/react-ecosystem-2026-frameworks-platforms-typescript-stack)

**Vue 3.6 with Vapor Mode** — Vue 3.6 อยู่ใน beta phase โดยมี Vapor Mode เป็น headline feature สำหรับการคอมไพล์เป็น vanilla JavaScript, Vue core 3.5.40 ออกเป็นรุ่น stability [React vs Vue TypeScript Setup 2026 ⚠️](https://tech-insider.org/?p=16032)

→ **ภาพรวม:** TypeScript 7.0 และ React 19.2 ให้รากฐานเสถียร; Vue 3.6 Vapor Mode ให้ทางเลือกสำหรับการ serialize component เป็น vanilla JS
