## 🌐 Web / Frameworks / Languages

- **React Compiler port ไป Rust — PR #36173 เปิดมีนาคม 2026 [official]** — Joseph Savona ทีม React port logic TypeScript → Rust, สัญญาณ Rust เป็นบ้านยาวเรื่อยๆ สำหรับ compiler อนาคต [official] ([Frontend Wrapped H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **Next.js 16 (กุมภาพันธ์ 2026) ตั้ง Turbopack เป็น default bundler [official]** — ใช้สำหรับ next dev และ next build ครบถ้วน, ยืนยัน Rust-powered build tools เป็นมาตรฐาน [official] ([LogRocket](https://blog.logrocket.com/?p=214230))
- **Biome แทน ESLint + Prettier, Rust-based [official]** — tool linting/formatting เดี่ยว, อย่างไรก็ตาม rule น้อยกว่า ESLint + plugin parity issue ยังมีจนบัดนี้ ⚠️ ([Hackernoon](https://hackernoon.com/rust-is-now-the-hidden-engine-behind-javascript-tooling))
- **TypeScript type checking — ยังเป็น Go ไม่ใช่ Rust** — Microsoft port type checker ไปที่ Go, แตกต่างจาก build tooling stack ⚠️ ([TianPan forum](https://tianpan.co/forum/t/biome-is-replacing-eslint-prettier-bun-is-replacing-node-js-2026-is-the-year-rust-rewrites-the-javascript-toolchain/916))

→ **ภาพรวม:** Rust ยึดชั้น build tools + React Compiler, TypeScript ตั้งมั่นบน Go type checker
