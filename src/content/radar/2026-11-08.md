- **MMI, General Compute และ Pathos AI ระดมทุนรวม $494M** — ภูมิหลังของ AI startup funding ที่ไม่ใช่เพียงแค่ฟ้อร์อัพใหญ่โต แต่มีความหลากหลาย ([VCBacked — November 2026 Funding](https://www.vcbacked.co/funding/november-2026))

→ **เกี่ยวกับเรา:** AI inference/gateway tools (fal, LiteLLM) ที่ track ช่วยใจ agents ที่ต้อง scaling

## ☸️ Cloud / DevOps / Infra

- **KubeCon + CloudNativeCon North America 2026 Nov 9–12 ที่ Salt Lake City [official]** — งานใหญ่ของแพลตฟอร์ม CNCF ที่มี Kubernetes 1.37 สกรีนท่อง + ผลจากเทคนิคใหม่ ([LWCN — Week 44 Oct 26–Nov 1 2026](https://buttondown.com/lwcn/archive/lwcn-week-44-oct-26-nov-1-2026/))
- **KServe (CNCF Incubating) – ตัวจัดการ AI Inference บน K8s** — สนับสนุน multi-node inference, prefill/decode disaggregation, KV-cache-aware routing → หนุนรองสตาร์ทอัพ AI ที่ต้องสเกลทีน ([Thoughtworks Technology Radar — Platforms](https://www.thoughtworks.com/radar/platforms))
- **Yardi ซื้อ Sidero Labs (ผู้ทำ Talos) [official]** — Talos (Kubernetes distribution minimal open-source) อยู่ภายใต้ MPL-2.0 ต่อไป ความหมาย: ผู้ทำเครื่องมือ K8s เซฟ เสตบิลิตี้ยาว ([Tech News Oct 2026](https://devopsdigest.com/))
- **SPIFFE SPIRE v1.15.5 & CoreDNS v1.15.0 ปล่อย (security focus)** — ตรวจสอบพระราชกฤษฎีกา certificate authority compromise ที่ผ่านมา ([LWKD — Week ending Nov 16 2025](https://buttondown.com/LastWeekInKubernetes/))

→ **ภาพรวม:** ค่อนข้างฟ้อกัส AI inference optimization + security hardening หนึ่งขั้นบน K8s

## 🌐 Web / Frameworks / Languages

- **Preact 11 Beta ปล่อยออกมา [official]** — Hydration 2.0 ที่ปรับปรุง, default ref forwarding, streamlined bundling → React-compatible framework ที่เบา ได้ประโยชน์จากการพัฒนาเรื่อง hydration ที่เลกเกอร์ ([Frontend Wrapped H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **React Compiler + Rust PR #36173 ตัวสร้างคิดตัดสินใจ** — Joseph Savona ปล่อย experimental PR ที่ port TypeScript → Rust ของ compiler หลักการถูกนำมา Rust เสร็จสิ้น ⚠️ ([Frontend Wrapped H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **TypeScript 7.0 Beta – Go rewrite, strict-by-default** — ทีมกำลังเขียน compiler ใหม่ด้วยภาษา Go ลิตเถอร์จะตัด ES5 target + AMD/UMD/SystemJS type-check parity ≈99.6% ([State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/))
- **Vite 8 + Rolldown (Rust bundler) standard** — Rolldown 1.0 ตกลง API มั่นคง แทนการแยก esbuild/Rollup → Rust tooling ยึดกำหนด JS ecosystem ([State of JavaScript 2026](https://devnewsletter.com/p/state-of-javascript-2026/))

→ **ภาพรวม:** Rust เข้ามาแทนที่จุดหลักของ performance tooling; React infrastructure ยังอยู่ทีเอส/จาวาสคริปต์
