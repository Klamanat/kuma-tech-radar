## ☸️ Cloud / DevOps / Infra

- **Kubernetes = Default OS สำหรับ AI** — 82% container workloads ใช้ K8s ใน production ตอนนี้ GPU workloads เป็น first-class citizen ([Fairwinds K8s 2026 playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- **Dynamic Resource Allocation (DRA) beta→stable** — K8s 1.35 DRA binding conditions เข้า beta ทำให้ AI/ML workloads ใช้งานได้ง่ายขึ้น สร้าง self-healing clusters ([Fairwinds blog](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- **Platform Engineering adoption ~80%** — 80% orgs ตั้ง Internal Developer Platforms (IDPs) ลดภาระความซับซ้อนจาก K8s ให้กับ developers ([LoginLine Kubernetes trends](https://www.loginline.com/en/blog/2026-kubernetes-trends))
- **AI-Powered K8s Tools เพิ่มขึ้น** — Tools ใหม่ reasoning over cluster state, auto-correlate + fix problems ด้วยเลขศูนย์ manual intervention ([Pulumi automation era](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))

→ **ภาพรวม:** Kubernetes เลื่อนจาก container orchestrator ไป compute OS สำหรับ AI infrastructure
