## ☸️ Cloud / DevOps / Infra

- **Kubernetes มีอัญญาธิการเป็น "OS สำหรับ AI"** — K8s 1.35+ มี Dynamic Resource Allocation (DRA) ในเบตา ขนาดบรรจุ GPU/resource-intensive jobs กับ high-volume services ([Fairwinds — K8s 2026 playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- **Platform Engineering ยืดหนึ่งครั้ง** — ประมาณ 80% orgก่อตั้ง Internal Developer Platforms (IDPs) เพื่อซ่อน K8s complexity ([Pulumi Blog](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))
- **AI-Powered DevOps Tools** — เครื่องมือ generation ใหม่ reasoning over cluster state อัตโนมัติตรวจ correlate + fix problems ([Medium — 7 AI-Powered K8s Tools](https://medium.com/devops-ai-decoded/7-ai-powered-kubernetes-tools-rewriting-cloud-native-ops-in-2026-e5e57c69cd73))
- **RapidFort ที่ Black Hat USA** — ขยายความสามารถ secure open source runtimes ในตัว production (ประกาศ ส.ค. 2026) [official]

→ **ภาพรวม:** K8s กำลังจากการ manage containers → ชั้นของ AI compute orchestration

## 🌐 Web / Frameworks / Languages

- **React 19.2 ใช้ production** — React Compiler v1.0 (ตุลา 2025) ประมาณสุก [official], ค่า TypeScript adoption = 40% ของนักพัฒนา ([Nucamp blog](https://www.nucamp.co/blog/javascript-framework-trends-in-2026-what-s-new-in-react-next.js-vue-angular-and-svelte))

- **TypeScript ครองเบสลาย** — 40% exclusive TS adoption, 6% plain JS-only, TS เป็น baseline ของ professional projects เพราะ AI tools read type clearer ([Nucamp](https://www.nucamp.co/blog/javascript-framework-trends-in-2026-what-s-new-in-react-next.js-vue-angular-and-svelte))

→ **ภาพรวม:** TypeScript baseline + meta-frameworks ครองระบบ, Rust tooling (ต่อเนื่องจากช่วงก่อน) ยึดได้ยิ่งขึ้น
