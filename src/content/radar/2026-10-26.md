## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.36 shipping stable features** — Kubernetes v1.36 นำ new stable, beta, alpha features เข้ามาในการ release ที่ผ่านมา spring 2026 ([Cloud Native Now](https://www.cncf.io/mail/u/0/page/13/))
- **Topcoat: Rust full-stack framework [official]** — Tokio announced (22 ก.ค. 2026) Topcoat เป็น modular, batteries-included framework สำหรับสร้าง full-stack reactive web apps ด้วย Rust บนบ้าน server-rendered บน Toasty ORM ([tokio.rs/blog](https://tokio.rs/blog/2026-07-22-announcing-Topcoat))
- **FinOps converge กับ DevOps** — Cost management และการ convergence ของ DevOps + FinOps กลายเป็น core concern สำหรับการควบคุม Kubernetes cost ⚠️

→ **เกี่ยวกับงาน:** Kubernetes stability ทำให้พื้นฐาน production-ready แข็งขึ้น, Rust frameworks พร้อมสำหรับ backend

## 🌐 Web / Frameworks / Languages

- **React Compiler TypeScript → Rust port [official]** — Joseph Savona เปิด PR #36173 (มี.ค. 2026) เพื่อ experimental port React Compiler จาก TypeScript ไป Rust, merged สำเร็จ มิ.ย. 2026 แต่ยังอยู่ experimental label ([LogRocket H1 2026 Review](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **Vite 8 + Rolldown unified bundler [official]** — Vite 8 shipped with Rolldown เป็น Rust-based bundler, Rolldown 1.0 stabilized API ไม่นาน หลังจากนั้น ภาพรวม: Rust tooling (Rspack, Biome, Turbopack) เข้ามาแทน JS tools ([LogRocket](https://blog.logrocket.com/?p=214230), [JavaScript Weekly](https://javascriptweekly.com/issues/796))
- **Leptos, Yew, Dioxus Rust frontend frameworks** — ตลาด Rust frontend frameworks กำลังขยายตัว แต่ไม่มี clear winner yet; บทเรียนจากใช้งานแล้วชี้ว่า performance vs DX tradeoff ยังอยู่บนโต๊ะ ⚠️ ([Reintech comparison](https://reintech.io/blog/leptos-vs-yew-vs-dioxus-rust-frontend-framework-comparison-2026))

→ **ภาพรวม:** Rust ยึดชั้น JS tooling infrastructure (build, compile), TypeScript vibe ยังแข็งแกร่ง แต่ edge cases บวก performance demands กำลังเปิดประตู Rust frameworks
