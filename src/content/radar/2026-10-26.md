## 🤖 AI / LLM / Agents

- **Claude Haiku 5.5 ลดราคา per-token** [official] — Anthropic ปล่อยรุ่นเล็กรุ่นใหม่วันที่ 9 ต.ค. โดยลดราคา per-token สำหรับ prompt ขึ้นถึง 100K tokens ทำให้เข้าถึงได้สำหรับงาน cost-sensitive มากขึ้น ([AI Agent Changelog — Oct 2026](https://openclawdatabase.com/changelog/2026-10/index.md))

- **Claude Code 2.1.306 พร้อม fork subagents** [official] — เวอร์ชันจาก 2.1.296–2.1.306 ส่งมอบ idle compaction และ fork subagents by default ปรับปรุง agent workflow ที่สำคัญและลดเวลา execution สำหรับ multi-step tasks ([AI Agent Changelog — Oct 2026](https://openclawdatabase.com/changelog/2026-10/index.md))

- **Microsoft Agent Framework ถึง Release Candidate** — Microsoft รวม AutoGen และ Semantic Kernel เป็นกรอบงาน unified ที่เข้าสู่ RC status ปรับสนับสนุน enterprise agent architectures ที่ scale ([AI Agent Frameworks Guide](https://hatchworks.com/blog/ai-agents/ai-agent-frameworks-guide/))

→ **ท่าทีตลาด:** Agent frameworks consolidate รอบ 8 ecosystem หลัก (LangGraph, CrewAI, Microsoft, Google, OpenAI, LlamaIndex, Pydantic, Claude) · ราคา Haiku ลด = cost barriers ไป low

## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37 rootless mode, HPA scale-to-zero Beta** [official] — September 2026 release ย้ายระดับ kubelet's rootless mode และ HPA scale-to-zero เป็น Beta, Storage Version Migration general available ปรับสนับสนุน zero-trust deployment และ cost optimization ([Last Week in Cloud Native — Week 37](https://buttondown.com/lwcn/archive/lwcn-week-37-sep-7-13-2026/))

- **containerd v2.3.5 patch ความปลอดภัย** [official] — แพตช์ CVE-2026-53495 และ GHSA-rp3h-jf77-q9p4 บรรจุการป้องกันการเคลื่อนตัวของ credential ระหว่าง image distribution เพิ่มความมั่นคง supply chain container ([Last Week in Cloud Native — Week 37](https://buttondown.com/lwcn/archive/lwcn-week-37-sep-7-13-2026/))

→ **เกี่ยวกับเรา:** rootless Kubernetes + HPA scale-to-zero = low-privilege + cost-optimized infrastructure · container hardening priority

## 🌐 Web / Frameworks / Languages

- **React 19.2.8 RSC decoding ประสิทธิภาพ** [official] — เวอร์ชัน 21 กรกฎาคม ส่ง decoding ที่เร็วกว่าสำหรับ React Server Components แก้ไข bottleneck โคดในการทำงาน RSC ที่เกิดขึ้นบ่อย ([State of JavaScript 2026](https://devnewsletter.com/p/state-of-javascript-2026))

- **Next.js LTS security releases** [official] — เวอร์ชัน 16.2.11 (Active LTS) และ 15.5.21 (Maintenance LTS) ปัดตัวได้จำนวนช่องโหว่หลายแห่ง ส่งสัญญาว่า framework ต้องให้ LTS track อย่างจริงจัง ([State of JavaScript 2026](https://devnewsletter.com/p/state-of-javascript-2026))

- **TypeScript 7 native Go implementation** — Podcast กุมภาพันธ์ 2026 ยืนยัน TypeScript 6 เป็น final release ที่เขียนด้วย TypeScript เอง · version 7 use Go native ทำให้เร็วขึ้นและ maintenance ง่ายขึ้น ([TypeScript 6.0 for React Developers](https://medium.com/@mernstackdevbykevin/typescript-6-0-for-react-developers-what-actually-changed-a0215ac68a57))

→ **ภาพรวม:** React ecosystem optimize ต่อ RSC perf · TS + Go rewrite = tooling speed leap · Framework LTS = maturation signal
