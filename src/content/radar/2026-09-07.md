## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37: DRA Extended Resource → GA** [official] — 3 release ต่อเนื่องที่ build DRA บรรลุ General Availability, เปิด extended resources scheduling สำหรับ GPU/custom hardware ([Kubernetes Blog](https://kubernetes.io/blog/))
- **KubeletInUserNamespace → beta** — kubelet, CRI runtime, CNI plugins, kube-proxy รันได้เป็น non-root user บน host, ลดความเสี่ยง security ⚠️ ([2026 Kubernetes Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- **Horizontal autoscaling down to zero replicas (scale-to-zero)** — K8s v1.37 รองรับ scale workloads ลง 0 replicas, ประหยัด cost สำหรับ event-driven/batch jobs ([Kubernetes Blog](https://kubernetes.io/blog/))
- **CNCF Certified Kubernetes AI Conformance Program** เปิดตัว — standardize AI/ML workload execution บน K8s, K8s เป็น de facto OS ของ AI services ([2026 Kubernetes Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

→ **เกี่ยวกับงาน tune-keycloak:** DRA GA = GPU scheduling ง่ายขึ้น, scale-to-zero = cost savings, AI Conformance = standardized AI platform

## 🌐 Web / Frameworks / Languages

- **React Compiler: TypeScript → Rust port merged into main** [official] — Meta PORT logic ส่วนใหญ่ของ React Compiler จาก TypeScript ไป Rust, integrate tight กับ Rust-based JS toolchain, build เร็วขึ้นและ DX ดีขึ้น ([React Compiler Rust Port — InfoQ](https://www.infoq.com/news/2026/07/meta-react-compiler-rust/))
- **React Compiler v1.0 (ต.ค. 2025) ใช้ production ทั่วไป** — Meta ใช้อยู่แล้ว, เพิ่ม TypeScript exclusive adoption ขึ้นเป็น 40% ⚠️ ([Web Dev Trends 2026](https://www.alphonsolabs.com/web-development-trends-2026/))
- **Vite 98% developer satisfaction vs Webpack** — Webpack-to-Vite migration เป็น transition บิวด์ tool หลักใน 2026, rolldown (Rust bundler) ตั้งเป็น default ของ Vite ecosystem ([State of JS 2026](https://devnewsletter.com/p/state-of-javascript-2026/))
- **Leptos + Rust web frameworks ได้ momentum** — Actix Web, Axum, Rocket, Warp, Loco เติบโต, Dioxus recommended สำหรับทีม React ที่ migrate ไป Rust ([Best Rust Frontend Frameworks 2026](https://medium.com/@priya.raimagiya/the-5-best-rust-frontend-frameworks-reviewed-for-2026-4694dad8f181))

→ **ภาพรวม:** Rust toolchain dominant ในปี 2026 (React Compiler, Vite/rolldown), TypeScript ยังแข็งในเลเยอร์ application
