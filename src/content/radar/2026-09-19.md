## 🤖 AI / LLM / Agents

**OpenAI GPT-6 Astra [official]** — GPT-6 Astra ปล่อย GA ในเดือนนี้ด้วยราคา $10/$1 (cached)/$12.50 cache write/$50 per 1M tokens รองรับ context 1.05M tokens และ output 128K tokens เปิดทำให้ reasoning มากขึ้นเรื่อยๆ กำลังทดแทน GPT-5 ทั้งหมด ([llmgateway.io — AI releases](https://llmgateway.io/timeline))

**Anthropic Fable 5.1 GA [official]** — ปล่อย General Availability วันที่ 1 กันยายน 2026 โมเดลตัวน้อยแต่เร็ว lightweight แข่งขันโดยตรงกับ OpenAI GPT-4o-mini ในการงานทั่วไป ([llm-stats.com — AI news](https://llm-stats.com/ai-news))

**Google Gemini 3.8 Flash และคณะ [official]** — Google ปล่อย Gemini 3.8 Flash ในต้นเดือนนี้ พร้อมอัปเดตสิ่งต่างๆ ทั้ง vision, reasoning, code gen ตัดจ่ายสตรีมิย่างฉับพลันยิ่งขึ้น ([llm-stats.com — updates](https://llm-stats.com/ai-news))

**DeepSeek V4.1, Sakana Fugu, Atria Dawn [official]** — เดือนกันยายนเปิดออกมาหลาย open/semi-open models: DeepSeek V4.1 Flash (10 ก.ย.), Sakana AI Fugu Max (11 ก.ย.), Atria Dawn Preview (12 ก.ย.) ตลาดเร่งแข่ง reasoning ให้เทียมกับ Astra ([llm-stats.com — news](https://llm-stats.com/ai-news))

**OpenAI GPT Image 2.5 variants [official]** — Flare และ Sunburst ปล่อยเมื่อ 8 กันยายน ใช้ DALL-E 4 layer ช่วยวาดภาพจากข้อความ ([llmgateway.io — timeline](https://llmgateway.io/timeline))

→ **เกี่ยวกับเรา:** Reasoning models (Astra, Fugu, Atria Dawn) เหมาะสำหรับ skill authoring อัตโนมัติและ agent loops; Fable 5.1 ประหยัดค่า API

## ☸️ Cloud / DevOps / Infra

**Kubernetes v1.37 บนโลด [official]** — วางตัวเมื่อวันที่ 8 กันยายน 2026 โฟกัสใหญ่ไปที่ AI workloads: KubeletInUserNamespace ขึ้น beta, GPU scheduling, resource management ต่างๆ สำหรับ inference engines ([kubernetes.io — releases](https://kubernetes.io/releases/))

**Kubernetes ทั้งระบบทะยายเข้า AI stack** — K8s ไม่พลาดเทรนด์ AI แล้ว ปัจจุบันใช้เพื่อทำ inference, ML pipelines, GPU routing, model serving ร่วมกับ KubeFlow, Volcano, HAMi ([cloudnativenow.com — feature](https://cloudnativenow.com/features/kubernetes-did-not-miss-the-ai-wave-it-absorbed-it/))

**Sangfor Enterprise AI Platform [official]** — บิลด์ AI compute platform บน K8s + Volcano + HAMi ก่อนหน้านี้จุกขัดที่ 2 concurrent dev Pods ตอนนี้ขึ้นไป 30 pods (15X) บน 8-GPU portable device ⚠️ ([portworx.com — trends](https://portworx.com/blog/kubernetes-enterprise-adoption-trends/))

**Enterprise Adoption เพิ่ม** — 84% ของ enterprises คิดว่าภายใน 5 ปี จะสร้างอย่างน้อยครึ่งของแอปพลิเคชันใหม่ บน Kubernetes เพื่อ stateful apps, AI pipelines, VMs ([portworx.com — trends](https://portworx.com/blog/kubernetes-enterprise-adoption-trends/))

→ **ภาพรวม:** K8s ขึ้นแท่นเป็น backbone ของ AI infrastructure ทั้งระบบ; GPU + inference scheduling กำลังเป็น feature หลัก

## 🌐 Web / Frameworks / Languages

**TypeScript ครองหัวจริงตามมา [official]** — ขึ้นเป็น most-used language บน GitHub ตั้งแต่เมื่อ August 2025 ด้วยอัตรา YoY contributor growth 66.63% ⚠️ นี่อันดับแรกครั้งแรก ชนะ Python, JavaScript ([strapi.io — frameworks 2026](https://strapi.io/blog/best-javascript-frameworks))

**TypeScript adoption มาก** — ในสำรวจ Stack Overflow 2025 ถึง 48.8% ของ professional developers ใช้ TypeScript, 58% ว่าสะใจใจ type safety ของมัน ([infoworld.com — JavaScript 2026](https://www.infoworld.com/article/4123802/are-you-ready-for-javascript-in-2026.html))

**React ยังครอง แต่ Next.js/Svelte ได้ territory** — React ยังหลัก แต่ฝ่ายใหญ่ชุมชนไปทาง Next.js (RSC + PPR), Svelte (signals), Astro (zero JS by default) ขนแบบเซิร์ฟเวอร์-first, stateful caching ([medium.com — next big frontend](https://medium.com/@mernstackdevbykevin/the-next-big-frontend-framework-is-not-coming-its-already-here-94749abf1b48))

**Remix 3 reboot, AI-native full stack** — Remix ไม่ขึ้นบน React อีกแล้ว ก่อตั้งจากศูนย์ (ground-up rethinking) ครั้งนี้ฝ่ายสร้าง Ryan Florence + Michael Jackson ดึง AI engineers เข้ามากำหนด framework architecture ([dev.to — JavaScript Frameworks](https://dev.to/this-is-learning/javascript-frameworks-heading-into-2026-2hel))

**HistTypeScript/strictness ยังเทรนด์** — Team ต่างๆ ขาดไขแปลง strict type checking สูงขึ้น; frameworks ที่มี TS support ดี เช่น Next.js ได้สัง ([c-sharpcorner.com — top 10](https://www.c-sharpcorner.com/article/top10-javascript-frameworks-to-watch-in-2026/))

→ **เทรนด์หลัก:** TypeScript เลี่ยวนำจริงแล้ว, React ecosystem สาขาไปหลายทาง (Next/Svelte/Astro), AI embedding ในเฟรมเวิร์กเอง
