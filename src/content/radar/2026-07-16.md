## ☸️ Cloud / DevOps / Infra

**Platform Engineering แทนที่ DevOps (80% ขององค์กร 2026)** — การเปลี่ยนมุมมอง: DevOps คลาสสิก → Platform Engineering เพื่อลด cognitive load ของ developers มี 80% ขององค์กรเห็นคุณค่าของ internal developer platforms ขึ้นจาก 45% เมื่อ 3–4 ปีที่แล้ว [aggregator] ([Medium DevOps 2026](https://medium.com/@h.stoychev87/devops-cloud-platform-tools-by-category-for-2026-68ed92103c17))

**Kubernetes ยังเป็น de facto OS สำหรับ AI** — K8s ไม่ใช่ orchestrator อีกต่อไป มันเป็น default operating system ของ AI workloads, microservices, data pipelines, และ edge ทั้งหมดผสมกัน Multi-cluster architecture กลายเป็น standard สำหรับ scale global [industry report] ([Kubernetes Playbook 2026](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

**Policy enforcement + AI-driven orchestration = ยุค automation ใหม่** — Infrastructure as code, policy enforcement (Kyverno), และ AI-driven orchestration ทำงานร่วมกัน Platform teams ต้องเรียนรู้ kubectl, Helm, manifests เป็น "second nature" [industry guidance] ([Pulumi Blog — Beyond YAML](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))

→ **เกี่ยวกับ tune-keycloak:** K8s policy + Kyverno admission control ตรงกับ realm config governance

## 🌐 Web / Frameworks / Languages

**TypeScript ขึ้นแท่น (#1 ภาษา GitHub contributor by count)** — TypeScript กลับมาครอง GitHub monthly contributor count หลังจาก Python ในตลาด professional developer 78% ใช้ TypeScript (ขึ้นจาก 69% ในปี 2024) React ยังคงแชมป์ job market และ 46.9% professional developers ชื่นชอบ [official metrics] ([Stack Overflow 2025 Survey](https://www.alphonsolabs.com/javascript-trends-2026/))

**Rust web ecosystem mature: Leptos, Axum, Yew ครบพร้อม** — Frontend (Yew = React-inspired, Leptos component model) Backend (Axum, Actix Web, Rocket, Warp) สามารถทำ full-stack ได้ เรียบร้อย ประวัติการทำงาน: ทดแทน Node microservice ด้วย Rust ในงาน data processing, auth, analytics ที่ Node หนักตัว [industry report] ([JetBrains Rust 2026](https://blog.jetbrains.com/rust/2026/01/27/rust-vs-javascript-typescript/))

**Next.js / React ยังครอง fullstack ตลาด** — ขณะ Rust โตแต่ Next.js/React ยังอื่นอย่างแข็งแรง developer อาจใช้ Rust backend + React/Next frontend = hybrid stack ยุค 2026 [market snapshot] ([Wasp Frameworks 2026](https://wasp.sh/resources/2026/02/24/best-frameworks-web-dev-2026))

→ **ภาพรวม:** TypeScript ขึ้นเสมอ, Rust เข้ามาเป็นตัวเลือกสำหรับ high-performance, React ครองตลาด fullstack ยัน
