## 🤖 AI / LLM / Agents

**OpenAI GPT-5.6 Luna, Terra, Sol ออก 9 ก.ค.** — OpenAI ปล่อยตระกูลโมเดล Luna (reasoning ลึก), Terra (general), Sol (speed-optimized) ในวันเดียว ทำให้เทรนด์โมเดลใหม่ออกประมาณทุก 3 วัน [official](https://llm-stats.com/llm-updates)

**Meta Muse Spark 1.1 และ Grok 4.5 ตามมา** — Meta ปล่อย Muse Spark 1.1 (9 ก.ค.) ส่วน xAI เปิด Grok 4.5 (8 ก.ค.) ตอกย้ำว่า frontier model รุ่นใหม่แม่นยำและรวดเร็ว ⚠️ ([AI Flash Report](https://aiflashreport.com/model-releases.html))

**โมเดล open-source ชั้นนำในเดือนนี้** — GLM-5.2 (1.1T parameter MoE, MIT license, 91.2% GPQA Diamond), DeepSeek V4 Pro, Kimi K2.7 Code (+21.8% ดีกว่า K2.6), MiniMax M3 — ล้วนมี context window ยาวและรองรับ coding agents เก่ง ([LM Market Cap](https://lmmarketcap.com/new-ai-models))

→ **เกี่ยวกับเรา:** LLM ตัวเล็ก (MiniMax M3, DeepSeek V4) ที่ถูกและเร็วเหมาะ agent workflow, coding automation

## ☸️ Cloud / DevOps / Infra

**Kubernetes v1.37 ออก 26 ส.ค. พร้อม breaking changes 3 ประการ** — K8s 1.37 ต้องการ containerd 2.0 ขึ้นไป (ไม่รองรับ containerd 1.x แล้ว), cgroup v2 บังคับ, และตัดแล้ว deprecated kubelet flags — ทีมต้องวางแผนข่ามอย่างน้อย 1.5 เดือนล่วงหน้า [official](https://www.kubernetes.dev/resources/release/)

**Dynamic Resource Allocation เพิ่ม GPU partitioning** — K8s 1.37 ขยายการ allocate device เป็นส่วน ๆ ได้ (NVIDIA MIG) ทำให้ inference workload หลายตัวใช้ GPU เดียว — สำคัญต่อ cost ของ AI inference cluster ([kubernetes.io/releases](https://kubernetes.io/releases/))

**ไม่มี major CNCF graduate ใหม่เดือนนี้** — OpenTelemetry ยังบทบาทหลัก Kyverno policy engine ยังพัฒนา GPU scheduling + DRA ยังอยู่ใจกลางคุยโพล ([CNCF news](https://www.cncf.io/news/))

→ **ล่าวสังคม:** containerd 2.0 + cgroup v2 ต้องเตรียม, GPU partitioning ลดค่าพอดี

## 🌐 Web / Frameworks / Languages

**TypeScript 7.0 ใช้ Go native compiler ออก 8 ก.ค. [official]** — Vercel เอา tsc ไปเขียน Go ใหม่ ทำให้ type-checking เร็ว 11.9x เท่า, ยังคงความแม่นยำ 99.6% กับตัวเดิม — TS จึงเป็นภาษาหลักแบบพัฒนาต่อไป ([ecorpit.com — Next.js 16.3 and TypeScript 7.0](https://ecorpit.com/nextjs-16-3-typescript-7-rust-go-toolchain-2026/))

**React Compiler เขียนใหม่ใน Rust แล้ว 9 มิ.ย.** — PR #36173 ส่วนใหญ่มาจาก AI port จาก TypeScript → Rust, Next.js 16.4 ชิปแล้ว build เร็ว 40% ขึ้นไป (experimental ยังต้องเปิด flag) — Rust ยึดชั้น perf-critical tools ([React Compiler Is Now in Rust — Next.js 16.4](https://byteiota.com/react-compiler-rust-nextjs-16-4-faster-builds/))

**Next.js 16.3 เพิ่มลด memory 90%, build ลด 5.5x (29 มิ.ย.)** — Turbopack cache บน disk ทำให้ dev server สตง, production build แรกติดตั้งเร็วขึ้น — ecosystem JS เคลื่อนไปเทค native binary ล้วน ⚠️ ([Next.js 16.3 announcement](https://byteiota.com/react-compiler-rust-nextjs-16-4-faster-builds/))

→ **ภาพรวม:** ทั้ง TypeScript และ React Compiler ไปใน Go + Rust หนีออกจาก JavaScript, Vite แซง Webpack (84M weekly downloads, 98% satisfaction)
