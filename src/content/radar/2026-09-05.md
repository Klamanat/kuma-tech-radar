## 🤖 AI / LLM / Agents

- **โมเดลใหม่ 5 รุ่นออกใน 3 วันแรกของเดือน** — ตลาด AI ยังรักษาโมเมนตัมเร็ว มีการ release ในเกือบทุกเพลตฟอร์มหลัก ([llm-stats — AI updates](https://llm-stats.com/llm-updates))
- ออกช่วงต้นกันยายน: **Anthropic Fable 5.1** (GA 1 กันยายน), **Qwen3.8 27B** (2 กันยายน), **Muse Spark 1.3 Contributor** จาก Meta (2 กันยายน), **Google Gemini 3.5/3.6/3.7 Flash** variants, **Amazon Nova 2 Sonic** ที่มี real-time voice capability ([LLM Gateway — timeline](https://llmgateway.io/timeline))
- เรือธง tier-1: **OpenAI GPT-6 Astra** (staged GA ที่ $10/$50 per 1M tokens, context 1.05M) ได้คะแนน Terminal-Bench 4.0 57.7, DeepSWE 74.1, GPQA 96.0 ([llm-stats — AI news](https://llm-stats.com/ai-news))
- Gemini family momentum ยังแรง โดยเฉพาะตัวแปร lightweight (3.5 Flash Lite) ที่เหมาะสำหรับ edge + voice features ⚠️ ([LLM Gateway — timeline](https://llmgateway.io/timeline))

→ **เกี่ยวกับเรา:** Fable 5.1 + GPT-6 Astra คือตัวเลือกใหม่สำหรับ agent authoring ต้องติดตาม benchmark

## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37 released** — Production ready **3 กันยายน 2026** [official], brings Dynamic Resource Allocation (DRA) Extended Resource support ไปอยู่ GA, หมายความว่า GPU resource management เป็นขั้นจริงแล้ว ([kubernetes.io/blog](https://kubernetes.io/blog/))
- **Auto-scaling to zero replicas บน API level** — v1.37 ใช้ horizontal autoscaling API ที่สามารถ scale workload ลงมาเป็นศูนย์ได้ ขณะนี้อยู่ Beta และ enabled by default, สำคัญสำหรับ cost optimization ([Spectro Cloud news](https://www.spectrocloud.com/news))
- **etcd RangeStream graduating to beta** — การอ่าน etcd ใหญ่ได้ faster + efficient มากขึ้น ช่วยให้ cluster scale ได้ดีกว่า ([kubernetes.io/blog](https://kubernetes.io/blog/))
- **Kubernetes เป็น default operating layer สำหรับ AI infrastructure** — ตั้งแต่ data pipeline ไปถึง edge + edge AI ทำให้ K8s ปัญหาร้อนในปี 2026 ⚠️ ([Fairwinds — 2026 Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

→ **ภาพรวม:** K8s 1.37 ตัวเร็ว ด้วย DRA GA + auto-scale to zero, ต้องเตรียม cluster upgrade

## 🌐 Web / Frameworks / Languages

- **Rolldown (Rust bundler) ขยายพื้นที่หลัก** — reached v1.0 เมื่อพฤษภาคม 2026, ปัจจุบัน powers Vite 8 (stable มาตั้งแต่มีนาคม 2026), build speed เร็ว **10-30x ตามเทียบ Rollup** ⚠️ ([Medium — Rust Frameworks 2026](https://medium.com/@priya.raimagiya/the-5-best-rust-frontend-frameworks-reviewed-for-2026-4694dad8f181))
- **TypeScript ยังนำในการเลือกใช้** — TypeScript adoption ขณะนี้ยังเป็นตัวนำใน JavaScript community แม้ว่าไม่ universal, compiler + language improvements ยังมีการพัฒนาต่อ ([JetBrains Blog — Rust vs JS/TS](https://blog.jetbrains.com/rust/2026/01/27/rust-vs-javascript-typescript/))
- **React + Next.js ecosystem ยงใหญ่ที่สุด** — React ยังมี largest library collection + talent pool, Next.js ชี้นำด้วย React Server Components, Server Actions, serverless deployment via Vercel ([Strapi — Best JS Frameworks 2026](https://strapi.io/blog/best-javascript-frameworks))
- **Full-stack Rust frameworks maturity** — Leptos (full-stack), Dioxus (cross-platform: web/desktop/mobile/terminal), Actix Web, Axum, Rocket ทั้งหมดเป็นตัวเลือกจริงแล้ว ([Rustify — Leptos 2026](https://rustify.rs/articles/rust-leptos-fullstack-web-2026))

→ **ภาพรวม:** Rust ยึดชั้น build tooling (Rolldown 10-30x) + full-stack framework, TypeScript ยังแข็งแกร่ง application layer
