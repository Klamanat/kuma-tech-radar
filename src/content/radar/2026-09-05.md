## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37 ออกแล้ว 3 กันยายน 2026** [official] — **DRA (Dynamic Resource Allocation) Extended Resource ขึ้น GA** หมายความว่า GPU/hardware resource management เสถียรสำหรับ production แล้ว ([kubernetes.io/blog](https://kubernetes.io/blog/))
- **Horizontal autoscaling scale ลงถึง zero replicas (Beta, enabled by default)** — API level support ทำให้ cost optimization ดีขึ้น ลดค่า idle resources ([Pulumi — Kubernetes 2026](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))
- **DataAgent ออกมาจาก stealth พร้อม $10 มิลลิอนเพาะทุน (pre-seed)** — agentic AI platform ออกแบบเพื่อแก้ปัญหาการผลิตภายใน Kubernetes environments · CrowdStrike Falcon 2026 ยังผลักดัน Real-Time Supply Chain Attack Protection ([DevOps news — 3 Sept](https://shyam.kubeify.com/2026/09/latest-devops-cloud-news-03-september.html))
- **K8s เป็น default layer สำหรับ AI infrastructure** — Infrastructure as Code + Policy Enforcement + AI-Driven Orchestration เข้าสู่ยุคใหม่ ⚠️ ([Fairwinds — 2026 Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

→ **ภาพรวม:** K8s 1.37 ตัวเร็วกับ DRA GA, agentic AI สำหรับ K8s เริ่มออกมา

## 🌐 Web / Frameworks / Languages

- **React 19.2+ คือรุ่นล่าสุด, React 20 กำลังพัฒนา** [official] — React 19.2 นำ Activity Component (ควบคุม visibility), useEffectEvent Hook (แยก events จาก effects), cacheSignal API (async resource cleanup ใน Server Components) ([Medium — React ecosystem Sept](https://medium.com/@onix_react/whats-new-in-react-ecosystem-september-edition-6bd1ec2c10ab))
- **React Server Components ถึง production-standard** — เดินทางจาก experimental เป็น stable · paradigm shift ในการคิด data fetching + component architecture · React Router 7.9 ทำให้ middleware + type-safe context APIs เสถียร ⚠️ ([DEV Community — JS 2026](https://dev.to/this-is-learning/javascript-frameworks-heading-into-2026-2hel))
- **WebStorm 2026.2 + TypeScript 7 support** — ปรับปรุง performance บน large codebases, React 19 full support ใน React Buddy · TypeScript adoption ใน React projects ถึง **78%** ([JetBrains — WebStorm 2026.2](https://blog.jetbrains.com/webstorm/2026/07/webstorm-2026-2/))
- **Rust ยึดชั้น performance-critical tooling** — bundlers, compilers, linters เหล่านี้ต้องการ speed + memory efficiency

→ **ภาพรวม:** React Server Components + TypeScript 78% = paradigm shift, Rust ยึดชั้น build tooling
