## ☸️ Cloud / DevOps / Infra

- **Kubernetes 1.37 "Garhwal"** — เปิดตัว เน้นเสถียรภาพ, security, AI/ML workload optimization รอบนี้เป็นหลัก ([Kubernetes InfoQ](https://www.infoq.com/news/2026/09/kubernetes-1-37/)) [official]
- **Native histogram support** ขึ้นบ้านใหญ่เป็น Beta และเปิดแบบ default ใน v1.37 — metrics API ก้าวหน้าเข้าสู่ production-ready ([Kubernetes Blog](https://kubernetes.io/blog/)) [official]
- **GPU allocation ปั่น 95%+** บน Kubernetes ด้วย Koordinator (case study Zhuoyu Technology), มี infrastructure team 3 คนตัดลด cloud cost 30-40% ([Portworx Trends](https://portworx.com/blog/top-tech-trends-2026-kubernetes-ai-inference/)) ⚠️
- **Voice of Kubernetes 2026:** 84% ขององค์กรจาก 500+ คาดว่า half ของแอปเพ็นใหม่จะสร้างบน K8s ใน 5 ปีข้างหน้า ([Portworx Enterprise Adoption](https://portworx.com/blog/kubernetes-enterprise-adoption-trends/)) ⚠️

→ **เกี่ยวกับงาน:** GPU optimization + AI scheduler อยากเศษต่อ tune-keycloak, K8s เป็น default layer สำหรับ AI inference

## 🌐 Web / Frameworks / Languages

- **Rolldown 1.0 ปล่อยเมื่อพฤษภาคม 2026** — Vite 8 (stable ตั้งแต่มีนาคม) สนับสนุน, bundler แบบ Rust เร่งบิลด์ 10-30x ไปกว่า Rollup ([Strapi Frameworks](https://strapi.io/blog/best-javascript-frameworks)) [official]
- **Elysia บน Bun runtime** — ทำให้ 2-3x throughput กว่า Express, zero config, type-safe routing ดึง Fastify มาอยู่ข้างหลัง ([Sencha JS Trends](https://www.sencha.com/blog/tend-technologies-in-javascript/)) ⚠️
- **TypeScript 7 support** ใน WebStorm 2026.2 — IDE พร้อมรอรับโปรเจคที่ใช้ TS 7 แล้ว ([JetBrains WebStorm](https://blog.jetbrains.com/webstorm/2026/07/webstorm-2026-2/)) [official]
- **ES2025 language features** ขึ้นเป็น standard, React ชนะโด่งด้วย Server Components, Angular ยึด enterprise ด้วย standalone components, Vue ลดต่อ Composition API ([Shift Asia Frameworks](https://shiftasia.com/column/top-20-web-development-frameworks/)) ⚠️

→ **ภาพรวม:** Rust tooling (Rolldown, elysia) ขึ้นแรง, JS framework shift ไปที่เสถียรภาพกับ enterprise readiness, ES2025 เป็นมาตรฐาน
