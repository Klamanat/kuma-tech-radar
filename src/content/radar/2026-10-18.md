## 🌐 Web / Frameworks / Languages

- **React 19 + TypeScript ยังเป็น default stack สำหรับ frontend** — Teams ใช้ React 19 + TypeScript + Next.js fullstack ได้เร็วขึ้น, hybrid rendering modes ของ Next.js เชื่อมกับ Vercel edge network ([DEV Community - web-frameworks-2026](https://dev.to/devin-rosario/web-frameworks-2026-future-proofing-enterprise-tech-stack-4l03)) ⚠️
- **Rust frontend frameworks ก้าวเข้าโปรดักชั่นแล้ว** — Leptos, Yew, Dioxus ตัวจริงแล้วใน production apps, Leptos ใช้ fine-grained reactivity ใกล้เคียง React hooks ([reintech.io - Rust frontend comparison](https://reintech.io/blog/leptos-vs-yew-vs-dioxus-rust-frontend-framework-comparison-2026)) [official]
- **Topcoat: Full-stack reactive Rust framework ประกาศ 22 กรกฎาคม 2026** — Server-rendered + reactivity via metadata (เหมือน HTMX pattern), modular + batteries-included, เทียมกับ Toasty ORM ([Tokio blog](https://tokio.rs/blog/2026-07-22-announcing-Topcoat)) [official]

→ **ภาพรวม:** Rust ยังคงความได้เปรียบด้าน performance backend/fullstack, React TS ปกครองส่วน frontend application logic
