## ☸️ Cloud / DevOps / Infra

- **66% Kubernetes ใช้ generative AI inference แล้ว** — CNCF data ว่า 82% container users รัน Kubernetes โปรดักชั่น และ 66% ใช้เพื่อจัดการ generative AI inference workloads — K8s กลายเป็น standard platform AI/ML orchestration ([CNCF - Cloud Native Report](https://www.cncf.io/blog/2026/01/13/the-symbiotic-revolution-ai-and-cloud-native-technologies-transforming-the-digital-landscape)) ⚠️
- **K8sGPT sandbox project ที่ CNCF** — อนุมัติ K8sGPT (AI diagnostics tool ให้ Kubernetes) เป็น sandbox project สำหรับ troubleshoot cluster issues ผ่าน AI ([notes.kodekloud.com](https://notes.kodekloud.com/docs/Introduction-to-K8sGPT-and-AI-Driven-Kubernetes-Engineering/The-AI-Revolution-in-Kubernetes-and-DevOps/Historical-Context-of-DevOps-and-AI-Evolution/page))
- **GPU/CPU allocation automation** — 200OK Solutions บรรยาย K8s auto-allocate ทำให้ GPU/CPU resources ตาม workload demands; recommend Prometheus monitoring + RBAC + network policies + autoscaling เพื่อควบคุม cost ([200OK Solutions - K8s AI Orchestration](https://www.200oksolutions.com/blog/kubernetes-ai-orchestration-2026/))

→ **ภาพรวม:** K8s นำค่ายปัจจุบันในการจัดการ AI inference ที่ scale — cost control เป็น next frontier

## 🌐 Web / Frameworks / Languages

- **React Compiler สำเร็จ Rust port — 3-10x เร็วขึ้น** — ทีม React port React Compiler จากไป Rust (opened March, merged June 2026) ผล ~3x ความเร็วผ่าน Babel plugin, ~10x บน raw transformation logic — test setup ยังอยู่ validation phase ⚠️ ([LogRocket - Frontend Wrapped H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **Rust frontend frameworks ปลายผลแน่นอน** — Yew, Leptos, Dioxus ก้าวขึ้น production-ready แล้ว: Leptos ให้ React-like ergonomics ผ่าน fine-grained reactivity, Dioxus เป็น React-inspired cross-platform UI framework ที่ compile ได้หลายแพลตฟอร์ม ([Reintech - Leptos vs Yew vs Dioxus](https://reintech.io/blog/leptos-vs-yew-vs-dioxus-rust-frontend-framework-comparison-2026)) [official]
- **TypeScript + React ยังครองไป frontend application** — Noapi (Axum + React + type sharing) แสดง pattern fullstack Rust แต่ยังนิยมเฉพาะ legacy ตัวเล็ก ([lib.rs - noapi](https://lib.rs/crates/noapi))

→ **ภาพรวม:** Rust ได้ foothold ด้าน frontend performance via compiler ports; React TS ยังเป็นปกติ application logic
