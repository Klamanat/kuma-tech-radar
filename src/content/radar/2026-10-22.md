## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.36 โลก Gateway API — Ingress-NGINX ปลายเส้นทาง** — release เมื่อ 22 เม.ย. 2026 shift ไปสู่ API ใหม่ที่ scalable กว่า Ingress-NGINX ซึ่งกำลังจะถูก retire เสร็จสิ้นในปี 2026 นี้ [official — kubernetes releases](https://kubernetes.io/releases/)

- **Argo CD patch releases บ่อย** — ongoing support cycle ให้ manifest และ signed container images ทั่วไป ใน roundup พบ v3.4.2 ขึ้นไป ([CNCF — last week in cloud native](https://buttondown.com/lwcn/archive))

## 🌐 Web / Frameworks / Languages

- **React Compiler เกือบกลายเป็นมาตรฐาน production** — จาก blog ก่อนหน้า ชี้ว่า React Compiler ปัจจุบันใช้ได้จริงกับ Meta และเริ่มเป็นปกติในหลาย project ด้วยอัตโนมัติ optimize memoization ⚠️ ([Medium — React trends 2026](https://medium.com/@onix_react/key-web-development-trends-for-2026-800dbf0a7c8c))
- **React Server Components ขึ้นเท่า production** — render side shift ไปเป็น server ที่ main แล้ว app ส่วนใหญ่ที่ใหม่เลือก RSC เป็น default architecture [trend — RSC adoption](https://git.handmade.network/javascript-frameworks-heading-into-2026.html)
- **Topcoat — Rust full-stack framework — announced 22 ก.ค. 2026** — Tokio project ประกาศ framework ใหม่สำหรับ server-rendered reactive web apps reactivity มาจาก HTML snippets + metadata ไม่ได้ใช้ virtual DOM ไปเหมือน HTMX [official — Tokio blog](https://tokio.rs/blog/2026-07-22-announcing-topcoat)
- **Leptos, Yew, Dioxus เป็น production-ready** — framework Rust เหล่านี้มี maturity ระดับใช้ได้แล้ว Leptos ใช้ fine-grained reactivity คล้าย React hooks, Dioxus target หลาย platform (web, desktop, mobile, TUI) [compare — reintech](https://reintech.io/blog/leptos-vs-yew-vs-dioxus-rust-frontend-framework-comparison-2026)

→ **ส่วนใหญ่:** JS ecosystem ยังนำโดย React + Server Components trend · Rust options ในเนื้อที่เพิ่มความเป็นเลือก
