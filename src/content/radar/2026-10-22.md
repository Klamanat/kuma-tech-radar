## 🌐 Web / Frameworks / Languages

- **React Compiler "Rust port"** — Joseph Savona opened PR ใน March 2026, merged ใน June 2026, still experimental [official] — full TS→Rust rewrite logic อยู่ใน core ([LogRocket — Frontend wrapped H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **TypeScript 7.0 Beta** — Go-native compiler ที่มี "major performance gains" ใน public beta [official], TS 6.0 beta มา stricter defaults เตรียมทาง v7 ([Reactiflux podcast — Feb 2026](https://reactiflux.js.org/transcripts/tmir-2026-02))
- **Vite 8 + Rolldown 1.0** — major Rust-powered build tool shift, Yarn 6 previewed as Rust rewrite [official] — obligatory "rewrite it in Rust" moment ที่เป็นจริง ([Reactiflux — Feb 2026](https://tmir.reactiflux.com/episodes/2026-02))
- **React Foundation launched** — official entity เพื่อ govern React ecosystem [official] ([React blog](https://react.dev/))

→ **ภาพรวม:** Rust เข้าชั้นไป React compiler + build tools อย่างมั่นคง, TypeScript 7.0 beta ready for feedback
