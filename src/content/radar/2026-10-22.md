## 🌐 Web / Frameworks / Languages

- **React 20 กำลังพัฒนา** — ตามหลัง React 19.2 ปัจจุบัน ([Medium - React Trends 2026](https://medium.com/@onix_react/key-web-development-trends-for-2026-800dbf0a7c8c))
- **React Server Components เป็น major shift** — Paradigm ใหม่ที่ fetch data server-side ก่อนส่งไปยัง client ลดขนาด JavaScript บน browser ([ATAC Interactive](https://www.atakinteractive.com/blog/best-web-technologies-2026))
- **Next.js กำลังครอบงำ** [official] — บริหารเป็น full-stack React meta-framework ที่ niche ที่สุด สำหรับ professional projects ส่วนใหญ่ ([Bitcot - Web Frameworks](https://www.bitcot.com/best-web-application-development-frameworks/))
- **Vite + TypeScript เป็นจุดเริ่มต้นสำหรับ modern development** — Create React App ถูก deprecated อย่างเป็นทางการ React ขอแนะนำให้ใช้ Vite, Next.js หรือ Remix สำหรับ projects ใหม่ ([BuildWithMatija](https://www.buildwithmatija.com/blog/md/react-ecosystem-2026-frameworks-platforms-typescript-stack))
- **TanStack Start และ React Router 8 ตามมา** — Frameworks ที่น่าจับตามองใหม่ที่เพิ่มเติม full-stack capabilities ให้กับ React ecosystem ([ATAC Interactive](https://www.atakinteractive.com/blog/best-web-technologies-2026))

→ **เทรนด์เด่น:** TypeScript เป็นพื้นฐาน React Server Components ทำให้เกิด paradigm ใหม่ Next.js ยังครอบงำแต่มี alternatives ที่น่าสนใจ
