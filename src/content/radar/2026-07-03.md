## 🌐 Web / Frameworks / Languages

- **Rolldown 1.0 RC ขยับตลาด** — Rust bundler ถึง 1.0 RC (มกราคม 2026) เป็น drop-in replacement ของ esbuild (dev) และ Rollup (prod) [official] · ลด build time 38–64% (Ramp, Mercedes-Benz.io, Beehiiv) ([PkgPulse Guide](https://www.pkgpulse.com/guides/rolldown-vs-esbuild-rust-bundler-2026))
- **Rust tooling ครองเครื่องมือ** — esbuild (0.19s) และ Rolldown (0.27s) นำหน้าในเรื่อง cold builds · tooling JS-based หลายตัวเปลี่ยนตัวไป Rust/Go tools ([Benchmark 2026](https://decodeapps.pp.ua/blog/post/fastest-js-bundler-2026-rolldown-vs-esbuild-vs-webpack-benchmark))
- **Performance jump** — 10–30x เร็วกว่า Rollup โดยเข้ากันได้กับ Rollup plugins ⚠️ ([DEV Community](https://dev.to/pockit_tools/rust-is-eating-the-javascript-toolchain-rolldown-oxc-rspack-and-the-end-of-js-based-build-tools-4007))

→ **ภาพรวม:** Rust ยึดชั้น build toolchain อย่างชัดเจน · หากยังใช้ Rollup/Webpack ควร ทดสอบ Rolldown
