## ☸️ Cloud / DevOps / Infra

- **KubeCon + CloudNativeCon North America 2026** — จัดขึ้น 9–12 พ.ย. ที่ Salt Lake City [official] เป็นแหล่งรวมการประกาศ AI-on-Kubernetes อย่างหนัก บริษัทหลัก (Buoyant, Solo.io, CIQ) เปิดตัววิธีการใหม่ใช้ GPU workloads บน K8s ([CloudNativeNow](https://cloudnativenow.com/tag/leanix/))

## 🌐 Web / Frameworks / Languages

- **Topcoat: Full-Stack Rust Framework** — ประกาศ July 2026 [official] modular batteries-included Rust framework สำหรับสร้าง reactive web apps ที่ไม่ต้อง heavy in-browser interactivity ตัดกับ Leptos/Dioxus ที่ compile WebAssembly ([Tokio Blog](https://tokio.rs/blog/2026-07-22-announcing-Topcoat))
- **rari: React Server Components + Rust Runtime** — project ล่าสุดเลือก RSC architecture เรียกใช้ Rust runtime ที่ embed V8; build HTTP server, RSC renderer, และ routing ด้วย Rust ล้วน ([docs.rs — rari](https://docs.rs/crate/rari/0.13.3)) ⚠️
- **Axum + React Full-Stack Templates** — ชุด Turborepo starter ที่เชื่อม React frontend ด้วย Axum backend Rust โดยแบ่ง types โดยอัตโนมัติผ่าน OpenAPI (type-safe end-to-end) ([GitHub](https://github.com/flosse/rust-web-framework-comparison))

→ **เทรนด์:** React-with-Rust-backend เป็น pattern หลักสำหรับ type-safe, high-performance full-stack; Rust-compiled-to-WebAssembly สำหรับ client-side heavy interactivity
