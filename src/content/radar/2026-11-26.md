## 🤖 AI / LLM / Agents

- **GPT-6 Cyber & GPT-5.6 Sol ออกจากศูนย์ OpenAI** — OpenAI เปิดตัวมาดอลเซิร์ฟสองตัวในนิวเวมเบอร์ โดย GPT-5.6 Sol มีราคาโปรโมท ที่หมดอายุประมาณ 21 พฤศจิกายน ⚠️ ([blog.mean.ceo — AI releases](https://blog.mean.ceo/new-ai-model-releases-news-november-2026/))
- **Claude Fable 5.2 และ Claude Mythos 5.2** — Anthropic ประกาศวางมาดอลสองตัวเมื่อวันที่ 9 นิวเวมเบอร์ โดย Mythos เป็นรุ่นที่ตัดความปลอดภัยบางส่วนออก ([nocode.mba — releases tracker](https://www.nocode.mba/ai-release-tracker/2026/11))
- **Tencent Hy4 — ประสิทธิภาพวิชั่น + computer-use** — Tencent ปล่อย Hy4 Flash API เมื่อ 16 นิวเวมเบอร์ พร้อมความสามารถเข้าใจภาพและบังคับคอมพิวเตอร์ ([thursdai.news — releases](https://thursdai.news/releases/2026-11))
- **Gemini 4 Carbon & Kimi K3.1 Pro เปิดตัวแบบคู่ขนาน** — Google Gemini 4 Carbon เข้า GA เมื่อ 10 นิวเวมเบอร์ ขณะที่ Moonshot AI ปล่อย Kimi K3.1 Pro โอเพนเวตต์ ⚠️ ([capitalandcompute.net — releases](https://capitalandcompute.net/md/new-ai-models-november-2026.md))

→ **เกี่ยวกับเรา:** ฮือ 15–22 มาดอลใน 1 เดือน ตลาด AI ยังเร่งออยากให้สิ้นปี

## ☸️ Cloud / DevOps / Infra

- **KubeCon + CloudNativeCon North America 2026 — AI workload เป็นจุดศูนย์กลาง** — งานบรรยายใหญ่จัด ที่ Salt Lake City วันที่ 9–12 นิวเวมเบอร์ โดยเฟกัสหลักไปที่การใช้งาน AI บน Kubernetes ([cloudnativenow.com — KubeCon coverage](https://cloudnativenow.com/tag/leanix/))
- **AWS Nitro Sandboxes + Kubernetes AI appliances** — AWS เปิด Nitro Sandboxes ให้คอนเทนเนอร์มีขอบเขตความปลอดภัยแบบ VM (17 นิวเวมเบอร์) ส่วน Supermicro ร่วมกับ Red Hat เปิดตัว edge AI appliance (13 นิวเวมเบอร์) ([cloudnativenow.com — Kubernetes news](https://cloudnativenow.com/category/topics/cloudnativedevelopment/kubernetes/page/5/))
- **Buoyant & Solo.io ชิงจังหวะ AI agents บน K8s** — Buoyant ปล่อย open-source control plane สำหรับ AI workload (4 นิวเวมเบอร์) ขณะที่ Solo.io เพิ่มการรองรับ AI agent clusters (13 นิวเวมเบอร์) ⚠️ ([cloudnativenow.com — CNCF news](https://www.cncf.io/page/2/?post_type=post))
- **Salesforce & Karpenter — ประเมิน 1000+ EKS clusters** — Salesforce ย้าย EKS clusters ไปใช้ Karpenter ใหญ่กว่า 1000 เครื่อง เพื่อเร็วขึ้นและทำงานเสถียรขึ้น ⚠️ ([infoq.com — DevOps](https://www.infoq.com/Devops/news/16/))

→ **เกี่ยวกับเรา:** K8s กับ AI ติดแน่น — agenda ประชุม GPU scheduling + control plane หลีกเลี่ยงไม่ได้

## 🌐 Web / Frameworks / Languages

- **TypeScript 7.0 — Go compiler ลด build time 8–12 เท่า** — Microsoft ปล่อย TypeScript 7.0 ที่ใช้ native Go compiler แทน JavaScript อดีต ส่งผลให้เวลา build ลดลงอย่างมากมาย ([infoq.com — JavaScript](https://www.infoq.com/javascript/news/45/))
- **React Router v8 & Remix 3 — ไม่ทำให้ React อีกต่อไป** — React Router v8 ปล่อย 17 มิถุนายน ด้วยการยกเลิก ES5 + เน้น web standards ส่วน Remix 3 beta ชี้ไปยังไทม์ แบบไม่พึ่ง React อีก ⚠️ ([infoq.com — Web Development](https://www.infoq.com/Web-Development/news/45/))
- **TypeScript ทำลายสถิติเมื่อเทียบกับ Python + JS** — ในนิวเวมเบอร์ TypeScript กลายเป็นภาษามากไฟใจในไฟ GitHub ที่สุด ไหนก่อน Python และ JavaScript ([okoone.com — tech innovation](https://www.okoone.com/spark/technology-innovation/what-javascript-looks-like-in-2026-and-why-it-matters/))
- **React 19.2 + React Compiler 1.0 — วิญญา optimize หลัก** — ตั้งแต่ late 2025 React team ส่ง Compiler เสถียรพร้อม React 19.2 ซึ่งอยู่ใน production ที่ Meta แล้ว ⚠️ ([thursdai.news — React releases](https://thursdai.news/releases/2026-11))

→ **ภาพรวม:** ทูลช่วยเน้นการลดเวลา build (TypeScript 7.0, Rust ecosystem) + frameworks หันไปวิธี web standards
