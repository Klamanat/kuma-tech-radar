## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.35 Pod Resize ไป GA** — Feature ที่ถ่ายทำผ่าน 3 รุ่น (alpha → beta → GA) ทำให้นักพัฒนาปรับ resource request/limit หลัง Pod schedule แล้ว ลดปัญหา overprovisioning ของการ pre-allocate resource ([Kubernetes Blog](https://kubernetes.io/blog/))

- **Docker ทำการอัพเดต container runtime และ security** — ปรับปรุง Docker Desktop บวก Ask Gordon sidebar แก้ destination-escape flaw CVE-2026-17106 บนคำสั่ง docker container cp ([Docker Release Notes](https://releasebot.io/updates/docker)) ⚠️

- **Container market $7.41B แต่ WebAssembly ขอมาขอไป** — 82% container users รันจริง Kubernetes บนเซิร์ฟเวอร์ production แต่ภัยคุกคาม Wasm ขึ้นมาจาก edge + low-latency workloads ทำให้ยักษ์ใหญ่เฝ้าตัว ([Kubernetes Infrastructure Report 2026](https://ernie55ernie.github.io/infrastructure/2026/08/21/kubernetes.html))

→ **เกี่ยวกับ tune-keycloak:** Pod resize ช่วยใจในการ tuning resource limits ค่อย ๆ ปรับให้ตรงตัว Wasm แพร่หลายอาจเปลี่ยนเกมใน edge auth scenarios
