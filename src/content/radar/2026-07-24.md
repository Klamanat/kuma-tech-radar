## 🤖 AI / LLM / Agents

- **GPT-5.6 ออกเร็ว OpenAI 9 กรกฎาคม** — ออกมา 3 variant: Luna, Terra, Sol ตามลำดับ [official](https://llm-stats.com/llm-updates) · Grok 4.5 จาก xAI และ Muse Spark 1.1 จาก Meta เสียบหนาบ "วันเดียว" (8–9 ก.ค.) แสดง momentum ของเรือธง AI ยังเร่งหนัก ([AI Model Releases](https://aiflashreport.com/topics/new-ai-model-releases.html))
- **Kimi K3 จาก Moonshot AI (16 ก.ค.)** — ตัวจริง frontier-scale LLM 2.8 trillion parameters, context 1 ล้านโทเค็น, native vision · ranking ประมาณที่ 4 โลกบนเลบอร์ดรด Artificial Analysis [official](https://llm-stats.com/ai-news) · ซอร์สโค้ดสัญญาปล่อย 27 ก.ค.
- **Gemini 3.5 Flash Lite & Gemini 3.6 Flash (21 ก.ค.)** — Google ลดจำนวนตัวเล็ก flash models ลง context ยาว affordable inference [official](https://llm-stats.com/llm-updates) · Claude Fable 5 (1 ก.ค.) + Claude Sonnet 5 (30 มิ.ย.) ยังสร้าง momentum ในกลุ่ม reasoning/agent

→ **ส่วนที่เกี่ยว:** AI agents มี inference cost ต่ำลงบนตัวจริง (Gemini 3.5 Lite, Kimi K3) = ทำให้ใช้งาน /learn + SKILL gen cost-effective

## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37 เข้า code freeze (23 ก.ค.)** — มีการปล่อยผ่าน feature freeze (10 ก.ค.) และ code freeze เมื่อวานนี้ [official](https://www.kubernetes.dev/resources/release/) · ตั้งเป้า release 26 สิงหาคม 2026 ([Kubernetes Contributors](https://kubernetes.io/releases/))
- **etcd v3.7.0 ออกเสียบ RangeStream** — component สำคัญของ Kubernetes ได้ feature ที่ยอดนิยมมานาน (streaming rangequeries) [official](https://kubernetes.io/releases/)
- **Kubernetes 1.33 เข้า maintenance mode (28 มิ.ย.)** → ก็เปลี่ยนมา 1.34 maintenance 27 สิ.ค. ผู้ที่ติดรุ่น 1.33 ต้องเร่งไป upgrade ⚠️ ([Kubernetes Release Info](https://endoflife.date/kubernetes))

→ **เกี่ยวกับโปรเจกต์:** update K8s dependency ต้องเสร็จก่อน August release date

## 🌐 Web / Frameworks / Languages

- **TypeScript 7.0 ออกพร้อมคอมไพเลอร์ Go (8 ก.ค.)** [official] — type-check เร็วขึ้น **11.9 เท่า** (VS Code ที่ใช้ 125.7 วินาที ตอนนี้ใช้แค่ 10.6 วิ) ([ecorpit TypeScript 7.0](https://ecorpit.com/nextjs-16-3-typescript-7-rust-go-toolchain-2026/)) · standard package ส่งคอมไพเลอร์ Go มาตรฐาน แต่ stable API ไม่ออก (wait for 7.1)
- **React Compiler ปลดปล่อย Rust port** — merge PR #36173 (9 มิ.ย.) port logic TypeScript → Rust ทั้งหมด · Next.js 16.4 ใช้ Rust version ได้ build เร็วขึ้น **40% ขึ้นไป** [official](https://byteiota.com/react-compiler-rust-nextjs-16-4-faster-builds/) ([Next.js Blog](https://nextjs.org/blog))
- **Next.js security release (21 ก.ค.)** — แอดเดรสหลาย security issues ⚠️ อัปเดตต้องเร่ง ([Next.js Blog](https://nextjs.org/blog))
- **Rust web frameworks ปลูกเพิ่ม** — Actix Web, Axum, Rocket, Warp, Loco ตอนนี้เทียบกับ JS patterns ได้ · full-stack tools เช่น Leptos นำ component model มา Rust [official](https://daily.dev/posts/rust-on-the-web-is-starting-to-look-quite-good--yfe0t5npg)

→ **ภาพรวม:** TypeScript เร็วขึ้นจาก Go compiler ส่วน React Compiler ปนปลายด้วย Rust = tooling ของ JS/TS ยังเสริม performance-heavy layer ด้วยสิ่งต่างภาษา
