## ☸️ Cloud / DevOps / Infra

- **Docker + Kubernetes adoption ที่สูงขึ้น** — Docker ใช้โดย 92% ของ IT professionals ณ 2026 [official], Kubernetes ที่มี ~92% market share ในด้าน orchestration ระดับ enterprise ([docker.com — 2026 reports](https://www.programming-helper.com/tech/docker-2026-container-adoption-enterprise-kubernetes-python))
- **Docker Desktop 4.69.0** — มี built-in Kubernetes support ที่ปรับปรุงแล้ว พร้อม containerd v2.2.1 และ Docker Compose v5.0.0 ([releasebot — docker updates](https://releasebot.io/updates/docker))
- **WebAssembly (Wasm) ขึ้นเป็นทางเลือก** — 31% ขององค์กรทดสอบ Wasm แทน containers สำหรับงานเฉพาะ ⚠️, เพิ่มขึ้นจาก 8% ใน 2024 ([sivaro — k8s analysis](https://sivaro.in/articles/kubernetes-in-2026-still-the-king-or-just-another-tool/))
- **Gordon feedback + stability** — Docker Desktop ได้รับ feedback buttons และการแก้ไข stop timeout bugs สำหรับ Mac/Windows/Linux ([releasebot — docker](https://releasebot.io/updates/docker))

→ **ภาพรวม:** Docker/K8s ที่เหนือเหนือแล้ว แต่ Wasm เริ่มโคจรเข้ามา สำหรับ edge computing
