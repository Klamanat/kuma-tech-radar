## ☸️ Cloud / DevOps / Infra

**KubeCon + CloudNativeCon North America 9–12 พฤศจิกที่ Salt Lake City** — งานประชุมใหญ่ที่เสร็จสิ้นแล้วโฟกัสบนการเรียกใช้ AI workloads บน Kubernetes รวมถึง GPU scheduling และการกู้คืนจากความล้มเหลว ยืนยันตำแหน่ง Kubernetes สำหรับ production AI ([cncf.io](https://www.cncf.io/page/2/?post_type=post)) [official]

**llm-d project ประกาศ Production-Ready** — Project นี้มอบวิธีที่ง่ายสำหรับการกระจาย (distributed) inference บน GPU คล้ายกับสิ่งที่ Kubernetes ทำให้ web apps ง่าย เปิดให้ทดสอบและใช้ production แล้ว ([cncf.io — llm-d](https://www.cncf.io/page/2/?post_type=post)) [official]

**CIQ ปล่อยการแจกแจง Kubernetes สำหรับ GPU/AI (2 พ.ย.)** — CIQ เปิดตัวการแจกแจง Kubernetes ที่กำหนดค่าและเรียบร้อยสำหรับการประมวลผล AI และ GPU infrastructure ฉีกขาด bottleneck ที่ AI engineers เจออยู่เดิม ([cloudnativenow.com — container ecosystems](https://cloudnativenow.com/category/topics/container-ecosystems/)) [official]

**Salesforce อพยพ 1,000+ EKS Clusters ไปยัง Karpenter** — Salesforce ย้าย clusters จำนวนมากไป Karpenter เพื่อปรับประสิทธิภาพ scaling speed และประหยัดต้นทุน สะท้อนแนวโน้ม FinOps ในโครงสร้าง cloud ขนาดใหญ่ ([infoq.com — DevOps](https://www.infoq.com/Devops/news/)) ⚠️

→ **ภาพรวม:** Kubernetes เข้าขั้น production-ready สำหรับ AI workloads อย่างเต็มตัว llm-d + specialized distributions + Karpenter tuning สร้างผืนดินใหม่

## 🌐 Web / Frameworks / Languages

**React 19.2.8 ยังคงเป็น default framework ของ ecosystem** — ล่าสุด (ณ กรกฎาคม 2026) React 19.2.x ครองตำแหน่ง default ด้วย meta-framework support ที่เข้มแข็ง (Nuxt, Next.js) และ hiring depth ที่ลึกสุด ทำให้หรือ adoption ไม่เสียงสูบประสิทธิภาพ ([sencha.com — web frameworks](https://www.sencha.com/blog/web-application-development-top-frameworks/)) [official]

**Rust-based Rolldown bundler ถึง 1.0 (พฤษภาคม 2026) และตัดสิน Vite 8** — Rolldown bundler สร้างจาก Rust ถึง 1.0 ในพฤษภาคม 2026 และเลือกเป็น bundler engine ของ Vite 8 นำมาซึ่งการ bundling ที่เร็วขึ้นสงคราม JS ecosystem ต่อ performance ([blog.logrocket.com — frontend wrapped](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/)) [official]

**React Compiler ถ่ายเก็บ PR ระดับการทำ Rust port ใน March 2026** — React team เปิด experimental PR ที่ port logic ส่วนมากของ React Compiler จาก TypeScript ไปยัง Rust ทำให้ Rust ยิงเข้า tooling infrastructure ของ JS/TS ecosystem อย่างเต็มตัว ([blog.jetbrains.com](https://blog.jetbrains.com/en/wp-json/wp/v2/rust/671574)) ⚠️

**Topcoat framework ใหม่สำหรับ full-stack reactive apps ใน Rust (22 ก.ค. 2026)** — เปิดตัว Topcoat ซึ่งเป็น Rust framework modular สำหรับสร้าง full-stack reactive web apps ให้เป็นทางเลือกใหม่ติดกับ Leptos/Dioxus กำลัง ecosystem ของ Rust on web ([tokio.rs — Topcoat](https://tokio.rs/blog/2026-07-22-announcing-topcoat)) [official]

→ **เกี่ยวกับเรา:** Rust toolchain (Rolldown, React Compiler, Topcoat) มีผลต่อ performance-critical sections — web framework หลักเคลื่อนไป bundler/compiler ได้ faster tooling
