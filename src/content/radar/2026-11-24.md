## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37 "Garhwal" — 67 enhancements ใช้งานแล้วตั้งแต่ 26 สิงหาคม 2026** — Metrics API ถึง GA, rootless kubelet เข้าสู่ beta, HPA scale-to-zero beta และเปิด by default ([kubernetes.io — v1.37 release](https://kubernetes.io/blog/2026/08/26/kubernetes-v1-37-release/) [official])
- **ขนาด:** 23 features ขึ้นเป็น beta, 16 ขึ้นเป็น stable/GA, 1 deprecation; cluster networking เลื่อนจาก IPVS ไปยัง nftables ([InfoQ — Kubernetes 1.37](https://infoq.com/news/2026/09/kubernetes-1-37/) ⚠️)
- **เส้นทางหน้า:** Kubernetes 1.38 คาดเข้า release ประมาณ ธันวาคม 2026 ([kubernetes.dev — releases](https://www.kubernetes.dev/resources/release/) [official])

→ **เกี่ยวกับทำนายการ-tune-keycloak:** Workload-aware scheduling + nftables network performance ส่งผลบวกต่อ scale

## 🌐 Web / Frameworks / Languages

- **React Compiler เปลี่ยนมาใช้ Rust อย่างสมบูรณ์ — PR ส่งเข้า March 2026, integrated ไปยัง repository** — Meta ฉวยใช้ Rust port เพื่ออัตราเร็วโครงการ ([LogRocket — frontend wrapped H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/), [InfoQ — Rust compiler](https://infoq.com/news/2026/11/topcoat-rust-framework/) [official])
- **TypeScript 7.0 — compiler ใช้ Go แทน tsc (TS → Go transpiler)** — ประสิทธิสร้างเร็วขึ้น 8-12 เท่า, TypeScript semantic ตรงกับโรงแรม ~99% ([blog.jetbrains.com — Rust trends](https://blog.jetbrains.com/en/wp-json/wp/v2/rust/671574/), [Medium — TS 7.0 outlook](https://medium.com/@onix_react/key-web-development-trends-for-2026-800dbf0a7c8c/) ⚠️)
- **Topcoat — Rust framework full-stack เพื่อ server-side rendering และ server-driven apps** — ประกาศ 22 กรกฎาคม 2026 บน Tokio blog, แม้ว่า Leptos/Dioxus ใช้ WASM สำหรับ client-heavy, Topcoat มุ่งไปยัง MPA/server-centric ([Tokio blog — Topcoat](https://tokio.rs/blog/2026-07-22-announcing-Topcoat) [official], [The Register — Topcoat](https://www.theregister.com/a/5306470) ⚠️)

→ **ภาพรวม:** Rust ยึดครอง JS/TS tooling (compiler, linter, bundler) · React Compiler + TypeScript + Topcoat เอื้อเฟื้อการ performance · React ยังเป็นใหญ่ แต่ server-centric alternatives กำลังเติบโต
