## 🌐 Web / Frameworks / Languages

- **React 19 ตัวจริง: Server-first mental model และ automatic memoization** — ทีม React ส่งสัญญาณชัดว่า render as much as possible บน server ส่วน client ทำ hydration เท่านั้น ([DEV Community React 2026](https://dev.to/parsajiravand/react-in-2026-start-from-scratch-the-right-way-cheat-sheet-2j9f))
- **Next.js 16.2.10 เสถียรกับ React Server Components + Partial Pre-Rendering** — ต้นกรกฎาคม 2026 เล็กขึ้น larger builds บน client ด้วย server components ([Strapi Best JS Frameworks](https://strapi.io/blog/best-javascript-frameworks))
- **Angular 22 แนะนำสำหรับ enterprise ที่มี standardized architecture** — full TypeScript integration และ dependency injection ยังแข็งแกร่ง ([C# Corner Top 10 JS Frameworks](https://www.c-sharpcorner.com/article/top10-javascript-frameworks-to-watch-in-2026/))
- **TanStack Router, Svelte, SolidJS ดึงผู้เขียน (State of JS 2025)** — high-performance alternatives ทำให้การเลือก framework นี้ขึ้นอยู่กับ user experience target มากขึ้น ([Brilworks Framework Comparison](https://www.brilworks.com/blog/javascript-web-frameworks-comparison/))

→ **ภาพรวม:** React dominates แต่ server-first shift เปลี่ยนวิธีเขียน fundamentally
