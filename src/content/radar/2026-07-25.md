## 🌐 Web / Frameworks / Languages

- **TypeScript monopoly: 48.8% developers ใช้ · React Compiler stable ก่อนหน้า** [official] — TypeScript บรรลุ 48.8% adoption ในนักพัฒนา professional + 84.1% satisfaction rate (น้อยเสีย) · React Compiler v1.0 (Oct 2025) อัตโนมัติ memoization ทำให้ code manual optimization สำหรับ component ลดลง · Next.js > 130k GitHub stars ยึด React ecosystem แม้ Server Components + Server Actions ยังเป็นการยืดผ้า ([Best JavaScript Frameworks 2026](https://strapi.io/blog/best-javascript-frameworks))

- **Rust frontend + full-stack frameworks ขึ้นเหนือ** — Yew (React-inspired, CSR/SSR) · Leptos (fine-grained reactivity via signals) · Dioxus (write-once, run-anywhere: web/desktop/mobile) · Actix/Axum/Rocket backend ขอ mirror Node.js idioms ส่วน Rust on WebAssembly ถูกจริง performance (/wasm สตริงอะ) หลายทีมใหญ่บริหาร Rust web as "performance tier" ไม่ใช่ "JS replacement" ⚠️ ([Rust Web Frameworks 2026](https://medium.com/@priya.raimagiya/the-5-best-rust-frontend-frameworks-reviewed-for-2026-4694dad8f181))

→ **สถานการณ์:** TS ยังแม่นเนื่องของ app layer · Rust ยึดชั้น tooling/bundler/infrastructure ซึ่ง rolldown/SWC momentum ยังส้อ
