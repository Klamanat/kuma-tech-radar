## 🤖 AI / LLM / Agents

- **Allen Institute for AI (AI2) ปล่อย Olmo-core 3** — Infrastructure แบบเปิดสำหรับสร้าง large Mixture-of-Experts (MoE) models เมื่อ Oct 1 2026 [official] ([AI2 Olmo](https://allenai.org/)) โปรเจกต์นี้เป็นการเดิมพันว่า open-source tooling จะช่วยให้ทีมเล็กๆ สามารถ fine-tune และปรับแต่ง models ที่มีจำนวน parameters มหาศาล
- **ประมาณการ AI model releases ตลาด** — Manifold Markets แสดงตัวเลือกที่น่าจับตา เช่น Qwen 4, Claude Haiku 5.5, Gemini 4 Pro แต่เป็นการคาดเดา ไม่ใช่ยืนยัน ⚠️ ([Manifold Markets — October 2026 AI Model Releases](https://manifold.markets/prismatic/october-2026-ai-model-releases))
- **ความเข้มข้น:** สิ้นสุด Q3 ยังมี momentum ในการปล่อย coding models และ agent models ต่อเนื่อง

→ **เกี่ยวกับเรา:** Open-source infrastructure เหล่านี้เปิดโอกาสให้ทีมเตรียม custom agents

## ☸️ Cloud / DevOps / Infra

- **Kubernetes ecosystem ยังมีความเป็นสด** — CNCF จัด webinar "Modernize for the AI Era" เมื่อ Oct 14 2026 โดยโฟกัสบนการผสมผสาน AI ops กับ traditional infrastructure ([Cloud Native Now](https://cloudnativenow.com)) แนวโน้มนี้สะท้อนความเหลื่อมล้ำระหว่างการอัปเดต Kubernetes เวอร์ชันเดิมและความต้องการสนับสนุน AI workflows
- **Ingress-nginx retirement progress** — CNCF ประกาศการย้ายจาก ingress-nginx ไปที่ Envoy Gateway บน cluster ของตนเอง ([CNCF news](https://www.cncf.io/news/)) ระยะเวลา migration ยาวนาน แต่ทำให้ standards ในชุมชน unified
- **AI-assisted observability กำลังเติบโต** — April 2026 ทีม SRE 2 คน ใช้ HolmesGPT + CNCF tools เพื่อ auto-diagnose Kubernetes alerts โดยให้หลักการสำคัญ runbooks มักจะเป็นคำตอบที่สำคัญกว่าโมเดล

→ **เกี่ยวกับงาน:** Kubernetes ที่ AI-aware เป็นเป้าหมาย

## 🌐 Web / Frameworks / Languages

- **ESLint v10 ยุติการสนับสนุน legacy eslintrc** — Major version ลบการสนับสนุน `.eslintrc.*` configuration files ทั้งหมด เพื่อสนับสนุน flat config ที่มีประสิทธิภาพมากกว่า [official] ([ESLint official blog](https://eslint.org/)) ระยะเวลา transition ยาวนาน แต่จำนวนโปรเจกต์ migration เพิ่มขึ้นในเดือน Q3–Q4
- **React 19.2 และ TypeScript ecosystem ยังมีชีวิต** — State of JavaScript 2026 สรุปว่า React 19.2, Next.js 16, TypeScript 7 ยังคงเป็นมาตรฐานสำหรับ web development ([State of JavaScript 2026](https://devnewsletter.com/p/state-of-javascript-2026/)) TypeScript 7 ในรูปแบบ Go native port เพิ่ม build speedup ประมาณ 10x ตามประกาศ
- **Next.js security releases schedule ครั้งแรก** — July 2026 Next.js ประกาศการเปลี่ยนเป็นการปล่อย security fixes อย่างสม่ำเสมอทุกเดือน v16.2.11 (Active LTS) และ v15.5.21 (Maintenance LTS) ได้รับปะทะ ([Next.js Security](https://nextjs.org/docs/getting-started/security))

→ **ภาพรวม:** Web tooling คุณภาพสูงและ stable ต่อเนื่อง TypeScript ยังคง consolidate ตำแหน่ง
