## ☸️ Cloud / DevOps / Infra

- **Karmada เข้า CNCF production maturity (7 กันยายน) [official]** — CNCF ประกาศ Karmada multi-cluster, multi-cloud Kubernetes orchestration เข้า graduation ขึ้น production-ready ติดตามการขยายตัวของ AI training/inference ที่ต้อง hybrid infrastructure ([CNCF Newsroom](https://www.cncf.io/newsroom/announcements/))
- **SoftBank + Crusoe เข้า CNCF silver members (7 กันยายน) [official]** — ทั้งสองเข้าชุมชน cloud native เพื่อสร้าง cost-efficient, sovereign infrastructure ตรงกับเทรนด์ repatriate workload ไป on-premise ([CNCF Newsroom](https://www.cncf.io/newsroom/announcements/))
- **Kubeflow graduation (17 สิงหาคม) [official]** — CNCF ปล่อย Kubeflow ออกจาก incubating หลังจากเห็นใช้งานกันแพร่หลายสำหรับ automate AI/ML workflows บน Kubernetes ([CNCF Newsroom](https://www.cncf.io/newsroom/announcements/))
- **SUSE Rancher for AWS ลองให้ ⚠️** — SUSE เปิด Rancher สำหรับ Amazon EKS เพื่อทำให้ manage EKS workload ง่ายต่อ enterprises ([SUSE Solutions](https://www.suse.com/))

→ **ที่ต้องจับตา:** sovereign infrastructure และ AI automation เป็นแรงทำให้ upgrade K8s/CNCF tools

## 🌐 Web / Frameworks / Languages

- **React Compiler ไปเป็น Rust (merged June 2026) [official]** — Joseph Savona เปิด experimental PR ในมีนาคม 2026 port React Compiler จาก TypeScript → Rust ผ่านไปแล้ว ยังขั้น experimental แต่ทีม Meta ทำให้ feedback ([LogRocket](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **TypeScript 7.0 ลง GA ด้วยคอมไพลเลอร์ Go (8 กรกฎาคม) [official]** — Microsoft ทำให้ TypeScript 7.0 ด้วยคอมไพลเลอร์ Go native ตรวจ type ได้เร็วขึ้น 11.9x เทียบกับเดิม ตัด ES5 target และ AMD/UMD/SystemJS ([TypeScript Blog](https://www.typescriptlang.org/))
- **Next.js 16.3: Turbopack ลดหน่วยความจำ 90% (29 มิถุนายน) [official]** — Vercel ปล่อย Next.js 16.3 ด้วย Turbopack ที่ลดหน่วยความจำ 90% บนแอปขนาดใหญ่ production build เร็วขึ้น 5.5x ด้วย persisted cache ([ecorpit.com](https://ecorpit.com/nextjs-16-3-typescript-7-rust-go-toolchain-2026/))
- **Rust tools ครอบคลุม JS ecosystem ⚠️** — SWC, Rspack, Biome, Oxc, Turbopack พบว่า bottleneck ทั้งหมดที่ JS development มี alternative ที่ ใช้ Rust แล้ว Vite ได้ 98% satisfaction rating ([PkgPulse](https://www.pkgpulse.com/guides/rise-of-rust-in-javascript-tooling-2026/))

→ **ภาพรวม:** Rust ยึดชั้น tooling ที่ต้อง performance ใหญ่ Go/Rust compiler แทน TypeScript/V8, React ตำแหน่ง stable
