## ☸️ Cloud / DevOps / Infra

- **KubeCon North America เสร็จสิ้น 9-12 พฤศจิกายน** — งานจัดที่ Salt Lake City โดย CNCF เน้นเรื่อง Kubernetes + AI workloads [official] ([cloudnativenow](https://cloudnativenow.com/tag/leanix/))
- **AI บน Kubernetes ขยายตัว** — CIQ ปล่อย single-binary packaging ของ K8s components สำหรับ AI (2 พฤศจิกายน) · Buoyant ประกาศ open source control plane สำหรับ AI workloads (4 พฤศจิกายน) · Kubernetes ขึ้นเป็นแพลตฟอร์มหลักในวงการ AI [official] ([CNCF news](https://www.cncf.io/page/2/?post_type=post))
- **Edge + Sandbox เข้ามาแรง** — Supermicro ร่วม Red Hat/Everpure ประกาศ edge AI appliance (13 พฤศจิกายน) · AWS ปล่อย Nitro Sandboxes ให้ containers มี VM-based security boundary เป็นของตัวเอง (17 พฤศจิกายน) [official] ([cloudnativenow](https://cloudnativenow.com/category/topics/cloudnativedevelopment/kubernetes/page/18/))
- **ประสิทธิภาพ cluster** — Salesforce ย้าย 1,000+ EKS clusters ไปยัง Karpenter เพื่อเร่ง scaling · Solo.io ขยายสนับสนุนสำหรับ AI agents บน K8s (13 พฤศจิกายน) ⚠️ ([cloudnativenow](https://cloudnativenow.com/category/topics/cloudnativedevelopment/kubernetes/page/2/))

→ **ภาพรวม:** Kubernetes ไม่เพียงแต่ production orchestrator แล้ว — กลายเป็นแพลตฟอร์มหลักสำหรับ AI workloads + edge

## 🌐 Web / Frameworks / Languages

- **Topcoat: Rust web framework ชุดประสาน** — Tokio team ปล่อย v0.9 public release ของ Topcoat เฟรมเวิร์ก full-stack reactive สำหรับ Rust · server-rendered ทั้งหมด + reactivity จาก cross-compiled Rust แทน WebAssembly [official] ([tokio.rs/blog](https://tokio.rs/blog/2026-07-22-announcing-Topcoat))
- **React Compiler ไปยัง Rust** — Meta ทำการ port React Compiler จาก TypeScript ไป Rust (เปิด PR มีนาคม 2026) · ตอนนี้ integrate ลงใน React repository แล้ว ⚠️ ([blog.logrocket](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **TypeScript 7.0 ปล่อย** — Microsoft แล้ว TS 7.0 พร้อม native compiler เร่งความเร็วการ build 8x-12x · strict-by-default + ตัด ES5 target ⚠️ ([infoq](https://www.infoq.com/Web-Development/news/))
- **Remix 3 beta preview** — full-stack web framework ที่ไม่ขึ้นต่อ React แล้ว โฟกัสไปยัง web platform primitives ⚠️ ([infoq](https://www.infoq.com/Web-Development/news/))

→ **ภาพรวม:** Rust tooling ครองแต่ performance-critical layers (bundlers, compilers) · TypeScript ยังเป็นภาษาหลักของ web
