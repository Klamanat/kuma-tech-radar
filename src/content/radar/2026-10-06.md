## 🤖 AI / LLM / Agents

- **AI Labs ปล่อยโมเดลหลายแห่งในตุลา 2026** — OpenAI, Anthropic, DeepSeek, Alibaba Qwen, Moonshot, Z.ai และลูกค้อื่นๆ ส่งเสริมการแข่งขันอย่างรุนแรง ตลาดโมเดล AI ยังเร่งตัว ความเร็ว iteration cycle ของโมเดล LLM ขยับเร็วขึ้นเรื่อยๆ ([Manifold Markets — AI Lab Releases October 2026](https://manifold.markets/Bayesian/which-ai-lab-releases-an-llm-in-oct)) [official]
- แต่ละ lab โฟกัส: **Coding models, reasoning, multimodal** — ขั้นต่อ: วัดความหนาแน่นของฟีเจอร์ (reasoning depth, long-context, tool-use) มากกว่าตัวเลข parameter เพียงอย่างเดียว

→ **เกี่ยวกับเรา:** Coding agent capabilities ยังเป็นหัวข้อที่ทีม AI engineers ติดตาม อย่างใกล้ชิด

## ☸️ Cloud / DevOps / Infra

- **KubeCon Europe 2026 บันทึกสถิติใหม่: 13,500 ผู้เข้าร่วมในอัมสเตอร์ดัม** — งานประชุมซอฟต์แวร์โอเพ่นซอร์สที่ใหญ่ที่สุดในประวัติศาสตร์ Kubernetes ได้ตำแหน่งเป็น "operating system for AI" ที่แท้จริงแล้ว ([VEXXHOST KubeCon Recap](https://vexxhost.com/blog/recap-year-2019)) [official]
- **NVIDIA เข้า CNCF เป็น Platinum Member** — บริจาค GPU driver สำหรับ DRA API (Dynamic Resource Allocation) นั่นหมายความว่า Kubernetes ใจกลางของ AI infrastructure ในอนาคต
- **VMware Exit Momentum: 33% Enterprises วางแผน Migrate จาก VMs ไป Kubernetes** — EU AI Act มีผลสมบูรณ์ (สิงหาคม 2026) ขับเคลื่อนให้เลือก sovereign AI on Kubernetes layer ⚠️ ([Enterprise Modernization Trends](https://letsdatascience.com/news/enterprises-embrace-kubernetes-to-modernize-infrastructure-edcf9741))

→ **เกี่ยวกับงาน tune-keycloak:** Infrastructure layer ต้องเตรียม DRA + GPU scheduling เพื่อรองรับ AI workload ในอนาคต

## 🌐 Web / Frameworks / Languages

- **React Compiler Rust Port เสร็จสมบูรณ์ (Merged June, Stable in October)** — TypeScript-to-Rust port ของ React Compiler merge แล้ว รักษาสถาปัตยกรรม compiler เดิม (HIR, CFG, SSA) ทำให้ optimization ที่ Meta ทำได้นำไปใช้ได้อย่างมีประสิทธิภาพ ([LogRocket Frontend Wrapped H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/)) [official]
- **TypeScript 7.0 ใช้ Go Compiler** — Public beta ปลายตุลา Go compiler เพิ่มความเร็วขึ้นอย่างมีนัยสำคัญ performance gain ที่มากขึ้นจาก traditional TS compilation
- **Rust ยึดชั้น tooling สำหรับ performance-critical paths** — React Compiler, Rolldown, สกปรกเล็กๆ ทั้ง ecosystem บริเวณ build/optimization

→ **ภาพรวม:** Rust ไล่ออก JavaScript tooling ที่ต้องการ raw speed; TS ยังคง application logic หลัก แต่ compilation/optimization ผลักไป Rust/Go

- **Fundraising trend:** Series A/B ยังสนใจ โซลูชัน edge AI + compliance ที่คู่หูใจกลาง
