## ☸️ Cloud / DevOps / Infra

**Kubernetes 1.37 release หลัง DRA ยิงเข้า GA** — Dynamic Resource Allocation ยิง General Availability หลังจาก 3 releases ต่อ ๆ กัน, สำหรับ GPU/hardware allocation ตามระบบ [official] ([kubernetes.io — Release Notes](https://kubernetes.io/releases/))

**API autoscaling down to zero replicas เข้า Beta** — Kubernetes 1.37 รองรับ horizontal autoscaling เก็บลงเหลือ zero replicas (cost savings สำหรับ bursty workloads), enable by default [official] ([Kubernetes Blog](https://kubernetes.io/blog/))

**etcd RangeStream graduating to beta** — วอช support for pagination/streaming ใหม่ เพื่อแก้ problems กับ large-scale data sync ([State of DevOps 2026](https://devnewsletter.com/p/state-of-devops-2026/))

**CNCF Certified Kubernetes AI Conformance Program launched** — คณะตั้งมาตรฐาน AI/ML workload execution ลงบน K8s, ทำให้ reproducibility และ vendor interop แน่นขึ้น ⚠️ ([Kubernetes 2026 Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

**Platform Engineering แทน DevOps — reduces cognitive load** — เรื้องนี้ 2026 ใหญ่แล้ว, องค์กรต่างหัน platform engineer มากกว่า ops engineer ไปหมด ⚠️ ([Beyond YAML in Kubernetes](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))

→ **ภาพรวม:** K8s เป็น default OS for AI แล้วตอนนี้, ที่จะเวิร์คต้องระบบ platform engineering ที่หนึ่ง

## 🌐 Web / Frameworks / Languages

**Rolldown bundler (Rust) 1.0 ใน May — ยึด Vite 8 แล้ว** — Rolldown (Rust rewrite ของ Rollup/esbuild) มา 1.0 ในเดือน 5 แล้ว, กำลังขับ Vite 8 เสถียรตั้งแต่ March 2026 [official] ([Meta React Compiler to Rust — InfoQ](https://www.infoq.com/news/2026/07/meta-react-compiler-rust/))

**Vite builds ขึ้น 10-30x ที่เคย Rollup** — performance jump แบบนี่หา JavaScript bundler ไม่เจอ, Vite ได้ 98% dev satisfaction เทียบ Webpack 37% negative sentiment [official] ([Best Web Development Tools 2026](https://www.rudrainnovative.com/blog/web-development-tools-frameworks/))

**TypeScript adoption 48.8% professional devs** — StackOverflow 2025 survey บอก, 58% current users admire it — ภาษา default ของ app layer ยังเป็น TS/JS ตามเดิม ([6 Best JavaScript Frameworks 2026](https://strapi.io/blog/best-javascript-frameworks))

**React Compiler merge ไป Rust port** — Meta ผลัก React Compiler จาก TypeScript → Rust เสร็จแล้ว, ทำให้ integration กับ Rust toolchain แน่น ทำให้ build ขึ้นเร็ว ([Meta React Compiler to Rust — InfoQ](https://www.infoq.com/news/2026/07/meta-react-compiler-rust/))

**Rust web frameworks เก็บตั้ง: Leptos, Dioxus, Yew, Actix Web, Axum** — Leptos ให้ fastest UI ที่สุด + SSR for SEO, Dioxus เพื่อ cross-platform React devs, Yew ขนาดใหญ่ community support ⚠️ ([5 Best Rust Frontend Frameworks 2026](https://medium.com/@priya.raimagiya/the-5-best-rust-frontend-frameworks-reviewed-for-2026-4694dad8f181))
