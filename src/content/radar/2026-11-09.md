## ☸️ Cloud / DevOps / Infra

- **KubeCon NA 2026 เริ่มวันนี้** — Salt Lake City, 9–12 พฤศจิกายน 2026, ศูนย์กลางของ CNCF ecosystem ความจำเป็นอย่างรีไลเบิลต์ [official] ([CNCF Events](https://www.cncf.io/events/kubecon-cloudnativecon-north-america-2026/))
- **CIQ Stratum Kubernetes Engine** — บรรจุ AI-related K8s components เข้าไบนารี่เดียว พร้อม GPU scheduling improvements [official] ([CloudNativeNow](https://cloudnativenow.com))
- **KubeVirt v1.8 ประกาศแล้ว** — คนโฮสต์ KVM virtualization บน Kubernetes เวอร์ชัน v1.8 ขยายขีดความสามารถ [official] ([Kubernetes.io](https://kubernetes.io))
- **Gateway API migration** — ingress-nginx กำลังเลิกใช้งาน (March 2026) ขอให้เปลี่ยนไปใช้ Gateway API ⚠️ ([Kubernetes Gateway API](https://gateway-api.sigs.k8s.io/))

→ **ภาพรวม:** AI meets infrastructure ที่ KubeCon; GPU scheduling และ virtualization เป็นจุดเด่น

## 🌐 Web / Frameworks / Languages

- **TypeScript 7 เขียนใหม่ด้วย Go** — Microsoft ประเมินว่า build เร็ว 10x และใช้หน่วยความจำน้อยกว่า; TS 6 เป็นขั้นเตรียม ⚠️ ([Devnewsletter — State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/))
- **Astro 6 Beta ออกแล้ว** — Server ปรับปรุงด้วย Vite Environment API, Cloudflare Workers support, live content collections เสถียรแล้ว ⚠️ ([Astro Blog](https://astro.build))
- **Vue Router 5.0 รวม unplugin-vue-router** — ไฟล์ routing เจาะลึก TypeScript support บรรเทาการดำเนินการแพ็คเกจ [official] ([Vue Router](https://router.vuejs.org))
- **Signals แพร่หลายผ่าน ecosystems** — Angular, Vue, Solid, Svelte ใช้ fine-grained reactivity; React ยังครอบครอง market (ใช้ 15x มากกว่า Vue) ⚠️ ([State of JavaScript 2025](https://devnewsletter.com/p/state-of-javascript-2026/))

→ **ภาพรวม:** TypeScript 7 Go-rewrite + Astro 6 performance focus = คลั่งไคล้ performance; Signals กระบวนการถูกยืดยาว
