## ☸️ Cloud / DevOps / Infra

- **Kubernetes เป็น OS ชั้นต้นสำหรับ AI workloads** — MLOps platforms เป็น heaviest workload ใน K8s 2026 ตัวอย่าง: bursty, resource-intensive Jobs (training/processing) + high-volume Services (real-time inference) ต้อง orchestration ที่ smart ([fairwinds — K8s playbook 2026](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- **Platform Engineering แทน DevOps** — ประมาณ 80% องค์กรใช้ IDP (Internal Developer Platforms) แล้ว ขึ้นจาก 45% ปีก่อน เป้าคือลด cognitive load ของ dev ด้วย self-service infrastructure ([pulumi — beyond YAML](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/)) ⚠️
- **Serverless containers + Multi-cloud trend** — Deploy services บน K8s โดยไม่ต้องกังวล underlying infra, หลายทีม ใช้ hybrid/multi-cloud architectures ([loginline — K8s trends](https://www.loginline.com/en/blog/2026-kubernetes-trends))

→ **ภาพรวม:** AI เป็น first-class workload ใน Kubernetes, tooling เปลี่ยนจาก DevOps → Platform Engineering

## 🌐 Web / Frameworks / Languages

- **React 19.2 + React Compiler 1.0 stable** — React Compiler ออก Oct 2025 ทำให้ memoization automatic โดยไม่ต้องแตะด้วย manual hooks, 48.8% professional developers ใช้ TypeScript แล้ว (satisfaction 84.1%) ([strapi — best frameworks 2026](https://strapi.io/blog/best-javascript-frameworks)) [official]
- **Rust web frameworks แข่งชิงที่ tooling** — Actix, Axum, Rocket, Warp, Loco, Leptos เติบโต, Yew (Rust frontend) มี 30k+ GitHub stars + 4M+ crates.io downloads, บ่งชี้ WebAssembly ยังเป็น trend ([medium — Rust frontend frameworks 2026](https://medium.com/@priya.raimagiya/the-5-best-rust-frontend-frameworks-reviewed-for-2026-4694dad8f181))
- **rolldown bundler: build ~100x เร็วขึ้น** — บางทีม build time ลดจาก 2.5 นาที → 40 วิ ด้วย Rust-based bundler แทน esbuild/Rollup, ขยายมากขึ้นเป็น default ใน Vite ecosystem ([jetbrains — Rust vs TS/JS](https://blog.jetbrains.com/rust/2026/01/27/rust-vs-javascript-typescript/)) ⚠️

→ **ภาพรวม:** Rust ยึดชั้น tooling ที่ต้อง performance, React + TS ยังคงแข็งแรง ใน application layer
