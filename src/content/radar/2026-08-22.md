- **Multimodal เป็นมาตรฐาน** — ทุกรีลีสใหม่รองรับ text/image/video ได้แล้ว ([llm-stats.com/llm-updates](https://llm-stats.com/llm-updates)) **Meta Llama 4** (open-source standard-setter) มี context window 10M token พร้อม MoE multimodal native ⚠️ ตลาด AI เชื่อและทำให้ค่ายต่างแยกชัดขึ้น

## ☸️ Cloud / DevOps / Infra

- **Kubernetes = OS สำหรับ AI แล้ว** — ไม่ใช่แค่ container orchestrator อีกต่อไป ([CNCF Blog](https://www.cncf.io/blog/2026/01/19/top-28-kubernetes-resources-for-2026-learn-and-stay-up-to-date/)) 84% ขององค์กรใช้ containerized apps พร้อม K8s ([fairwinds — 2026 playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth)) MLOps workloads (bursty training jobs + high-volume inference services) ข่มเก่าคิว

- **Internal Developer Platforms (IDPs) เป็นมาตรฐาน** — 80% ขององค์กรจะมี IDP ปี 2026 เพื่อซ่อนความซับซ้อนของ K8s ([Pulumi Blog — beyond YAML](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/)) ⚠️ จากแค่ 45% เมื่อสองสามปีที่แล้ว

- **AI-powered DevOps tools** — รุ่นใหม่ไม่ใช่แค่รายงานอาการแต่แก้ปัญหาอัตโนมัติแล้ว ([Fairwinds — self-healing](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth)) AWS เลิก EKS auth method แต่ยัง 81% cluster ใช้อยู่ ⚠️ ([DevOps news Aug 20](https://shyam.kubeify.com/2026/08/latest-devops-cloud-news-20-august-2026.html))

→ **ภาพรวม:** K8s + AI ไป-ไม่ได้แยก, IDP ถัดไป = DevOps competitive advantage

## 🌐 Web / Frameworks / Languages

- **React 19.2 Compiler — optimize ให้ 25-40% ของ re-render** [official] ([Nucamp — React trends 2026](https://www.nucamp.co/blog/javascript-framework-trends-in-2026-what-s-new-in-react-next.js-vue-angular-and-svelte)) React Server Components ลดเวลา render จาก 2.4 วิ → 0.8 วิ ⚠️ ([Strapi — best frameworks 2026](https://strapi.io/blog/best-javascript-frameworks))

- **TypeScript กลายเป็นมาตรฐาน** — 40% ของ dev ใช้ TS exclusive, แค่ 6% เลือก plain JS exclusive ([Nucamp — frameworks 2026](https://www.nucamp.co/blog/javascript-framework-trends-in-2026-what-s-new-in-react-next.js-vue-angular-and-svelte)) plain JS ถือว่าทำให้ legacy ไปแล้ว

- **Vite ขนาด 98% dev satisfaction** — หลังจาก Webpack (37% negative sentiment) ([Brilworks — frameworks comparison](https://www.brilworks.com/blog/javascript-web-frameworks-comparison/)) ⚠️ อาจหมายถึง Webpack มี pain point สูง ส่วน Vite smooth

- **4 ธีมบรรจบ:** fine-grained reactivity + server-first rendering + compiler-driven optimization + AI-assisted workflows ([Alphonso Labs — 12 trends 2026](https://www.alphonsolabs.com/web-development-trends-2026/))

→ **ภาพรวม:** TypeScript baseline, React Compiler ผลิต value, Vite ชนะ developer experience
