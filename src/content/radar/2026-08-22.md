## ☸️ Cloud / DevOps / Infra

- **Kubernetes เป็นปล้องหลักของ AI — 84% ขององค์กรใช้ K8s ในการผลิต** — K8s ไม่อีกแค่ container orchestrator แล้ว มันกลายเป็น default operating system สำหรับ AI workloads ร่วมกับ microservices และ edge applications ([fairwinds.com/blog/2026-kubernetes-playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

- **Platform Engineering แทน DevOps — 80% ขององค์กรจะนำมาใช้ในปี 2026** — แนวโน้มเปลี่ยนจากโครงสร้างดั้งเดิม DevOps ไปสู่ Platform Engineering เพื่อลด cognitive load ให้กับนักพัฒนา ([pulumi.com/blog/beyond-yaml-kubernetes-2026](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era))

- **AWS deprecated EKS auth method — 81% ของ clusters ยังใช้อยู่** — เตือนเรื่องการบำรุงรักษากรรมสิทธิ์เดิมในโครงสร้างพื้นฐานที่มีอยู่ ([kubeify.com/2026/08/latest-devops-cloud-news](https://shyam.kubeify.com/2026/08/latest-devops-cloud-news-20-august-2026.html) ⚠️)

→ **เกี่ยวกับงาน tune-keycloak:** K8s-native identity management ร่วมกับ AI-powered governance มาเป็นอกุณภาพของพระ

## 🌐 Web / Frameworks / Languages

- **TypeScript ครองตลาด 48.8% ของนักพัฒนา ความพึงพอใจ 84.1%** — TypeScript กลายเป็นภาษาที่ใช้มากที่สุดใน GitHub (โดยนับจำนวน contributors) ตั้งแต่ August 2025 ลำดับความชอบเพิ่มขึ้นต่อเนื่อง ([jetbrains.com/rust/2026/01/27](https://blog.jetbrains.com/rust/2026/01/27/rust-vs-javascript-typescript/))

- **React Compiler v1.0 — 12% faster initial load, 2.5x faster interactions** — ออก October 2025 ปัจจุบัน Meta ใช้งาน production แล้ว react-compiler ช่วยจัดการ component memoization โดยอัตโนมัติ React 19.2 เพิ่มปรุง server rendering ⚠️ ([coderio.com/blog/software-development/guide-frontend-frameworks-2026](https://www.coderio.com/blog/software-development/guide-frontend-frameworks-2026))

- **Rust frameworks นำสนาม tooling — Axum, Actix Web, Rocket, Warp, Salvo** — Yew (Rust frontend) มี 30,000+ GitHub stars, 4M+ downloads บน crates.io เหล่านี้แทน JavaScript bundlers ในเคสที่ต้องความเร็ว ([medium.com/@priya.raimagiya/the-5-best-rust-frontend](https://medium.com/@priya.raimagiya/the-5-best-rust-frontend-frameworks-reviewed-for-2026-4694dad8f181))
