## 🤖 AI / LLM / Agents

- **Claude Sonnet 5 ตัวโมเดลเอเจนต์** [official] — Anthropic เปิดตัว Claude Sonnet 5 พร้อมความสามารถเอเจนต์ (tool use เช่น browser, terminal) ที่ต้นทุนต่ำกว่า Opus 4.8 ชนิดพิมพ์เดียว เหมาะสำหรับการใช้งานสินค้า ([Anthropic announces Claude Sonnet 5](https://www.anthropic.com/research/claude-sonnet-5))

- **โมเดล AI ออกทุก 3 วัน ต่อเนื่อง** — ตลาด AI ร้อนดำเนิน OpenAI เปิดตัว GPT-5.6 Luna, Terra, Sol (9 ก.ค.), Meta ปล่อย Muse Spark 1.1, xAI ออก Grok 4.5, NVIDIA ยิงเอา nvDock (8 ก.ค.) โมเดลใหม่ถึง ~ทุก 3 วัน ([LLM News July 2026](https://llm-stats.com/ai-news))

- **Cursor ยึดเอาเจนต์ "Sand" สำหรับ non-developers** — บริษัท Cursor กำลังพัฒนา AI agent ชื่อ Sand ที่จัดการอีเมล เอกสาร ข้อความ สำหรับผู้ที่ไม่มีทักษะโค้ด ([Cursor AI agent Sand](https://www.cursor.sh/blog/sand-agent))

- **Andrej Karpathy นำ AI ทดลอง 700 ครั้ง ใน 2 วัน** — นักวิจัยแอนด์เรจ การปัตยหลักเดินดำเนินการ experiments อิสระผ่าน AI agent ได้ประสิทธิผลเร่ง training 11% ([AI Research — Autonomous Experiments](https://karpathy.ai/research/autonomous-ml))

→ **เกี่ยวกับเรา:** Tool use + agent pattern ของ Claude Sonnet 5 แรงกว่า ใช้งานได้ถนัด ส่วน Cursor Sand สำหรับ user ธรรมชาติ

## ☸️ Cloud / DevOps / Infra

- **Kubernetes ถึง 93% adoption ใน enterprise** [official] — CNCF รายงาน 93% ขององค์กร ใช้/test/study Kubernetes อยู่ 80% วิ่ง production แล้ว ([CNCF Kubernetes Adoption Survey July 2026](https://www.cncf.io/reports/kubernetes-adoption))

- **Serverless 2.0: Wasm-based ไร้ cold start** — เทรนด์ใหม่รวม containerization + on-demand scaling โดย Wasm-based serverless เอาชนะปัญหา cold start ส่วน Knative ยืนยันว่าเป็นมาตรฐาน serverless on Kubernetes ([Serverless 2.0 Architecture 2026](https://dev.to/serverless-blog/serverless-2-0-wasm))

- **Hybrid cloud dominance: K8s core + serverless edge** — ค่าใช้ Kubernetes ถูกกว่า 46% ในสเกล 50M requests/month แต่องค์กรเลือก hybrid: serverless ขอบ (edge) + Kubernetes จุดหลัก (core) ([Kubernetes vs Serverless Cost 2026](https://techcrunch.com/2026/07/kubernetes-vs-serverless-cost/))

→ **ลำแหน่ง:** Kubernetes แน่น hybrid approach เหนือ pure serverless โจทย์คือ manage edge + core พร้อมกัน

## 🌐 Web / Frameworks / Languages

- **TypeScript 7.0 GA: คอมไพเลอร์เขียน Go เร็ว 10x** [official] — Microsoft เปิดตัว TypeScript 7.0 (8 ก.ค.) ด้วยคอมไพเลอร์เขียนใหม่เป็น Go (Project Corsa) VS Code codebase build เพิ่มขึ้น 125 วิ → 10.6 วิ breakthrough ([TypeScript 7.0 Release](https://www.typescriptlang.org/blog/announcing-typescript-7-0/))

- **TypeScript 7.0 warning: API unstable ⚠️** — เวอร์ชัน GA ยังไม่มี stable programmatic API Vue/Svelte/Astro/Angular with templates ควร รอ TypeScript 7.1 (คาดตุลา 2026) ([TypeScript 7.0 Known Issues](https://github.com/microsoft/TypeScript/issues/60621))

- **Next.js 16.3: dev memory -90%, build 5.5x faster** [official] — Vercel ปล่อย Next.js 16.3 (29 มิ.ย.) Turbopack dev-server ลดหน่วยความจำ 90% large apps + build production เร็ว 5.5x เพราะ persisted cache + React Compiler Rust port ([Next.js 16.3 Release](https://nextjs.org/blog/next-16-3))

- **Build tools trend: Biome 56x ESLint, Bun → Rust** — Vite dominant 84M weekly downloads, TypeScript adoption 78%, React Server Components 45% new projects, Bun acquired by Anthropic rewrite Rust, Biome replace ESLint at 56x speed ([State of JS 2026](https://devnewsletter.com/p/state-of-javascript-2026/))

→ **ไทย-go-ism:** TypeScript 7.0 Go compiler ช่วยใหญ่ build time แต่ API stability expect รอสัปดาห์หน้า · Rust takeover build tooling (Biome, Bun, Turbopack) ต่อ
