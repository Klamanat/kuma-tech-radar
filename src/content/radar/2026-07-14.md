- **OpenAI GPT-5.6 Luna, Terra, Sol ออกจริง** — GPT-5.6 ได้ release 9 กรกฎาคม 2026 เป็นไปตามแผน mid-July สำหรับ general availability (GA) หลังจากการปล่อยตัว 26 มิถุนายน ลูกค้าสามารถเข้าถึงได้กว้างขึ้นในสัปดาห์นี้ ([llm-stats — ai-news](https://llm-stats.com/ai-news)) [official]
- **Anthropic Claude Sonnet 5 และ Fable 5** — Claude Sonnet 5 release 30 มิถุนายน 2026 ส่วน Fable 5 (Mythos-class frontier) แสดงอักษรกระโดด benchmark ที่ราว 2x ค่า Opus models ทีมอัพเกรด API ยิ่งกำลังขยาย capability multimodal ([best-ai-models](https://www.buildfastwithai.com/blogs/best-ai-models-july-2026-ranked)) [official]
- **Meta Muse Spark 1.1 และ xAI Grok 4.5** — Meta พลิก Muse Spark 1.1 วันที่ 9 กรกฎาคม ส่วน xAI ปล่อย Grok 4.5 วันที่ 8 กรกฎาคม ทั้งคู่โฟกัสเข้มเรื่อง multimodal (image, video, mixed media) การแข่งขันในตลาด LLM สูงขึ้นตรง capability แทนแค่ performance ([buildfastwithai](https://www.buildfastwithai.com/blogs/best-ai-models-july-2026-ranked)) [official]
- **Google Gemini 3.5 Flash ตำแหน่ง production-friendly** — Gemini 3.5 Flash ปรับตัวให้เป็น fast และ lightweight สำหรับ production workload แบบไม่ต้องแลก latency กับ quality เกินไป ใช้ที่ production ที่ Google แล้ว ([llm-updates](https://llm-stats.com/llm-updates)) [official]

## ☸️ Cloud / DevOps / Infra

- **etcd v3.7.0 เชิญ RangeStream feature** — etcd ปล่อยรุ่น 3.7.0 วันที่ 8 กรกฎาคม โดยมีการมาของ RangeStream feature ที่คร่านขอมานาน ช่วย Kubernetes cluster scale มหาศาล โดยลด memory footprint และ query latency กว่า ก่อนหน้าหลายเท่า ([kubernative-digest](https://faun.dev/co/stories/shurup/kubernative-software-digest-july-10th-2026/)) [official]
- **Google GKE Labs ปล่อย OpenRL สำหรับ fine-tune LLM on Kubernetes** — OpenRL ให้ API self-hosted อันช่วย post-training และ fine-tune LLM บนมาตรฐาน Kubernetes cluster ไม่ต้องใช้ managed cloud ข้อมูล k3s edge clusters ~34% ของ deployments ปัจจุบัน ทำให้ edge AI on K8s ออกโปรดกว่า ([cloud-native-now](https://cloudnativenow.com/contributed-content/cloud-natives-interest-payment-just-came-due/)) [official]
- **CloudNativePG 1.30.0 declarative database role management** — CloudNativePG กระโดดไปที่ 1.30.0 โดยใส่ declarative role management สำหรับ PostgreSQL บน Kubernetes ลดความซับซ้อนในการจัดการ RBAC พร้อม Dragonfly v2.5.0 ที่มี rate limiting ดี ๆ ([k8s-news](https://www.infoq.com/Kubernetes/news/)) [official]
- **Kubernetes adoption plateau ~68% แต่ edge scaling ขึ้น** — K8s production workload ติด 68% ลดจากปีก่อน เพราะ serverless container (Cloud Run, Container Apps, Fargate) ยิ่งดึงเอา ส่วน edge distribution ~34% ใช้ K3s บน Raspberry Pi และ NVIDIA Jetson ทำให้ infrastructure multi-target ([devopsdigest](https://www.devopsdigest.com/2026-container-predictions)) ⚠️

→ **เกี่ยวกับงาน tune-keycloak:** OpenRL + fine-tune LLM on edge K8s cluster มีโอกาสเช่นเดียว สำหรับ lightweight identity + AI model ร่วม

## 🌐 Web / Frameworks / Languages

- **TypeScript 7.0 ออกจริง บน Go compiler** — TypeScript 7.0 ประกาศ GA วันที่ 8 กรกฎาคม 2026 เปลี่ยน compiler ไป Go native ทำให้ type-check เร็วขึ้น **11.9x** ตัว tsc binary default แล้วใช้ Go version ทำให้ adoption smooth ส่วนมากทีม ([announcing-typescript-7](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/)) [official]
- **Next.js 16.3 Turbopack ประหยัด memory, build เร็ว 5.5x** — Next.js 16.3 ประกาศ 29 มิถุนายน 2026 พลิก Turbopack dev-server memory ลดได้ถึง 90% บน large app production build ปรับปรุง 5.5x ด้วย persistent cache ทดลองเพิ่ม Rust port ของ React Compiler ([next-16-3](https://ecorpit.com/nextjs-16-3-typescript-7-rust-go-toolchain-2026/)) [official]
- **React Server Components (RSC) มาตรฐาน production** — React Server Components เลิกเป็น experimental ณ ปี 2026 component default run on server เว้นแต่ "use client" directive ใช้อยู่ production แล้ว React 19 stable ยิ่ง auto-memoization ลด manual tuning ([react-trends](https://dev.to/parsajiravand/react-in-2026-start-from-scratch-the-right-way-cheat-sheet-2j9f)) [official]
- **Biome Rust formatter/linter แทน ESLint + Prettier** — Biome ลันเรือ Rust-based formatter/linter ดึง ESLint + Prettier เข้ามาเป็นเครื่องมือเดียว adoption เพิ่มขึ้นอย่างเห็นได้ชัด ค่ายที่ต้องการ performance-first tooling มองไป Biome + pnpm combo ([javascript-stack](https://www.javascriptdoctor.blog/2026/05/the-javascript-stack-in-2026-what-every.html)) [official]

→ **ภาพรวม:** ตลาด JS tooling ไหลไป Rust/Go compiler เพื่อ performance; TypeScript ยังคง domain language ที่ใหญ่ที่สุด; Next.js/React ใช้ Server-first architecture มาตรฐาน
