## 🌐 Web / Frameworks / Languages

- **TypeScript 7.0 Go Compiler** — TypeScript compiler เขียนใหม่ด้วย Go เปิดตัว 8 กรกฎาคม 2026 ประสิทธิภาพกระโดด: VS Code codebase type-check จาก 125.7 วิ → 10.6 วิ (เร็วขึ้น ~12x) ⚠️ ([besthub.dev — 2026 toolchain](https://www.besthub.dev/articles/2026-frontend-toolchain-rewritten-in-go-and-rust-what-changed-7c3c338ba937))

- **Vite 8 Default Rolldown** — Vite 8 เปลี่ยน bundler เป็น Rolldown (Rust-based) เป็น default และเพิ่ม built-in tsconfig path support ทำให้ build performance ดีขึ้นกว่า esbuild/Rollup เดิม ([buttondown.com — JEM newsletter](https://buttondown.com/agney/archive/jem-web-in-march-javascript-every-month-newsletter-2031/))
- **Deno 2.8 & Bun Rust Rewrite** — Deno 2.8 ปล่อยพร้อม TypeScript และ ESM improvement; Bun ทำการ merge PR สำหรับ experimental Rust rewrite เพื่อ improve compatibility ([dev.to — JSDev Space](https://dev.to/feed/jsdevspace))

→ **สรุป:** Go/Rust dominant ใน tooling layer ที่ต้อง performance; JavaScript application-layer ยังเด็กเด่น
