## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37 RC0 ออกแล้ว — เตรียม production ต้นเดือนกันยายน** — ประกาศรวม Pod eviction coordination (WASM support), service account token binding, CompositePodGroup, จำนวน API และ kubelet improvements; release เต็มตัว target Sept ([Releasebot — Kubernetes August](https://releasebot.io/updates/kubernetes)) [official]
- **RapidFort extend runtime security — Black Hat USA ประกาศ** — ขยายเครื่องมือให้ cover open source runtime ใน production (นอกเหนือ container image); ปัญหา AWS: deprecated EKS auth method แล้ว แต่ยัง 81% clusters ใช้เก่า ([Black Hat USA 2026 conference](https://www.blackhat.com/us-26/)) ⚠️
- DevOps automation เข้ายุค "beyond YAML" — infrastructure-as-code + policy enforcement + AI-driven orchestration ทำงานร่วมกัน; K8s adoption ขึ้น 66% (2023) → 82% (2026) ของ container teams ([Pulumi — Beyond YAML Kubernetes 2026](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/)) ⚠️

→ **แนวโน้ม:** legacy method deprecation ต้องเตรียม, automation + AI orchestration เป็นฮิต

## 🌐 Web / Frameworks / Languages

- **Next.js ครองตำแหน่ง React meta-framework ยอดนิยม** — App Router + React Server Components + Edge Functions ร่วมให้ production-grade performance; Astro เชี่ยวชาญ content sites ที่ไม่ต้อง JS overhead ([Strapi — Best JavaScript Frameworks 2026](https://strapi.io/blog/best-javascript-frameworks)) ⚠️
- **TypeScript adoption เพิ่มขึ้นครอบทั้ง stack** — ทีมเลือก TS เพื่อ refactoring safety, onboarding speed, และ reliability ของ AI-assisted coding; @types/react maintained by community ให้ support เต็มที่ ([MindPath Tech — ReactJS Trends 2026](https://www.mindpathtech.com/blog/reactjs-trends/)) ⚠️
- **Svelte (15KB) และ SolidJS (7KB) มี momentum ใน SPA ที่ต้อง performance** — lightweight bundling ติดตามอยู่เพื่อโปรเจกต์ที่ต้องความเร็ว; React อย่างไรก็ยังครองชั้น ([Focusreactive — React Frameworks 2026](https://focusreactive.com/blog/react-frameworks-to-use/)) ⚠️

→ **ความสำคัญ:** TypeScript ขึ้นจาก style เป็น architecture decision; Next.js กำหนดเทรนด์ production React
