## 🌐 Web / Frameworks / Languages

- **React Compiler v1.0 ยังร้อน** — ออก Oct 2025 ([React Blog](https://react.dev/blog/2025/10/07/react-compiler-1)) auto-memoization ไม่ต้องจำ developer ต้อง optimize เอง, production-ready สำหรับทีมใหญ่แล้ว
- **React Server Components ตัด client JS** — แบบลืม ส่ง HTML+data จาก server หนึ่งไป client, Vercel case studies: 70% TTFB เร็วขึ้น, server cost 40% ลด ⚠️ ([Strapi — Best JS Frameworks 2026](https://strapi.io/blog/best-javascript-frameworks))
- **TypeScript ครองใจ 48.8% pro devs** — satisfaction 84.1% ([State of JS 2026](https://blog.jetbrains.com/rust/2026/01/27/rust-vs-javascript-typescript/)), ยังเป็น lingua franca ของ application tier
- **Rust ถูกทำให้ frontend-friendly** — Leptos แนะนำ for 2026 new projects (server-side rendering + fine-grained reactivity), Yew ยังแกร่ง (30K+ stars, 4M+ crates.io DL) ([Medium — 5 Best Rust Frontend](https://medium.com/@priya.raimagiya/the-5-best-rust-frontend-frameworks-reviewed-for-2026-4694dad8f181))

→ **ภาพรวม:** TypeScript ยึดแอพ, Rust ยึด build tooling, React Server Components ลดจำนวนผู้ใช้ JS บน client
