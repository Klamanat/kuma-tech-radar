## ☸️ Cloud / DevOps / Infra

- **Kubernetes 1.37 shipped** — เปิดตัวปลายกันยายน 2026 พร้อม 67 enhancements [official]; DigitalOcean ใช้ K8s 1.37.0 ตั้งแต่ 8 ตุลาคม กับ Cilium 1.20 และ containerd 2.3.3 [official] ([DigitalOcean changelog](https://docs.digitalocean.com/products/kubernetes/details/changelog/))
- **Amazon EKS Cluster Control-Plane Rollbacks** — ปล่อยความสามารถ revert ได้ภายใน 7 วันหลังจาก upgrade ลดความเสี่ยงของการทำให้ cluster ชำรุด [official] ([AWS EKS releases](https://docs.aws.amazon.com/eks/latest/userguide/kubernetes-versions.html))
- **Docker Desktop 4.95.0 + Docker Cloud Sandbox Kit** — update stability มี fix สำหรับ image pull timeout; Sandbox Kit launched ประมาณ 1 ตุลาคม เป็น portable OCI artifact สำหรับ agent permissions [official] ([Futurum — Docker](https://futurumgroup.com/insights/))
- **Azure Container Apps Express GA + Cloudflare disclosure** — microVM sandbox layer ตัวใหม่ available; Cloudflare Containers เกิด cross-tenant data exposure (fixed, no exploitation evidence) ⚠️ ([Azure announcements](https://azure.microsoft.com/en-us/updates/))

→ **ภาพรวม:** K8s 1.37 + rollback capability เป็น game-changer สำหรับ production reliability

## 🌐 Web / Frameworks / Languages

- **React 19.3.0 + Next.js 16.4.0** — React release 9 กันยายน, Next.js 16.4 ออก 7 ตุลาคม กับ stable features; React ยังครองตลาด ~45% ใช้งาน [official] ([react.dev](https://react.dev), [nextjs.org](https://nextjs.org))
- **Framework Landscape ตุลาคม 2026** — React ยังเป็นทางเลือก default สำหรับ ecosystem breadth; Next.js ครอง full-stack React; Vue + Svelte + Astro นิชเพิ่มขึ้น; Angular ใจ enterprise ⚠️ ([guideflow blog](https://www.guideflow.com/blog/javascript-frameworks))
- **TypeScript universal** — ทุก major framework รองรับ TypeScript ลึก; ความสำคัญของ type safety ยืนแน่นในโปรแกรมโลก [official] ([Stack Overflow 2026](https://survey.stackoverflow.co/))

→ **เทรนด์:** React + Next.js + TypeScript ครองตลาด; tooling Rust (rolldown, swc) เด่นกำลัง
