## ☸️ Cloud / DevOps / Infra

→ **ภาพรวม:** Cloud infrastructure เข้า inflection point ที่ AI orchestration ชิด infra layer มาก; multi-cloud เป็น norm ตอนนี้

## 🌐 Web / Frameworks / Languages

- **Rolldown bundler (Rust) ถึง 1.0 พฤษภาคม 2026, ตอนนี้ power Vite 8 stable** — Build ลดจาก minuto หลายนาทีเหลือ 40 วิ ได้; 10-30x ความเร็วเทียบ Rollup, esbuild ([JetBrains Rust Blog](https://blog.jetbrains.com/rust/2026/01/27/rust-vs-javascript-typescript/)) [official]
- **React Compiler ฉบับ Rust เร็ว 3x เทียบ TypeScript version, logic บางส่วนขึ้นไป 10x** — Meta port React Compiler เขียนหลัก logic จาก TS → Rust ช่วย AI; isolation transformation หลายโปรแกรมลพั้น faster ([InfoQ](https://www.infoq.com/news/2026/07/meta-react-compiler-rust/)) ⚠️
- **Leptos (Rust web framework) ถึง 1.0 stable late 2025** — Rust web frameworks (Actix Web, Rocket, Leptos) ผลักดัน memory safety + performance สำหรับ compute-intensive apps; WebAssembly near-native perf ([Rustify](https://rustify.rs/articles/rust-vs-typescript-full-stack-2026))
- TypeScript ยังอยู่ default application language; Rust ครองชัยใน build tooling + perf-critical layer

→ **เกี่ยวกับเรา:** Rust tooling story เปลี่ยนแกน; Leptos stable ทำให้ Rust isomorphic web เป็นจริง
