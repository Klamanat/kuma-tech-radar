## ☸️ Cloud / DevOps / Infra

- **Kubernetes + AI as First-Class Citizens** — K8s กำลังรับ heavy MLOps workloads, scheduling strategy ต้องรองรับ bursty Jobs + continuous Services พร้อมกัน ([Fairwinds 2026 K8s Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth)) ⚠️
- **Platform Engineering adoption ~80%** — กว่า 80% องค์กรจะเลือก Platform Engineering แทน traditional DevOps ในปี 2026 เพื่อลดความสับสน developer cognitive load ([Pulumi Beyond YAML](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/)) ⚠️
- **Serverless Containers + Multi-Cloud trends** — "Serverless containers" เพิ่มขึ้น (hybrid scalability) และ multi-cloud adoption ยังสูง ขณะที่ Infrastructure as Code + policy enforcement ผสม AI orchestration เป็น default ([DEVOPSdigest 2026](https://www.devopsdigest.com/2026-container-predictions))
- **Self-Healing Clusters focus** — Kubernetes cluster management เลื่อนมาจากแค่ scheduling ไปสู่ automated remediation และ health correction ([Security Boulevard K8s Playbook](https://securityboulevard.com/2025/12/2026-kubernetes-playbook-ai-at-scale-self%E2%80%91healing-clusters-growth/))

→ **ภาพรวม:** K8s เป็น base layer ของ AI ops, Platform Engineering ถูก = cheaper toil, multi-cloud essential

## 🌐 Web / Frameworks / Languages

- **TypeScript 78% adoption + native runtime** — TypeScript ไม่ใช่ optional แล้วสำหรับ professional JS development, native runtime support ช่วยให้ส่วนใหญ่ไม่ต้อง transpile ([Alphonso Labs JS Trends 2026](https://www.alphonsolabs.com/javascript-trends-2026/)) ⚠️
- **React Compiler v1.0 ที่ production (Oct 2025)** — automatic memoization ลด boilerplate, Next.js full-stack + Server Components ยังเป็น best practice ของ React ecosystem ([Strapi best frameworks](https://strapi.io/blog/best-javascript-frameworks))
- **Vite 84M weekly downloads, rolldown stable release** — Vite ผ่าน Webpack ตั้งแต่ July 2025, satisfaction score 98% vs Webpack 26%, Rolldown (Rust bundler) ได้ stable release ทำให้ build เร็วขึ้นกว่าเดิม ([Alphonso JS trends 2026](https://www.alphonsolabs.com/javascript-trends-2026/))
- **Rust-ification: Biome 56x faster, Bun 26x faster** — toolchain critical path กำลังออกจาก JS ไปยัง Rust (Biome linting, Bun installs), Dioxus รองรับ web/desktop/mobile จากเดียว ([Rust vs JS/TS](https://blog.jetbrains.com/rust/2026/01/27/rust-vs-javascript-typescript/))

→ **สรุป:** TypeScript เป็น default, React + Next.js ยังเด่น, Rust ยึดชั้น toolchain performance-critical
