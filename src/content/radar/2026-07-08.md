## 🤖 AI / LLM / Agents

- **Claude Sonnet 5 & Gemini 3.5 Pro ก้าวขึ้นเป็นหลัก** — Anthropic ปล่อย Claude Sonnet 5 เมื่อ 30 มิถุนายน 2026, ส่วน Google Gemini 3.5 Flash ใช้ production ตั้งแต่ 19 พฤษภาคม และ Gemini 3.5 Pro คาดมาในกลางเดือนกรกฎาคม; ทั้งสอง reinforce ตำแหน่ง flagship เทียบกับ open models ที่ออกเร็วแต่กระจัดกระจาย ([llm-stats — AI updates](https://llm-stats.com/llm-updates))

- **Open-weight models ลื่นไหล: GLM-5.2, MiniMax M3, Nemotron Ultra** — GLM-5.2 (744B MoE, MIT license) ออกมิถุนายน, MiniMax M3 (428B MoE, 23B active) เช่นกัน, NVIDIA Nemotron 3 Ultra (550B / 55B active) ประกาศ Computex; บ่อยครั้งเร่งตัวประมาณทุก 2 วัน ([pricepertoken.com — model releases](https://pricepertoken.com/news/model-releases))

- **xAI Grok 4.5 private beta, OpenAI GPT-5.6 รอบมา** — xAI Grok 4.5 เข้า private beta 28 มิถุนายน คาดเปิด public กรกฎาคม; OpenAI GPT-5.6 (Sol, Terra, Luna variants) คาดเปิด general availability กลางเดือน ⚠️ ([AI Flash Report](https://aiflashreport.com/model-releases.html))

→ **ยิ่งไปยังไง**: โมเดล major (Claude, Gemini, GPT) ทำหน้าที่เป็น anchor ตรวจสอบ, ขณะ open-weight สร้าง tail ecosystem

## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37 เข้า Production Readiness Freeze วันนี้ 8 กรกฎาคม (AoE) / 9 กรกฎาคม 12:00 UTC** — Feature Freeze เมื่อหลายวันแล้ว, Enhancements Freeze จบแล้ว, release ครบกำหนด 26 สิงหาคม 2026; K8s v1.36 (Haru) ปล่อยแล้ว 70 enhancement เน้น security, AI workloads, API scalability ([kubernetes.dev — v1.37 schedule](https://www.kubernetes.dev/resources/release/))

- **AI workloads เป็นฮับ: DRA Beta, User Namespaces, Fine-Grained Kubelet Auth stable** — Dynamic Resource Allocation (DRA) ยกระดับ Beta, ทดแทน integer-GPU model ด้วย primitives ที่ express accelerator partitioning/sharing; User Namespaces และ Fine-Grained Kubelet Authorization เข้า GA; บ่งชี้ K8s กลายเป็น OS layer สำหรับ AI-driven services ไม่ใช่เพียงแค่ microservices ([kubernetes.io/releases](https://kubernetes.io/releases/))

- **Kubernetes adoption ถดถอยเล็กน้อย ลงมา 68% แต่ edge คงขึ้น** — บ่อยครั้ง split workloads ระหว่าง core cluster กับ serverless (Cloud Run, Container Apps); edge computing ยังไต่ขึ้นที่ 34% deployments แล้ว K3s distribution ⚠️ ([Fairwinds — 2026 K8s Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

→ **ต่อจากที่ผ่านมา**: GPU scheduling + observability aggregation (metrics/logs/traces/events) โหลดลดลง, AI workload expressivity เพิ่มขึ้น

## 🌐 Web / Frameworks / Languages

- **React Compiler v1.0 เทคมาตรฐาน, useMemo/useCallback เป็น legacy** — React Compiler ปล่อยผลฉลาด 7 ตุลาคม 2025 แล้ว, ตอนนี้ build-time memoization ถูกมองว่าเป็นค่ามาตรฐาน; dev ใช้ manual optimize ด้วย useMemo, useCallback, React.memo จะถูกมองว่า legacy pattern ใน 2026 ([State of JavaScript 2025](https://www.infoq.com/news/2026/03/state-of-js-survey-2025/))

- **TanStack Start ตัวฉับไป: 14M downloads/สัปดาห์ (เมื่อเทียบ 600k เมษายน)** — Meta-framework เกิดใหม่ที่เล็ก, ใช้ Tanstack Query, Router, Forms; ปริมาณดาวน์โหลด surge ต่อ 23x ใน 2 เดือน, ใกล้เข้าพื้นที่ Next.js; Next.js, Nuxt ยังเป็น standard choice ส่วนใหญ่ ⚠️ ([JavaScript Framework Trends 2026](https://www.nucamp.co/blog/javascript-framework-trends-in-2026-what-s-new-in-react-next.js-vue-angular-and-svelte))

- **Astro 6.0 stable, 60k+ GitHub stars, สวน #1 satisfaction State of JS 2025** — Astro team ได้รับกระหยี่ Cloudflare เมื่อ January 2026, Astro 6.0 stable มิถุนายน 2026; momentum ต่อ, fastest-growing meta-framework ที่มี AI-first redesign mindset เหมือนกับ Remix ([Medium — JavaScript Frameworks 2026](https://medium.com/@mernstackdevbykevin/javascript-frameworks-are-quietly-losing-their-grip-30642cd57680))

→ **ภาพรวม**: React Compiler ทำ memoization เป็นอัตโนมัติ, meta-frameworks ครองเล่น, AI-assisted (Copilot, v0) ยังคงเป็นเครื่องชี้ทาง
