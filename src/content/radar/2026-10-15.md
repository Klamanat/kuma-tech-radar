## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.36** — Release เมื่อต้นปี 2026 เน้น stability, compatibility, reproducibility ส่วน ingress-nginx migrate ไปใช้ Envoy Gateway ใน CNCF infrastructure ([CNCF news](https://www.cncf.io/mail/u/0/page/13/))
- **FinOps surge** — เทรนด์ 2026 เลื่อนจาก DevOps ไปเป็น **DevOps + FinOps** ฉันวัด cloud cost real-time และ allocate ให้ teams ตามความใช้จริง ([Cloud Native Now](https://cloudnativenow.com/topics/cloudnativeplatforms/the-good-the-bad-and-kubernetes-ugly/))
- **Kubernetes & AI webinar** — โปรแกรมวิจารณ์ integration ระหว่าง K8s กับ LLM workloads (workload awareness, GPU scheduling) จัดเมื่อ **21 กันยายน 2026** ([event archive](https://www.cncf.io/mail/u/0/page/13/))

→ **ภาพรวม:** FinOps ไม่ใช่ buzzword อีกต่อไป — เป็น operational requirement ส่วน K8s stable ทำให้ production ready สำหรับ agent workloads

## 🌐 Web / Frameworks / Languages

- **React 19.2** — ยังครอบครองตลาด **91% ของ framework users** โดยอาศัย React Compiler ลด manual memoization overhead ทำให้ app ต่อเร็วโดยไม่ต้องปรับปรุง code ([web framework survey 2026](https://www.bitcot.com/best-web-application-development-frameworks/))
- **Next.js 16 + Angular 21** — Next.js คง default full-stack solution สำหรับ React ecosystem; Angular ล่าสุดทำให้ **zoneless change detection default** สำหรับ enterprise ⚠️ ([framework analysis](https://shakuro.com/blog/web-development-frameworks))
- **Vue 3.5 + Svelte/SvelteKit & Astro** — Vue paired กับ Nuxt สำหรับ flexible adoption; Svelte และ Astro ก็เข้ายังงาน production-grade; TypeScript **baseline สำหรับ professional teams** แล้ว ([web tech landscape 2026](https://www.atakinteractive.com/blog/best-web-technologies-2026))
- **Bun vs Node.js** — Runtime showdown ยังดำเนิน: Bun เร็วกว่าแต่ Node.js ecosystem ใหญ่สุด

→ **ภาพรวม:** React ecosystem dominant, TypeScript standard, alternative frameworks สร้างความเชี่ยวชาญ niche ของตัวเอง
