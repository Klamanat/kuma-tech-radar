- **Google Gemini 3.5 Flash (1M context window)** — ได้รีลีส 19 พ.ค. 2026 ที่ Google I/O, Gemini 3.5 Pro เตรียมมาเดือนต่อ [lmcouncil.ai — model benchmarks](https://lmcouncil.ai/benchmarks)

- **Anthropic Claude Fable 5 ออก 9 มิ.ย.** — เป็นเวอร์ชันใหม่สุดจากแบรนด์ Claude ที่เรียงรายอยู่: Claude Opus 4.8, Sonnet 4.6, Haiku 4.5 [AI Flash Report](https://aiflashreport.com/model-releases.html)

- **Cycle of release ~ทุก 2 วัน** — โมเดลใหม่ออกมาเร็วที่สุดเท่าที่เคยมี ตลาด AI ในโหมด high-velocity race ⚠️ ([LLM News](https://llm-stats.com/ai-news))

→ **เกี่ยวกับเรา:** Coding agents (Qwen Coder, MiniMax) มี momentum หนัก, ต้องติด reasoning models ที่มี context ยาวพอ

## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.36 "Haru" ออก** — 70 enhancements: 18 Stable, 25 Beta, 25 Alpha; focus ที่ AI/ML workloads, security hardening, GPU scheduling with Dynamic Resource Allocation (DRA) ⚠️ [InfoQ — Kubernetes 1.36](https://www.infoq.com/news/2026/05/kubernetes-1-36-released/)

- **Platform Engineering ขึ้นแทน DevOps** — ประมาณ 80% ขององค์กรหันไป Platform Engineering เพื่อลด cognitive load บนนักพัฒนา, trend ที่ชัดจริง ⚠️ ([Medium — Platform Engineering Trends](https://medium.com/@orlando1409/beyond-kubernetes-platform-engineering-trends-for-2026-8f82e09e27e0))

- **AI Workloads ต้อง MLOps Orchestration** — Kubernetes ได้กลายเป็น "default OS สำหรับ AI" แล้ว, workloads ต้อง coordinate Jobs (burst) กับ Services (continuous) ⚠️ ([Pulumi Blog](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))

- **FinOps + Observability ตัดปม Cost** — 2026 องค์กรต้องรู้ว่าทีมไหนกิน budget เท่าไร, observability ขยายจาก metrics→logs/traces/events unified view ⚠️ ([Fairwinds Blog](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

→ **ภาพรวม:** K8s 1.36 บีบ AI workloads มากขึ้น, Platform Engineering กลายเป็น standard, FinOps ขึ้นมาเป็นเรื่องจริง

## 🌐 Web / Frameworks / Languages

- **React 19 Compiler Stable + Auto Memoization** — React Compiler จัดการ memoization อัตโนมัติ, useEffect ควรเป็นทางเลือกสุดท้าย, full shift ไป data fetching/derived state handling ⚠️ ([DEV Community](https://dev.to/parsajiravand/react-in-2026-start-from-scratch-the-right-way-cheat-sheet-2j9f))

- **TanStack Start สยบ Next.js ในไว** — Weekly downloads โหลด 600K → 14M ระหว่าง Apr-Jun 2026, TanStack Router ขึ้นเท่ากับ Next.js ในเร็วต่อมา ⚠️ ([nucamp.co — React Trends](https://www.nucamp.co/blog/javascript-framework-trends-in-2026-what-s-new-in-react-next.js-vue-angular-and-svelte))

- **TypeScript เป็น Baseline** — TypeScript + AI-assisted tooling กลายเป็น table stakes, Node.js 22.18.0+ ไปเป็น type-stripping by default, major frameworks ทั้งหมดใช้ TypeScript ⚠️ ([State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/))

- **JavaScript Frameworks รวบตัว 4 themes** — fine-grained reactivity, server-first rendering, compiler-driven optimizations, AI-assisted workflows; React จากเป็น "UI lib" เป็น "app framework" แล้ว ⚠️ ([Medium Guide](https://medium.com/@mernstackdevbykevin/typescript-with-react-best-practices-2026-78ce4546210b))

→ **เอกสิทธิ์เลือก:** Rust tooling ยังเด่นต่อเนื่อง, React Compiler ลดความต้องการ manual optimization, TypeScript เป็นเนื้อหาตรงกลาง
