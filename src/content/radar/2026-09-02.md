## 🤖 AI / LLM / Agents

- **Google Gemini 3.5 / 3.6 / 3.7 Flash ลุยตลาด** — Google ปล่อย Gemini Flash ทั้ง text, audio, image variants เพื่อตอบกลับ Anthropic Claude 3.5 Sonnet และเก้าอี้พลาสติก LLM ทั้งหมดที่ออกหมุนไป ตลาดเร่งออกโมเดลใหม่ทุก 1-2 สัปดาห์ แต่คนดูดีกว่า: cost-per-token, latency, task-specific quality ([blog.mean.ceo — AI releases Sept 2026](https://blog.mean.ceo/new-ai-model-releases-news-september-2026/))

- **Amazon Nova 2 Sonic: real-time voice assistant** — Amazon ย้อนกลับ Nova 2 Sonic มี real-time speech understanding สำหรับ customer support และ voice assistants ที่ต้องเร็ว-ถูก ช่วยให้ฝั่งเซิร์ฟเวอร์ไม่ตัวอักษร ([llm-stats.com — AI news](https://llm-stats.com/ai-news))

- **Z.ai GLM-5.3-Flash: multimodal open-source ตัวแรก** — GLM-5.3-Flash เป็นโมเดล open-source ตัวแรกของ Z.ai ที่จัดการ text, image, audio ได้พร้อมกัน ช่วยให้ startups เล็ก ๆ ทำ multimodal application ได้โดยไม่ต้อง orchestrate models หลายตัว ([thundercompute.com — open source LLMs Sept](https://www.thundercompute.com/blog/best-open-source-llms))

→ **ภาพรวม:** LLM market เลิกแข่ง parameters และ benchmark, มาแข่ง cost-efficiency, speed, multimodal support แล้ว

## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.36: 70 enhancements, มุ่ง AI + security** — K8s v1.36 มี 70 features ใหญ่ๆ ต่อ security, AI workload scheduling, API scalability; 3 feature โดนขึ้น GA: User Namespaces, Mutating Admission Policies, Fine-Grained Kubelet Authorization ทำ cluster ปลอดภัย + มี native GPU scheduling เข้มมาก [official] ([kubernetes.dev — v1.36](https://www.kubernetes.dev/resources/release/))

- **Microsoft AKS Build 2026: AI training/inference platform** — Microsoft เปิด AKS enhancement ใหญ่ๆ ทำให้ Kubernetes เป็น platform ที่เหมาะ AI training, inference, large-scale cloud-native apps ตัวนี้ตอบ Google GKE ([medium.com — DevOps 2026](https://medium.com/@h.stoychev87/devops-cloud-platform-tools-by-category-for-2026-68ed92103c17))

- **Google GKE OpenRL: LLM fine-tuning on K8s** — Google ปล่อย OpenRL เป็น open-source API ให้ ML engineers ทำ post-training + fine-tuning LLM บน Kubernetes cluster เดียว คิดว่า: ไม่ต้องเปลี่ยน orchestrator เมื่อต้อง switch ระหว่าง training/inference workflow ([fairwinds.com — K8s 2026 playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

→ **เกี่ยวกับตัวเรา:** K8s เป็น platform ตรงไปตรงมา สำหรับ AI workload หนัก บน production, ต้อง try OpenRL สำหรับ fine-tuning

## 🌐 Web / Frameworks / Languages

- **React 19.2.0: Activity Component + cacheSignal API [official]** — React ปล่อย v19.2 มี 3 feature ใหญ่: (1) Activity Component ลำดับความสำคัญตามการแสดงผล, (2) useEffectEvent Hook แยก events จาก side-effects, (3) cacheSignal API บริหาร async resource cleanup ใน Server Components ลักษณะนี้ helper สำหรับ server-first architecture ([dev.to — React 2026](https://dev.to/parsajiravand/react-in-2026-start-from-scratch-the-right-way-cheat-sheet-2j9f))

- **tldraw 4.0: infinite canvas + CLI + accessibility** — tldraw (collaborative whiteboard) เกาะ v4.0 เพิ่ม infinite React canvas, CLI, starter kits สำหรับเริ่มเร็ว accessibility ดี tool นี้มีประโยชน์สำหรับ diagram/mockup products ยีนนี้ ⚠️ ([thisweekinreact.com — week 294](https://thisweekinreact.com/newsletter/294))

- **React Router 7.9 + React Query 5.89** — React Router 7.9 ทำให้ middleware + type-safe context API stable ใช้สำหรับ authentication guards; React Query 5.89 เพิ่ม context parameter ให้ mutation callback เข้าถึง Query Client โดยตรง ([thisweekinreact.com — week 294](https://thisweekinreact.com/newsletter/294))

- **Expo SDK stable: iOS build 10x faster** — Expo ขึ้น SDK version stable สาบเป็นตัวสุดท้ายที่รับ Legacy Architecture iOS build เร็ว 10x, build cache stable แล้ว ตัวนี้เปิดทำให้ React Native เร็ว ([dev.to — React 2026](https://dev.to/parsajiravand/react-in-2026-start-from-scratch-the-right-way-cheat-sheet-2j9f))

→ **ภาพรวม:** React 19.x ecosystem เข้ารอบ server-first pattern + compiler optimization, ทำให้เขียน component เรียบง่าย
