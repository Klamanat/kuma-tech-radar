## ☸️ Cloud / DevOps / Infra

## 🌐 Web / Frameworks / Languages

- **React Compiler port ไปเป็น Rust แล้ว — 3x เร็วกว่าเดิม** — Meta ย้ายจาก TypeScript เป็น Rust, isolated transformation logic ขึ้นถึง 10x faster, ยังคง memoize components/hooks อัตโนมัติ ([InfoQ — Meta Ports React Compiler to Rust](https://www.infoq.com/news/2026/07/meta-react-compiler-rust/))

- **TypeScript 7.0 ขับเคลื่อนด้วย Go compiler — 11.9x faster type-checking** — เปิดตัว 8 ก.ค. 2026, VS Code codebase เร็วขึ้นจาก 125.7 วิ เหลือ 10.6 วิ [official] ([Ecorpit — Next.js 16.3 and TypeScript 7.0](https://ecorpit.com/nextjs-16.3-typescript-7-rust-go-toolchain-2026/))

- **Next.js 16.3/16.4 ว่อง Turbopack — build ขึ้น 5.5x faster, memory ลง 90%** — เปิดตัว 29 มิ.ย. 2026, persisted cache ลดการ rebuild, experimental Rust port ของ React Compiler ([byteiota — React Compiler in Rust](https://byteiota.com/react-compiler-rust-nextjs-16-4-faster-builds/))

→ **ภาพรวม:** Rust + Go ยึดตัวแปร tooling ต้องการ performance, TS ยังเป็นภาษา primary สำหรับ application
