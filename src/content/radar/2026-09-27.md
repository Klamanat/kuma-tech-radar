## 🤖 AI / LLM / Agents

- **OpenAI GPT-6 Luna & Astra ออกรอบนี้** — ต่อเนื่องจากการวิ่งขี่แมโจรของตลาด AI models ที่ปล่อยรุ่นใหม่ ๆ อย่างสม่ำเสมอ OpenAI ปล่อย GPT-6 Luna เมื่อ 22 กันยายน และ GPT-6 Astra พร้อมกัน ตีตลาดก่างปากกว้าง ([LLM Gateway](https://llmgateway.io/timeline)) [official]
- **23 models ใหม่เดือนกันยายน 2026** — จาก 15 providers ทั่วโลก (Google Gemini 3.8 Flash เมื่อ 2 กันยายน, Fugu Max จาก Sakana AI วันที่ 11, Ling 3.0 Flash VL จาก Inclusionai วันที่ 10, Smart Route เมื่อ 25 กันยายน) เพิ่มเติมคือ Xiaomi MiMo-V2.6, xAI Grok 4.7, DeepSeek V4.1-Flash ที่กำลังกวาดตลาดต่อ ([AI Model Releases Tracker 2026](https://toolpix.pythonanywhere.com/blog/ai-model-releases-tracker-2026)) [official]
- **เสียงกหล่อม:** edge latency, reasoning depth, multi-million token context windows, และ price-performance ปรับตัวขึ้นมาก ตลาดไม่ยอมให้ใครจม ปล่อย iterate บ่อยเพื่อ capture market share

→ **เกี่ยวกับเรา:** GPT-6 Luna & Astra พวกนี้ใช่ training basis สำหรับ coding agents ที่เราศึกษา ต้อง track ความต่างฟีเจอร์ระหว่าง Luna (ทั่วไป) กับ Astra (ฉึกฉัก)

## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37 — Native Histogram Support อยู่ Beta** — ความเปลี่ยนแปลงหลักใน v1.37 คือการเพิ่มการรองรับ histogram native สำหรับ metrics ของ Kubernetes ซึ่งปล่อยให้ AI/ML workloads และ complex batch jobs ได้อยู่ใน Kubernetes ตรง ๆ ได้อย่างมีประสิทธิภาพมากขึ้น ([Pulumi Blog](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/)) [official]
- **AI-Driven Orchestration เข้าใจมาตรฐาน** — ปี 2026 นี้ Kubernetes ไม่ใช่แค่ orchestrator แล้ว แต่กลายมาเป็น de facto operating layer สำหรับ AI services, microservices, data pipelines และ edge applications ที่ต้องใช้ infrastructure as code + policy enforcement + AI-assisted automation ([Fairwinds 2026 Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth)) [official]
- **Observability Unified View** — shift จากการแจ้งเตือนแยก ๆ (ad hoc) เป็นมุมมองแบบ unified ของสุขภาพ cluster ที่รวม metrics, logs, traces, events ไว้ด้วยกัน ช่วยให้ SREs ตัดสินใจเร็ว

→ **ภาพรวม:** K8s เข้าสู่ยุค AI-first infrastructure; observability เป็นทักษะต้องมี; DevOps teams ต้อง skill-up automatio

## 🌐 Web / Frameworks / Languages

- **React 19 — Compiler Stable & Automatic Memoization** — React 19 ผ่านไป stable เรียบร้อยแล้ว React Compiler จัดการ memoization ให้อัตโนมัติ ช่วยให้ developers ไม่ต้องไปคิดตรวจสอบปัญหา deps array ด้วยมือ component จึงเร็วขึ้นโดยไม่เสียแรง ([React in 2026 on DEV Community](https://dev.to/parsajiravand/react-in-2026-start-from-scratch-the-right-way-cheat-sheet-2j9f)) [official]
- **Next.js 15+, Vite 8, Angular 22 ครอบ production** — Next.js 15+ ใช้ App Router เป็น default, Vite 8 (stable มีนาคม 2026) พลัง Rolldown bundler เข้าแทน webpack, esbuild ทำให้ build เร็ว 10-30x เทียบ old tooling; Angular 22 เพิ่ม Signal Forms + Deferrable Views พร้อม TypeScript native support จนกระทั่งสำหรับ enterprise apps ([Strapi blog](https://strapi.io/blog/best-javascript-frameworks) & [FocusReactive](https://focusreactive.com/blog/react-frameworks-to-use/)) [official]
- **Rolldown Bundler 1.0 — Rust Power** — Rolldown bundler 1.0 ออกมาเมื่อ May 2026 ตอนนี้เป็นชิ้นส่วนแกนของ Vite ecosystem (Nuxt, SvelteKit, Astro) ทำให้ build time ลดจาก นาทีต่างๆ ลงมาที่ 30-40 วิ เจ้า Rust-based tooling ไล่ JavaScript tooling ให้ถอย

→ **สรุป:** Web dev ecosystem นี้ Rust tooling ครองฉาน, React/Next.js ครองใจ SPA, สำหรับ content/marketing site ให้ลอง Astro/Svelte
