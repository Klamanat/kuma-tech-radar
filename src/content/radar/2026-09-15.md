- **Z.ai GLM-5.3-Flash เป็นเนทีฟ multimodal แรก** — DeepSWE score 63.4 vs GLM-5.2's 46.2, ทำให้ coding tasks ดีขึ้นชัดเจน ([LLM Reference](https://www.llmreference.com/changelog/2026-09))

→ **เกี่ยวกับเรา:** Fable 5.1 + GPT-6 Astra ทำให้ inference cost ต่ำลง ใช้ได้สำหรับ production agents

## ☸️ Cloud / DevOps / Infra

- **Kubernetes 1.35 — DRA (Dynamic Resource Allocation) binding conditions → beta** [official] — เข้าใจง่ายขึ้นสำหรับ AI/ML workloads ที่ต้อง GPU/TPU, ตามไป adoption containerized apps ขึ้น 84% ของ organizations ([kubernetes.dev — v1.35 schedule](https://www.kubernetes.dev/resources/release/))
- **OCI Registries กลายเป็น standard สำหรับ IaC + GitOps** — ไม่ใช่แค่ container images แล้ว common IaC tools + GitOps tooling มีการรองรับเป็น first-class ([CNCF news](https://www.cncf.io/news/))
- **AI-assisted code ขึ้นสู่ 42% ของ code committed** — Sonar's 2026 State of Code survey แสดงว่า AI ส่งผลต่อ DevOps workflows อย่างมากแล้ว ([Sonar developer survey](https://www.sonarqube.org/))
- **Serverless + Kubernetes ครองตลาด** — Developers หันมา serverless เพราะความยืดหยุ่นและ operational overhead ต่ำ ⚠️ ([CNCF trends](https://www.cncf.io/cncf-annual-survey-2026/))

→ **เกี่ยวกับงาน keycloak:** DRA beta → ลองใช้กับ GPU scheduling, OCI registries เป็น option ใหม่
