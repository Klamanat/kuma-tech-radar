## ☸️ Cloud / DevOps / Infra

**KubeCon + CloudNativeCon North America — Kubernetes เป็น platform AI** — ประชุมใหญ่ 9–12 พ.ย. 2026 ที่ Salt Lake City โฟกัสเน้นหนัก "Kubernetes for AI agents" (Buoyant ผุด open-source control plane Nov 4, CIQ เบนด์ Kubernetes-for-AI binary Nov 2) AI agents ยอมรับ Kubernetes เป็นที่วิ่ง → แต่ Kubernetes ยังไม่มี recovery path ชัดเจนสำหรับ stateful/agent workflows [official](https://cloudnativenow.com/tag/leanix/)

**Salesforce migrate 1,000+ EKS clusters → Karpenter** — Large-scale migration ชี้ว่า scaling bottleneck ตั้งตน Karpenter ให้ fine-grained auto-scaling ที่ Kubernetes ยังให้ไม่ดี [⚠️ tracker](https://www.infoq.com/Kubernetes/news/)

**llm-d production-ready สำหรับ distributed GPU inference** — Project ยังว่าง Kubernetes-style efficiency ให้ GPU clusters (เสร็จ Oct 23) เมื่อ GPU inference scatter across machines → ต้อง orchestration ที่เข้าใจ GPU affinity, fault tolerance [⚠️ community](https://www.infoq.com/Devops/news/)

→ **เกี่ยวกับงาน tune-keycloak:** GPU scheduling + multi-host inference on K8s ตรงไปตรงมา สำหรับใครว่ายน้ำ distributed models

## 🌐 Web / Frameworks / Languages

**React Compiler 1.0 ทำ memoization อัตโนมัติ — production-ready** — Meta ส่ง React Compiler 1.0 ให้ production พร้อม automatic optimization บน hooks/components (ตรวจสอบแล้ว ใช้ production ที่ Meta) นี่คือ "magic" ที่ developers ต้องการตั้ง React 15 มา — วาด UI, let compiler เรียบลบ wasteful renders [official](https://builder.io/blog/react-ai-stack-2026)

**React 19.2.8 stable + React 20 ยังอบแพต** — React 19.2.8 เป็นเวอร์ชันปกติ (ฝั่ง July 2026), React 20 ยังอยู่ development เวอร์ชัน 19 ยังเป็น stable default ที่เสถียร · Next.js ถือ meta-framework top (surveys + job postings) [⚠️ guides](https://pdpspectra.com/blog/typescript-modern-stack-2026)

**Bun + TanStack Start แย่งตำแหน่ง · TypeScript baseline** — Bun ก้าวแข็ง all-in-one (package manager, runtime, bundler, test runner) เร็วที่สุด · TanStack Start ใหม่ (React/SolidJS) · TypeScript เป็น baseline 2026 ทั้งหมด — framework choice = flavour ของ TS ecosystem [⚠️ sources](https://learn.g2.com/best-javascript-web-frameworks)

→ **ภาพรวม:** React ยังฝั่งเสถียร, compiler automation เข้า production, Bun + Rust tooling (Vite ecosystem) บีบที่ build times
