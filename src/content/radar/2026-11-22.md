## ☸️ Cloud / DevOps / Infra

- **KubeCon + CloudNativeCon North America เสร็จ (9–12 พฤศจิกายน, Salt Lake City)** — Kubernetes ยืนยันอีกครั้งว่าเป็น fabric หลักสำหรับ AI agents ที่มี sandboxing/orchestration [official] CNCF ประกาศ Hyperlight ตัวใหม่ เพื่อรันแอป Linux ในไมโคร VMs ([CNCF news](https://www.cncf.io/u/0/page/34/))
- **kpt v1.0.0 release สำหรับ Agent Sandboxes** — เครื่องมือจัดการอย่างเสรจจำเพาะ ตัวใหม่มาจาก CNCF เพื่อให้ agentic development ง่ายในระบบ [official] ([CNCF — kpt v1.0.0](https://www.cncf.io/u/0/page/34/))
- **Broadcom + Buoyant ส่งระเบียบการ container/VM** — Broadcom บริจาค virtual machine API ให้ CNCF (9 พฤศจิกายน) · Buoyant ปล่อยควบคุมเครื่องมือ open-source สำหรับ AI workloads บน K8s (4 พฤศจิกายน) [official] ([CloudNativeNow](https://cloudnativenow.com/tag/leanix/))

→ **ภาพรวม:** Kubernetes คิด "ใช้ agentic" ต่างว่า "เอา containers" · VM/sandboxing เป็นปัญหาข้างเคียง

## 🌐 Web / Frameworks / Languages

- **Topcoat: Rust framework ใหม่สำหรับ full-stack reactive apps** — Tokio ประกาศวันที่ 22 กรกฎาคม 2026 ว่า Topcoat รวมระบบสำหรับ web app ตัวแบบ modularity เช่น Leptos/Dioxus [official] แต่เป็นสิ่ง compile ไป JavaScript (ไม่ WASM) ซึ่งให้ scope สำหรับ developer ที่ไม่อยาก frontend complexity ([Tokio — Topcoat](https://tokio.rs/blog/2026-07-22-announcing-Topcoat))
- **React Compiler ตัวเต็มเข้า Rust ระดับครึ่งหนึ่ง** — Meta PR #36173 (มีนาคม 2026) ทำ port ของ Compiler จาก TypeScript ไป Rust · Meta integrate เข้า main branch แล้ว [official] เพื่อให้ build/compile เร็วในระดับ production ([blog.logrocket — H1 2026 Frontend Wrapped](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **TypeScript 7.0 ด้วยสำเร็จ native Go compiler** — Microsoft ปล่อย TS 7.0 ร่มวิทยา native Go compiler ได้ประโยชน์ 8–12x faster build [official] ทำให้นักพัฒนา TypeScript จิตใจสบาย · Remix 3 beta step back ไม่ React บางส่วน ไป web primitives ([Sencha — Web frameworks](https://www.sencha.com/blog/web-application-development-top-frameworks/))

→ **ภาพรวม:** Rust tooling ครอบขว้าง JS/TS ecosystem · Go compiler ใน TypeScript ปัดหนาม build ไป
