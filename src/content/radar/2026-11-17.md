## 🌐 Web / Frameworks / Languages

- **Tuono 0.16+** (React + Rust full-stack) ยังคง stable ⚠️ — full-stack framework ทำ React apps ด้วย Rust backend สำหรับการทำงาน production ([docs.rs — tuono/0.16.4](https://docs.rs/crate/tuono/0.16.4))
- **Rari** (React Server Components on Rust runtime) ปรับเดินหน้าเวอร์ชัน 0.13 ⚠️ — Rust backends สำหรับ RSC แนว V8 embedded + Rolldown toolchain อยู่ในระยะปรับปรุง ([docs.rs — rari/0.13.3](https://docs.rs/crate/rari/0.13.3))
- **Leptos vs Yew vs Dioxus** (2026 comparison) — Rust-to-WASM frontends ทำให้ WASM patterns ไป full stack นอก Node ได้ learning curve favor React hooks dev ⚠️ ([reintech.io — framework comparison](https://reintech.io/blog/leptos-vs-yew-vs-dioxus-rust-frontend-framework-comparison-2026))

→ **เทรนด์:** Rust ยังจับมั่นชั้นเว็บ tooling—เพื่อให้ WASM/Rust patterns ไป full-stack alternatives ให้ performance-critical apps
