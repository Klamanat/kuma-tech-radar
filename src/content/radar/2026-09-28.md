## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37: Native Histogram metrics graduating to Beta (enabled by default)** [official] — ย้ายจาก experimental → standard monitoring layer ([kubernetes.io](https://kubernetes.io/blog/)) ส่งผลให้ observability cost ลดลงและ cardinality explosion ควบคุมได้ดีกว่า; K8s กลายมา platform เพื่อ AI workload ไม่ใช่แค่ orchestration

- **Platform Engineering/IDPs แทน traditional DevOps** ⚠️ — 84% infrastructure leaders คาดว่าครึ่งหนึ่งของ apps ใหม่จะรันบน K8s ภายใน 5 ปี, 82% container users มี K8s production แล้ว ([portworx — trends](https://portworx.com/blog/kubernetes-enterprise-adoption-trends/)) cognitive load ลด, self-service infra เพิ่ม

- **AI at scale on Kubernetes** ⚠️ — MLOps platforms ใหญ่ประกอบด้วย bursty Job (data processing) + continuous Service (inference) ต้อง coordinate บน K8s ([fairwinds — 2026 playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth)) ถัดจาก scheduling native GPU, DRA (Dynamic Resource Allocation) ก็จำเป็น

→ **ภาพรวม:** K8s 1.37 native histogram = มั่นใจ observability ที่ reliable; Platform Engineering เป็นโมเดลป้องกัน sprawl และ toil

## 🌐 Web / Frameworks / Languages

- **Rolldown bundler 1.0 (May 2026) → Vite 8 default, 10-30x ความเร็ว** [official] — Rust-based bundler ชิง esbuild/Rollup; Vite stable v8 (March 2026) ใช้ Rolldown เป็น optimizer ([dev.to](https://dev.to/agnelnieves/rust-owns-the-javascript-toolchain-in-2026-l9b)) build time ลด 2.5 นาที → 40 วินาที ⚠️ (บาง team)

- **TypeScript surpass JS + Python บน GitHub (Aug 2025), 48.8% pro devs ใช้** [official] — Stack Overflow 2025 survey; TypeScript ขึ้นเป็นภาษาเลือกเมื่อต้องประหยัด runtime error ([strapi — 2026 JS frameworks](https://strapi.io/blog/best-javascript-frameworks)) ยิ่ง strict mode โดยค่า = เป็น default ในอนาคต

- **Leptos โปรแกรม Rust full-stack web (SSR + client hydration)** ⚠️ — Actix Web / Axum มี routing + middleware แต่ Leptos recommended สำหรับ 2026 เพราะรองรับ server functions ใน Rust ที่สมบูรณ์ ([rustify — Leptos 2026](https://rustify.rs/articles/rust-leptos-fullstack-web-2026)) ลด JS/TS fatigue กับ bridge layer

→ **สรุป:** Rust toolchain กินเนื้อที่บน performance-critical layer; TypeScript ยังแกนหลักของ app code แต่ edge case (bundler, CLI, infra) = Rust
