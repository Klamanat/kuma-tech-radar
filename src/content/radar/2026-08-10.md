## 🌐 Web / Frameworks / Languages

- **TypeScript v7 มาบน Go compiler กลางปี** — TypeScript เตรียม v7 (หลัง v6) ที่เขียนใหม่ทั้ง compiler บน Go · สาเหตุ: strict-by-default, ตัด ES5 target + AMD/UMD/SystemJS, type-check parity ~99.6% ([Frontend Masters — JS 2026](https://frontendmasters.com/blog/what-to-know-in-javascript-2026-edition/))
- **TypeScript ขึ้นเป็นภาษา #1 contributor-wise** — GitHub ยืนยันว่า TypeScript surpassed Python/JavaScript ตั้งแต่เดือนส.ค. 2025 (2.63 million contributors) · 78% professional devs ใช้ TypeScript ปี 2026 ↑ from 69% in 2024 [official] ([C Sharp Corner](https://www.c-sharpcorner.com/article/top10-javascript-frameworks-to-watch-in-2026/))
- **Frameworks แบบ server-first + compiler-driven** — React 19 compiler ตัด re-renders 25-40% · Server Components ลดเวลา render จาก 2.4s → 0.8s · Vite เป็น default bundler สำหรับ Astro/SvelteKit/Nuxt ตอนนี้ ([Frontend Masters](https://frontendmasters.com/blog/what-to-know-in-javascript-2026-edition/))
- **Turbopack เป็น next.js v16 default** — Rust-based, คาดจะเร็ว 5–10x ที่ refreshing เทียบกับ webpack ([What To Know in JavaScript 2026](https://www.alphonsolabs.com/javascript-trends-2026/))

→ **ภาพรวม:** ภาษา + compiler ยินดีใช้ Rust/Go · Server-first render + tiny client hydration = ความชี้นำใหม่
