## ☸️ Cloud / DevOps / Infra

- **Kubernetes ตัดสิน: AI workload ต้องอยู่ใน cluster** — เมื่อ 84% ขององค์กรใช้ K8s เป็นชั้นกลางแล้ว ข้อสรุปสตรองคือ AI ชั้นบน (inference, fine-tuning) มัดขึ้นกับ native Kubernetes เลย; บางทีทีม adopt MLOps platform มากกว่า bare pod ⚠️ ([fairwinds.com/blog/2026-kubernetes-playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- **ยุค Kubernetes "นอกตัวปรี":** ก่อนหน้านี้ DevOps = "ดูแล K8s" แต่ตอนนี้เป็น "Platform Engineering" ที่เน้นให้ dev อื่นๆ ไม่ต้องเข้า kubectl — ปล่อยให้ AI assistant หรือ intelligent controller ทำอัตโนมัติ ([pulumi.com/blog](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era))
- **7 tools AI-powered ใหญ่สุด** กำลังทำให้ Kubernetes "เรียนรู้" cluster state ขึ้นมา — correlation signals, fix problem self-healing, auto-remediation เรียบร้อย ([medium.com/devops-ai-decoded](https://medium.com/devops-ai-decoded/7-ai-powered-kubernetes-tools-rewriting-cloud-native-ops-in-2026-e5e57c69cd73))

→ **ภาพรวม:** Kubernetes ไม่ใช่ infra มากเท่าไหร่ — มันกำลังเป็น "compute OS" ที่อัดเต็มไป AI

## 🌐 Web / Frameworks / Languages

- **React Compiler เข้าไป Rust full blast** — ทีม Meta ยืน Rust rewrite เพราะ TypeScript ไม่พอเร็ว สำหรับ compiler loop ที่ต้องวิเคราะห์ component/hook ล้าน-ตัว production ในเวลาจริง ([mindpathtech.com/blog/reactjs-trends](https://www.mindpathtech.com/blog/reactjs-trends/))
- **TypeScript 78% ของ pro teams** — ยูสแล้วแล้ว state-of-JS 2025 ยังแน่นยิ่งขึ้นเมื่อเข้า 2026 เพราะ AI agent (Claude, ChatGPT) อ่านโค้ด TS ดีกว่า JS มาก ⚠️ ([medium.com/@mernstackdevbykevin](https://medium.com/@mernstackdevbykevin/typescript-with-react-best-practices-2026-78ce4546210b))
- **React Server Components + AI-first dev:** โครงสร้าง 2026 = "server render 90%, client 10%" และพัฒนาร่วมกับ AI assist (~29% โค้ดใหม่มาจาก gen) ทำให้ feedback loop สั้นกว่า test cycle อีก ([nucamp.co/blog/javascript-framework-trends](https://www.nucamp.co/blog/javascript-framework-trends-in-2026-what-s-new-in-react-next.js-vue-angular-and-svelte))

→ **ภาพรวม:** TypeScript + React Server Component + AI gen = "application framework" มากกว่า "UI lib"; Rust ต้องมี performance ต้องที่
