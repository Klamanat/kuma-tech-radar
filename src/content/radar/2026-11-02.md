## ☸️ Cloud / DevOps / Infra

- **KubeCon Europe 2026 สร้างสถิติ** — บรรจุ ~13,500 ผู้เข้าร่วม (สูงขึ้น 10% จากปีที่แล้ว) ด้วยความสนใจโรดแมป AI orchestration ([Kubernative news](https://t.me/s/kubernative/321))
- **Ingress NGINX เข้าสู่พิธีปลดปล่อย** — ประกาศตรง KubeCon NA ว่า Ingress NGINX จะ retire ภายในอนาคต โปรแกรม ค่าย Kubernetes เริ่มส่งต่อไป gateway API [official] ([Kubernative announcements](https://t.me/s/kubernative/350))
- **ClickHouse ได้ operator แบบสมบูรณ์** — CNCF ยอมรับ Kubernetes operator อย่างเป็นทางการสำหรับ ClickHouse ทำให้ deployment ง่ายขึ้นบน K8s ([Kubernative news](https://t.me/s/kubernative/327))

→ **เกี่ยวกับเรา:** Gateway API จะหนักมากขึ้น ต้องเตรียม migration จาก Ingress NGINX

## 🌐 Web / Frameworks / Languages

- **React Compiler stable ใน React 19** — เปิดตัว stable ประจำและสามารถใช้ production แล้ว ช่วยลดการ optimize ด้วยมือสำหรับ component/hook ([React.dev official](https://react.dev/blog/2025/10/07/react-compiler-1))
- **TypeScript = baseline สำหรับ 87% React devs** — Stack Overflow 2026 survey ชี้ว่า TypeScript ยืดทั่วในสัญญาแรม สำหรับทีม professional ⚠️ ([Sencha blog](https://www.sencha.com/blog/how-to-create-react-app-typescript/?amp=1))
- **Next.js โลดโผน สำหรับ production** — ข้อมูล H1 2026 บ่งชี้ Next.js เป็น default framework สำหรับ SaaS และ web app ที่ต้อง scale ([Atak Interactive 2026 review](https://www.atakinteractive.com/blog/best-web-technologies-2026))
- **Vite แทน Create React App** — Create React App เลิกใช้แล้ว Vite + TypeScript เป็น recommended setup สำหรับ React project ใหม่ ([Sencha guide](https://www.sencha.com/blog/how-to-create-react-app-typescript/?amp=1))

→ **ภาพรวม:** TypeScript บังคับในทุก stack ระดับ production; Next.js + React 19 + Vite เป็น combo มาตรฐาน
