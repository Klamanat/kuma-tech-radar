## ☸️ Cloud / DevOps / Infra

- **Kubernetes กลายเป็น "AI Operating System"** — ในปี 2026 K8s ไม่ใช่แค่ container orchestrator แล้ว ถือเป็น default OS ของ AI workloads โดย MLOps platforms ต้องการ bursty high-resource Jobs กับ continuously running Services ([Fairwinds — 2026 K8s Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- **Platform Engineering แทน DevOps** — 80% ของ organizations คาดว่าเลิกใช้ traditional DevOps ไปใช้ Platform Engineering เพื่อลด cognitive load ของ developers ด้วยองค์ประกอบ IaC + Policy Enforcement + AI orchestration ([Loginline — 2026 K8s Trends](https://www.loginline.com/en/blog/2026-kubernetes-trends))
- **Kubernetes 1.37 + Gateway API v1.6.0** — Dynamic Resource Allocation (DRA) beta สำหรับ GPU/ML workloads, native GPU scheduling, fine-grained Kubelet authorization stable ([Kubernetes.io](https://kubernetes.io/releases/), [Pulumi Blog](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))

→ **เกี่ยวกับงาน infra:** DRA + AI tooling ช่วยลดโหลด ops ขณะที่ ML workloads เพิ่มขึ้น

## 🌐 Web / Frameworks / Languages

- **React Compiler ในรูป Rust — fast 10x** [official] — Meta merged PR #36173 เมื่อ 9 มิ.ย. ทีม port logic จาก TypeScript ไป Rust ด้วย AI assistance Rust version วิ่ง 3x เร็วกว่า TypeScript ต้นฉบับ บาง case ได้ถึง 10x ([Meta React Compiler Rust — InfoQ](https://www.infoq.com/news/2026/07/meta-react-compiler-rust/))
- **Next.js 16.4 — build speed ขึ้น 40%+** — Vercel ยืนยันว่า React Compiler Rust version ใน Next.js 16.4 ลดเวลา build อย่างมีนัยสำคัญ TypeScript adoption ขึ้น 78% และเป็นมาตรฐานจริงๆ สำหรับ professional development ([Next.js 16.4 — byteiota](https://byteiota.com/react-compiler-rust-nextjs-16-4-faster-builds/))
- **Rust Web Framework Ecosystem เติบโต** — Actix Web, Axum, Rocket, Warp, Loco, Leptos เป็นตัวเลือก full-stack นั่นเองหลายทีม build เร็วขึ้น 2.5 นาที → 40 วิ ⚠️ ([JavaScript Trends 2026 — Alphonso Labs](https://www.alphonsolabs.com/javascript-trends-2026/))

→ **ภาพรวม:** Rust tooling (Vite, Rolldown) ยึดชั้น performance, TypeScript/React ยังเป็นมาตรฐาน
