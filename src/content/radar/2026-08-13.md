- **Seedance 2.5** (8 สิงหาคม), **Muse Spark 1.2** จาก Meta (6 สิงหาคม), **Qwen Image 3.0 Pro** (5 สิงหาคม) — วงการแยกชัดระหว่างแบบจำลองทั่วไป vs coding/agent specialists ([Local AI Zone](https://local-ai-zone.github.io/blog/ai-updates-august-2026.html))
- **Claude Opus 5 ราคาลดลง 50%**, **GPT-5.6 + ChatGPT Work Agent**, **Kimi K3 เป็น open-weight โมเดลที่ใหญ่ที่สุด** — การแข่งขันราคาและการเปลี่ยนผ่านไปยังเอเจนต์ ([Price Per Token](https://pricepertoken.com/news/model-releases))

→ **เกี่ยวกับเรา:** agent frameworks (MCP, AutoGen) เป็นเครื่องหมายเทพของวิศวกรที่ทำงานกับ LLM

## ☸️ Cloud / DevOps / Infra

- **Kubernetes Gateway API v1.6.0** — ปลายมิถุนายน 2026 มา standard ใหม่สำหรับ service networking บทบาท/การแสดงออก ให้การกำหนดค่าเครือข่าย Kubernetes ชัดเจน ([Spectro Cloud](https://www.spectrocloud.com/news), [Pulumi Blog](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))
- **Kubernetes 1.37 เข้ามา** — Dynamic Resource Allocation (DRA) บีตา เพื่อจัดการ GPU/ML workloads ได้ง่ายขึ้น, AI-powered Kubernetes tools ลดเวลา MTTR 40% และลดค่า cloud ได้ 70% ([Kubernetes Blog](https://kubernetes.io/blog/), [Fairwinds Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- **Platform engineering trend:** Infrastructure as Code + Policy Enforcement + AI orchestration มารวมกันเป็น "operating system สำหรับ AI" ([Medium — Platform Engineering Trends](https://medium.com/@orlando1409/beyond-kubernetes-platform-engineering-trends-for-2026-8f82e09e27e0))

→ **เกี่ยวกับงาน infra:** DRA + AI tooling ช่วยลดโหลด ops ขณะที่ ML workloads เพิ่มขึ้น

## 🌐 Web / Frameworks / Languages

- **React 19.2 เสถียร + React Compiler v1.0** — โปรดักชัน-ready optimization อัตโนมัติ TypeScript ขึ้น 40% ใช้เป็นเบสไลน์สำหรับโปรเจกต์ขนาดกลาง-ใหญ่ ([Nucamp — JS Framework Trends](https://www.nucamp.co/blog/javascript-framework-trends-in-2026-what-s-new-in-react-next.js-vue-angular-and-svelte))
- **Meta-frameworks เป็น default** — ไม่เลือกแค่ React แล้ว เลือก Next.js; Svelte + SvelteKit/Nuxt/Astro ก็เป็นตัวเลือก หาแบบใช้ raw framework ไม่มี meta-layer ได้ยาก ([Strapi Blog](https://strapi.io/blog/best-javascript-frameworks))
- **Vite ชนะ (98% satisfaction)** เทียบกับ Webpack (37% negative), Rolldown/Turbopack ก้าวขึ้นมา Build time ขนาด 2.5 นาที → 40 วินาที ⚠️ ([Alphonso Labs](https://www.alphonsolabs.com/web-development-trends-2026/))

→ **ภาพรวม:** Rust tooling (Vite, Rolldown) ยึดชั้น performance, TypeScript/React ยังเป็นมาตรฐาน
