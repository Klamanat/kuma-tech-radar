## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37** — release วางจริง **26 ส.ค. 2026** [official], enhancements ทั้งหมด 86 ตัว มี alpha features 22 ตัว เน้น DRA (Dynamic Resource Allocation) + scheduling + security + storage ([kubernetes.dev — v1.37 timeline](https://www.kubernetes.dev/resources/release/))
- **ข้อเตือนจำเป็น:** containerd ต้องขึ้น 2.0+ ก่อน v1.37, cgroup v1 nodes ที่ยังไม่เซ็ต failCgroupV1: false จะ refuse start [official] ([Kubernetes 1.37 Release Guide](https://cloudsmith.com/blog/kubernetes-1-37-what-you-need-to-know))
- GPU scheduling (Workload Aware Scheduling + DRA) + Kyverno policies ยังเด่น จากรุ่น 1.36 ขึ้นไป ([Kubernetes Enhancements](https://medium.com/@PlanB./kubernetes-1-37-is-coming-the-new-alpha-features-infrastructure-teams-should-watch-550911e39e7b))

→ **เกี่ยวกับงาน tune-keycloak:** DRA + Kyverno ยากปรึกษาทีม SRE

## 🌐 Web / Frameworks / Languages

- **Vite 8 (มีนาคม 2026) ปลดปล่อย Rolldown 1.0 (Rust)** — build เร็ว 10–30x แทน Rollup เก่า [official] ([PkgPulse — Vite](https://www.pkgpulse.com/guides/why-you-should-default-to-vite-for-every-project-2026))
- Nuxt 3 / SvelteKit / Astro / Angular 17+ / SolidStart บอกลา Webpack เล็งไป Vite ทั้งหมด, Vite ขึ้นไป 98% satisfaction ([Tech Insider — Vite vs Webpack 2026](https://tech-insider.org/vite-vs-webpack-2026/))
- **Astro 6 (ก.พ. 2026)** โดย Cloudflare (ซื้อ Astro มกราคม 2026) เพิ่ม component-level caching + รัด runtime fidelity [official]; React ยังครอบ ~45% แต่ Svelte/Astro/Qwik โต ([Luminoid — Framework Comparison](https://blog.luminoid.dev/Web-Framework-Comparison-2026/))
- **Rspack (Rust, ByteDance)** — Webpack-compatible bundler ทำให้ migrate ได้โดยไม่เปลี่ยน config, ความเร็วเข้าใกล้ Vite ⚠️ ([Robin Wieruch — React 2026 Libraries](https://www.robinwieruch.de/react-libraries/))

→ **ภาพรวม:** Rust tooling (Rolldown, Rspack) กำลังทำการเป็นไปได้ให้ build ทั้งหมดเร็วขึ้นแบบ radical ในปี 2026
