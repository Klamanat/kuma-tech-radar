## 🌐 Web / Frameworks / Languages

- **TypeScript 7.0 ไปแบบ Go-native compiler** — ออก July 8, 2026 เร็ว 11.9x ตามเปรียบเทียบ type-checking, compiler written ด้วย Go เอาไว้ strict-by-default ตัด ES5 target + legacy module ([Next.js 16.3 and TypeScript 7.0 article](https://ecorpit.com/nextjs-16-3-typescript-7-rust-go-toolchain-2026/))
- **React Compiler Rust port ควง Turbopack** — Next.js 16.3 (June 29, 2026) นำ experimental Rust port ของ React Compiler เข้ามา, Turbopack dev-server memory ลด 90% บน large apps ⚠️ PR เปิด March, merged June 2026 ([LogRocket — Frontend Wrapped H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/), [React Repository PR](https://ecorpit.com/nextjs-16-3-typescript-7-rust-go-toolchain-2026/))
- **Topcoat framework + NoApi เอา Rust ฉิด web stack** — Topcoat modular batteries-included framework สำหรับ full-stack reactive apps; NoApi combine Axum + React ใช้ server actions + type safety ข้าม Rust↔TS ([Tokio Blog — Topcoat Announcement](https://tokio.rs/blog/2026-07-22-announcing-topcoat), [NoApi Docs](https://docs.rs/noapi/0.1.2)) · Vite 8 + Rolldown 1.0 ทำให้ Rust build tools คร่อม ecosystem ([InfoQ](https://www.infoq.com/React/news/))

→ **ภาพรวม:** Rust ต่อยถึง compiler layer (TS 7.0 ≈ Go, React Compiler ≈ Rust), web tooling ขยับทั้งหมด — performance + observability คือ priority
