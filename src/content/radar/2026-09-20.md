- **React 19.2.8 (21 ก.ค.) + Next.js 16.2.10 (1 ก.ค.) [official]** — React Server Components + Partial Pre-Rendering ลด load time + rendering risks; evolution ต่อเนื่องของ React ecosystem ([FocusReactive — Top React Frameworks](https://focusreactive.com/blog/react-frameworks-to-use/))

- **Svelte/SolidJS ใหญ่สำหรับ performance-critical SPAs** — bundling ขนาดเล็ก, runtime เบา ทำให้ migration จาก React มีเหตุผล ([C-Sharp Corner — Top JS Frameworks](https://www.c-sharpcorner.com/article/top10-javascript-frameworks-to-watch-in-2026/)) ⚠️
