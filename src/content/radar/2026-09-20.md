## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37 ออกตัวจริง** — Release ตั้งแต่ต้นเดือน พร้อมตัวอ่อน KubeletInUserNamespace (runningnode components ตัวแบบ non-root user) และ native histogram support ขึ้น Beta [official] ([kubernetes.io releases](https://kubernetes.io/blog/))
- **KubeletInUserNamespace ขึ้นมา Beta** — ทำให้ node ทั้งหมดรันเป็นผู้ใช้ปกติได้ แทนตัด root ทำให้ security posture ดีขึ้น และ container escapes ยากขึ้น ([Kubernetes 1.37 changelog](https://kubernetes.io/blog/))
- **Native histogram metrics เข้า Beta ใน 1.37** — สนับสนุน Prometheus และ monitoring ที่ละเอียดกว่า ได้เทพตั้งแต่ v1.37 โดยปริยาย ([kubernetes.io releases](https://kubernetes.io/blog/))
- **Kubernetes ใน EU: 8 managed providers พร้อม** — OVHcloud, Scaleway, Exoscale, Infomaniak, StackIt, Open Telekom Cloud, UpCloud, IONOS Cloud ยึดตีกัน 1 มี.ค. 2027 providers ห้ามคิดค่ากระสวย ([Qovery 2026 list](https://www.qovery.com/blog/eu-cloud-providers-managed-kubernetes-2026-sovereignty-checklist/))

→ **เกี่ยวกับงาน:** K8s 1.37 กลับไปตรวจเช็ก non-root nodes ของเรา + histogram monitoring ขยายช่วงความ visibility
