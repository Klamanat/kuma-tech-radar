## 🌐 Web / Frameworks / Languages

- **React Compiler แรง** — React/express/next.js ยังครองสามอันดับแรก npm weekly downloads ที่ 177M/178M/60M ตามลำดับ (1 ต.ค. 2026) [official], React Compiler โหลดหนัก auto-memoize component บันทึกนับพันบัฟเฟอร์ปล่อย ([npm downloads tracker](https://npm.community/))

- **TypeScript ยังมี momentum** — ประมาณ 99.6% type-check parity, next gen TS compiler เขียนด้วย Go (เป้า) ⚠️ ([State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/))

→ **ภาพรวม:** React Compiler ต่อด้วย Rust bundler tooling ยบัยั้ง bundle size อย่างดี; Next.js/SvelteKit ชนะจากด้านการกำหนด feature
