## 🌐 Web / Frameworks / Languages

- **React Compiler ย้ายไป Rust ถูกรวมแล้ว** — Meta ทีม React port React Compiler จาก TypeScript ไป Rust ผ่านการ merge ในมิถุนายน 2026 ทีมประเมินว่าเร็วขึ้นอย่างมีนัยสำคัญ [official] ([blog.logrocket.com](https://blog.logrocket.com/?p=214230))
- **Vite 8 เลือก Rolldown เป็น bundler default** — Rust-based bundler แทน esbuild/Rollup ทำให้ build time ลดลงจากนาที เป็นวินาที ⚠️ ([blog.logrocket.com — Frontend Wrapped](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **Topcoat — full-stack Rust framework ตัวใหม่** — Tokio team ประกาศ Topcoat เมื่อ 22 กรกฎาคม 2026 เป็น server-rendered reactive web app framework พร้อม ORM "Toasty" [official] ([tokio.rs](https://tokio.rs/blog/2026-07-22-announcing-topcoat))
- **Rust frontend frameworks นอกจาก Topcoat** — Leptos, Yew, Dioxus ยังคง mature options ที่ใช้ได้ Dioxus ครอบคลุม web, desktop, mobile, TUI ในโค้ดฉบับเดียว ([reintech.io](https://reintech.io/blog/leptos-vs-yew-vs-dioxus-rust-frontend-framework-comparison-2026))

→ **ภาพรวม:** Rust ยึด JS tooling infrastructure — React Compiler, bundler (Rolldown), framework ecosystem (Topcoat, Leptos) production-ready ทั้งหมด
