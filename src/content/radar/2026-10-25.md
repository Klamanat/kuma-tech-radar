## 🌐 Web / Frameworks / Languages

- **React 19.2 ถูกใช้ production ทั่วไป · React 20 อยู่ในพัฒนา** — ห้องแล็บ React ยังปรับปรุงแบบ incremental; Next.js 16 ได้กลายเป็น full-stack framework ที่ได้รับความพึงพอใจสูงสุด [official] ([React.dev](https://react.dev), [Vercel](https://vercel.com/))
- **Vite กำลังเป็น build tool ที่แนะนำ** — React team และ Next.js ยืนยันให้ใช้ Vite (และ Remix สำหรับเลือกอื่น) แทน Create React App ที่เลิกใช้ตั้งแต่เมษายน 2023 · TypeScript ได้กลายเป็น baseline ของ professional stacks [official] ([React recommendations](https://react.dev/learn/start-a-new-react-project))
- **TypeScript baseline · Next.js dominance** — โปรเจกต์ production ที่นับร้อยพันตัวใช้ TypeScript + Next.js combo · Vue 3.5 และ Angular 21 ยังมีจำนวนผู้ใช้ แต่ React ecosystem เป็นตัวเลือกที่เลือกอย่างกว้างขวาง ⚠️ ([State of JS 2026](https://2026.stateofjs.com/))

→ **ภาพรวม Web 2026:** React + TypeScript + Next.js 16 + Vite มาตรฐาน ขณะ Angular/Vue เป็น alternative
