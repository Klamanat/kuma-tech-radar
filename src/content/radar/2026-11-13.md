- **TypeScript 7.0 ออก** — Microsoft ship compiler native เขียนด้วย Go, ปรับปรุงความเร็ว 8-12x ([State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/)) [official]
- **React ecosystem ตัวใหญ่:** React Foundation launched February 2026 [official], React Compiler port จาก TypeScript → Rust (March 2026, PR #36173) ⚠️ ([LogRocket - Frontend H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **Framework releases:** Next.js 16.2 stable Adapter API (25 มีนาคม 2026), Remix 3 Beta Preview เคลื่อนไป web-standards full-stack, React Navigation 8.0 alpha, TanStack Table V9 beta ([Netlify/LogRocket](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **TypeScript type stripping:** โปรแกรมเขียนที่ใช้ native TS ไม่ต้องผ่าน build step ทั่วไป ([Okoone](https://www.okoone.com/spark/technology-innovation/what-javascript-looks-like-in-2026-and-why-it-matters/)) ⚠️

→ **ภาพรวม:** TypeScript Go compiler + React Rust ption หมายถึง performance tooling เป็นจุดเน้นใหญ่; Remix ทำให้ framework wars ชัดขึ้น
