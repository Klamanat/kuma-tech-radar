## 🤖 AI / LLM / Agents

- **GLM-5.3 Flash ออกจาก Z.AI (26 ส.ค.)** — โมเดลพื้นฐาน GLM-5.3 ออกมา 12 วันก่อนหน้า (14 ส.ค.) ตามด้วย Flash variant เพื่อความเร็วและราคาถูก ตัวแปรนี้ใช้สำหรับกรณีที่ต้องปฏิกิริยาเร็ว ([LLM Gateway — Timeline](https://llmgateway.io/timeline)) [official]

- **ห้อง AI ยังไม่เงียบ: 14 โมเดลใน 8 วิกฤตของสิ้นเดือน** — ตั้งแต่ 5-26 ส.ค. มีการปล่อยรุ่นใหม่จาก Alibaba (Qwen Image 3.0 Pro/3.0 วันที่ 5), Meta (Muse Spark 1.2 วันที่ 6), xAI (Grok 4.6 วันที่ 6), Google (Gemini 3.7 Flash วันที่ 13), DeepSeek (V4 Flash Vision Exp วันที่ 21) ([LLM Gateway — AI Updates](https://llm-stats.com/llm-updates)) [official]

- **ตลาดเร่งตัวสร้าง segmentation ชัดขึ้น** — โมเดลเลขาะแบ่ง flagship (การทำความเข้าใจลึก), flash/express (ตอบสนองเร็ว), vision (xử lý รูป) หนึ่งผู้ให้บริการอาจมี 3-4 ตัวแปร ([Price Per Token — Model Releases](https://pricepertoken.com/news/model-releases)) ⚠️

→ **เกี่ยวกับเรา:** สัญญาณ signal ของ agent/coding tools ต้องตัดสินใจ เรียกไหน — flash สำหรับเร็ว, flagship สำหรับความยุ่งยากระดับสูง

## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37 ออกมาวันนี้ (26 ส.ค. 2026)** — Release ตามกำหนดการ ที่มีการปรับปรุงหลักในเรื่อง Pod eviction coordination (alpha), service account token binding, CompositePodGroup support, และกรณี kubeadm etcd learner promotion ที่แก้ bug ([Kubernetes Contributors — v1.37 Release](https://www.kubernetes.dev/resources/release/)) [official]

- **Docker Desktop สนับสนุน Kubernetes ดีขึ้น** — ปล่อย Desktop ใหม่ที่มี Gordon feedback buttons, ปรับ Kubernetes flows, แก้ bug ให้ docker cloud context ทำงานถูกต้อง, caching Kubernetes (kind) cluster ที่ Enhanced Container Isolation หลังจาก restart ([Docker Release Notes](https://releasebot.io/updates/docker)) [official]

- **Kubernetes 1.34 เข้าโหมด sunset** — เมื่อวานนี้ (27 ส.ค.) Kubernetes 1.34 ได้เข้าโหมด maintenance พร้อม End of Life ที่ 27 ตุลาคม 2026 ใครยังใช้ 1.34 ควร วางแผน upgrade ([Kubernetes — Releases](https://kubernetes.io/releases/)) [official]

→ **ภาพรวม:** Kubernetes ecosystem นิ่ม ไป, Docker desktop ช่วยในการพัฒนา; ต้องแยกคนที่ 1.34 vs 1.37 ใน infra audit

## 🌐 Web / Frameworks / Languages

- **React Compiler port ไป Rust เสร็จแล้ว** — Meta ได้ port React Compiler มาจาก TypeScript ไปยัง Rust เข้า main repository, ลดขนาด build bundle และเพิ่มความเร็ว ขณะนี้อยู่ in production ที่ Meta; Compiler มีการทำ auto-memoization components/hooks ([InfoQ — React Compiler Rust](https://www.infoq.com/news/2026/07/meta-react-compiler-rust/)) [official]

- **Next.js ปล่อย hotfix สำหรับ 2 CVE ร้ายแรง** — ออกวิธีรักษา 16.3.3 และ 15.5.24 สำหรับช่องโหว่ severity critical จำนวน 2 ช่อง; แนะนำใครใช้ Next.js 15 หรือ 16 ให้ update ทันที ([Next.js Blog](https://nextjs.org/blog)) [official]

- **Turbopack Rust bundler เป็น default ของ Next.js 16** — Next.js 16 ทำให้ Turbopack (bundler ที่เขียนด้วย Rust) เป็นตัวเลือก default, ช่วยให้ build และ hot reload เร็วกว่า Webpack มาก ([Rust Web Development Trends](https://rustify.rs/articles/rust-leptos-fullstack-web-2026)) [official]

- **Leptos ขึ้นนิยม fullstack Rust development** — Leptos (framework Rust สำหรับ SSR, fine-grained reactivity, ไม่ virtual DOM) เป็นที่แนะนำสำหรับ new projects ปี 2026 ([Leptos fullstack Rust](https://rustify.rs/articles/rust-leptos-fullstack-web-2026)) [official]

→ **ภาพรวม:** Rust ยึดชั้น performance tooling (React Compiler, Turbopack), JavaScript ยังเป็นภาษาแอปพลิเคชัน แต่ infrastructure เคลื่อนไป Rust อย่างเห็นได้ชัด
