## ☸️ Cloud / DevOps / Infra

- **Kubernetes กลายเป็น default platform สำหรับ enterprise** — สำรวจ 500+ สถาปนิก infrastructure ยืนยัน K8s เป็น cornerstone สำหรับ stateful applications, AI pipelines, และแม้แต่ virtual machines ([portworx — k8s-enterprise-adoption](https://portworx.com/blog/kubernetes-enterprise-adoption-trends/))

→ **ภาพรวม:** Kubernetes 1.37+ กำลังกลายเป็นศูนย์กลางของ AI infrastructure ของ enterprise

## 🌐 Web / Frameworks / Languages

- **TypeScript ครอบครอง 48.8% นักพัฒนา professional** — ความพึงพอใจ 84.1% ในหมู่ผู้ใช้งาน TypeScript ยังคงนำหน้าในระบบ ecosystem ของ JavaScript 2026 ([jetbrains — rust-vs-typescript](https://blog.jetbrains.com/rust/2026/01/27/rust-vs-javascript-typescript/))

→ **ภาพรวม:** TypeScript + React Server Components ยืน market leader; Rust web frameworks ขึ้นมาแข็งตัวแล้ว
