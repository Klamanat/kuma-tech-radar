## 🤖 AI / LLM / Agents

- **OpenAI GPT-6 ซีรีส์ (Astra, Sol, Luna) นำในระดับ benchmark** — Astra นำหน้า coding ที่ 77.2% และ math ที่ 95.1%, แต่ DeepSeek V4 ตัดราคาสำหรับ input ที่ $0.04 ต่อ 1M tokens (vs GPT-6 Astra $3.50) ทำให้สุนทรียศาสตร์ cost/performance เปลี่ยนไป [official](https://zapier.com/blog/best-llm/)

- **Context window race ขยับเป็นล้านโทเคน** — Alibaba Qwen ถึง 1M tokens, Kimi K2.8 ปั่นไปถึง **2.5M tokens** โดยมี "near-flawless retrieval", DeepSeek V4 เล่นที่ 1M ด้วย reasoning + tool use ⚠️ ([LLM Model Tracker](https://lmmarketcap.com/new-ai-models))

- **Google Gemma 4 และ GLM-5.3** — Gemma 4 ออกด้วยขนาดหลากหลาย (256K context), GLM-5.3 ใช้ mixture-of-experts เพื่อ agentic workflows ([AI Model Releases](https://toolpix.pythonanywhere.com/blog/ai-model-releases-tracker-2026))

→ **เกี่ยวกับเรา:** Context window ที่ยาว + reasoning abilities เปิดประตู RAG/document-heavy use cases, GPT-6 ยังคง "safe choice" ส่วน DeepSeek บังคับให้ทบทวนอีกทีว่า frontier ≠ value

## ☸️ Cloud / DevOps / Infra

- **93% ขององค์กรเลือก AI-driven monitoring สำหรับ Kubernetes** — Intelligent tooling ลด MTTR 40% และ cloud bills ได้ถึง 70%, ท่า "FinOps + AI ops" เป็น default ไม่ใช่ optional (official)([Beyond YAML in Kubernetes 2026](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))

- **Platform Engineering (IDP) เป็นหลัก** — องค์กรสร้าง Internal Developer Platforms เป็น product แทนที่ ops-focused infrastructure, ลด cognitive load และบังคับ consistency ให้ application teams ([State of DevOps 2026](https://devnewsletter.com/p/state-of-devops-2026/))

- **Migration deadline เข่ง** — migrate ingress-nginx → Gateway API ก่อน March 2026 retirement, Kubernetes nodes upgrade ไป cgroup v2 + containerd 2.0+ ก่อน v1.36 end-of-life ⚠️ ([K8s Playbook 2026](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

→ **ภาพรวม:** AI ยึดการ monitor/predict, Platform Engineering ขยับจาก tooling-obsessed → product-obsessed, migration debt สะสมเร็ว

## 🌐 Web / Frameworks / Languages

- **Next.js 16.2.10 และ React Router v8.3.0** — Next.js (ไฮบริด JS/TS/Rust) มี stable 16.2.10 (July 2026), React Router v8.3.0 (July 2026), ชี้บ่งว่า React meta-framework ยังไม่ปลดปล่อย [official](https://en.wikipedia.org/wiki/Next.js)

- **Axum 0.8.8 (Rust) ยึดสถานะ default ของ Tower ecosystem** — released Jan 2026, นักพัฒนารุ่นใหม่คืบหน้าจาก Actix-web, เหตุผล: modern async/await integration และ type safety ที่สวยงาม ([Rust Web Frameworks 2026](https://aarambhdevhub.medium.com/rust-web-frameworks-in-2026-axum-vs-actix-web-vs-rocket-vs-warp-vs-salvo-which-one-should-you-2db3792c79a2))

- **Leptos + Astro ขึ้นฉากเต็มตัว** — Leptos = full-stack Rust (SSR + server functions + type safety end-to-end), Astro = island architecture (build-time HTML + selective hydration) ทั้งคู่มี production adoption ⚠️ ([Leptos Full-Stack 2026](https://rustify.rs/articles/rust-leptos-fullstack-web-2026))

→ **ภาพรวม:** Rust ไม่ใช่อพยพหลังสุด แต่กลายเป็น tier-1 tooling (Next.js bundlers, Axum web, build pipeline), TypeScript/React ยังเป็น application default
