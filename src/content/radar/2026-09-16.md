## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37 ปล่อยต้นเดือนกันยายน พร้อม DRA Extended Resource GA** — Dynamic Resource Allocation (DRA) สำหรับ GPU/device ขึ้นมา GA หลังจากสามรีลีส ก่อนหน้า ช่วยให้ DRA drivers จัดการ extended resources แบบเดิมได้โดยไม่ต้องมี device plugin ลวงใจ [kubernetes.io — v1.37 dra updates](https://kubernetes.io/blog/2026/09/03/kubernetes-v1-37-dra-updates/)

- **K8s v1.37 นำมาอื่นๆ ได้แก่ manifest-based admission control beta และ pod-level checkpoint/restore alpha** — ฟีเจอร์เหล่านี้เพิ่มความมั่นคงในการจัดการ cluster scaling และ workload lifecycle ที่ซับซ้อน [thenewstack.io — kubernetes v1.37](https://thenewstack.io/kubecon-kubernetes-updates-security/)

- **Azure AKS ติดตามไปกับ Kubernetes v1.37 preview และเตรียม VMAS deprecation migration** — โปรแกรม auto-upgrader ของ AKS จะเปลี่ยน deprecated Availability Sets clusters ไปเป็น Virtual Machines node pools ตั้งแต่ 30 กันยายน ข้างหน้า managed system node pools เปิด GA สำหรับ AKS Automatic [github.com/Azure/AKS — releases](https://github.com/Azure/AKS/releases)

→ **ภาพรวม:** K8s ecosystem ล็อคเตอร์ GPU scheduling ได้อย่างเป็นทางการ, infrastructure migration story ชัดเจนขึ้น

## 🌐 Web / Frameworks / Languages

- **React Compiler ถูก port เป็น Rust และมี speedup ที่โดดเด่น** — Meta ทำการแปลง React Compiler จาก TypeScript เป็น Rust และแสดงผลความเร็วเพิ่มขึ้น 50% ในบาง benchmark oxc team ได้ proof-of-concept แสดง 17.6x speedup บนโครงการ React Router ขนาด 1,036 ไฟล์ [github.com — react compiler rust](https://github.com/react/react/actions/runs/23817351368)

- **Vite v6.1.0 มาพร้อม experimental native React Compiler support** — นักพัฒนาสามารถเปิด React Compiler ใน Vite config ได้โดยตั้ง { compiler: true } ซึ่งแสดงว่า Rust tooling ต่อเนื่องแทรกลึกเข้า JavaScript ecosystem [infoq.com — meta react compiler rust](https://www.infoq.com/news/2026/07/meta-react-compiler-rust/)

- **Leptos ถึง 1.0 stable เมื่อปลายปี 2025 เป็น React-like framework บนพื้น Rust** — แสดงแนวโน้มที่กว้างขึ้นของการใช้ Rust ในการสร้าง JavaScript tooling เพื่อประสิทธิภาพที่ดีกว่า TypeScript-based alternatives ได้มาตรฐาน [blog.master.dev — react rusted](https://blog.master.dev/react-now-rusted-all-the-way-out/)

→ **ภาพรวม:** Rust ทำให้ toolchain ของ JavaScript/React เร็วขึ้นอย่างจริงจัง, ตอบโต้ปัญหา build performance ที่โปรเจ็กต์ใหญ่ๆ ประสบ
