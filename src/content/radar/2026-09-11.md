## ☸️ Cloud / DevOps / Infra

- **AI/ML workloads เป็น first-class citizen ของ K8s** — MLOps platforms ยิงออกเมื่อต้องประสานบ bursty, resource-intensive Jobs พร้อม high-volume Services บนคลัสเตอร์เดียว ([Pulumi Blog — Kubernetes 2026](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))
- **Platform Engineering กำลังแทนที่ DevOps ดั้งเดิม** — องค์กรหันมาสร้าง Internal Developer Platforms (IDPs) เพื่อซ่อนความซับซ้อน K8s, เปิด portal self-service ให้ devs ใช้ง่าย ๆ ([Fairwinds — 2026 K8s Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- **Multi-cloud + on-premise เป็นค่าปกติใหม่** — deployment ขยายจาก AWS/Azure/GCP รวมไปถึง datacenter เองเพื่อหลีกเลี่ยง vendor lock-in หรือปรับ cost ([Medium — DevOps Tools 2026](https://medium.com/@h.stoychev87/devops-cloud-platform-tools-by-category-for-2026-68ed92103c17))
- **Infrastructure as Code ขยับไปใช้ภาษาจริง** — Pulumi/Terraform ชี้พวกจาก YAML-centric ไปยัง TypeScript, Python, Go, C#, Java ทำให้เขียนและ test ได้ง่ายขึ้น ([Kubeify News — DevOps Sept 2026](https://shyam.kubeify.com/2026/09/latest-devops-cloud-news-10-september.html))

→ **เป้า:** Security/governance/compliance เป็นส่วนเขียนทั้งหมด — secrets management + policy enforcement + vulnerability scanning ที่ทุกชั้น

## 🌐 Web / Frameworks / Languages

- **React Compiler port ไป Rust ปรับปรุง build speed 10-30x** — Meta ย้ายลอจิก React Compiler ส่วนใหญ่จาก TypeScript → Rust, merge เข้า repository หลักแล้ว ทำให้ build ผลิต bundler/toolchain ได้ไวขึ้น ([InfoQ — React Compiler Rust](https://www.infoq.com/news/2026/07/meta-react-compiler-rust/))
- **Rolldown 1.0 ขับ Vite 8 stable ตั้งแต่มีนาคม 2026** — Bundler Rust ใจใจตั้งเป็น default ของ Vite ecosystem (Nuxt/SvelteKit/Astro) แทนท่ีท่อ esbuild/Rollup, build time ลดจาก 2.5 นาที เหลือ 40 วินาที ⚠️ ([JetBrains Blog — Rust vs JS 2026](https://blog.jetbrains.com/rust/2026/01/27/rust-vs-javascript-typescript/))
- **TypeScript ยังคงเป็น lingua franca** — 48.8% ของ professional developers ใช้ TypeScript, 58% ของผู้ใช้ปัจจุบัน admire ภาษา ([Daily.dev — Rust on Web](https://daily.dev/posts/rust-on-the-web-is-starting-to-look-quite-good--yfe0t5npg))
- **React Server Components ยังคงเสถียร** — RSC stable ตั้งแต่ React 19 ออก (ธ.ค. 2024), framework ต่าง ๆ ปล่อย performance-focused updates ต่อไป ([Medium — Best Rust Frameworks 2026](https://medium.com/@priya.raimagiya/the-5-best-rust-frontend-frameworks-reviewed-for-2026-4694dad8f181))

→ **ภาพรวม:** Rust ยึดเครื่องมือที่ต้องประสิทธิ์ (bundler, compiler), TypeScript ยังเป็นภาษาหลักของ application code
