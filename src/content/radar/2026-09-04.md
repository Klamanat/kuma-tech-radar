## 🤖 AI / LLM / Agents

- **Anthropic Fable 5.1 General Availability** — เข้าสู่ GA เมื่อ 1 กันยายน 2026 [official], โมเดล flagship ของ Anthropic พร้อมใช้งานในโปรดัคชั่น ดึงดูดความสนใจจากธุรกิจที่ต้องการความเชื่อถือและความปลอดภัย ([llm-stats.com/llm-updates](https://llm-stats.com/llm-updates))

- **OpenAI GPT-6 Astra Staged Release** — ตั้งราคา $10/$50 ต่อ 1 ล้านโทเคน พร้อมบริบท 1.05 ล้านโทเคน ⚠️, บ่งชี้ว่าตลาด AI ยุคนี้วัดความสำเร็จไม่ใช่จากเบนช์มาร์ก แต่จากความสามารถในการทำงานจริง ([llm-stats.com/ai-news](https://llm-stats.com/ai-news))

→ **เกี่ยวกับเรา:** โมเดลขนาด compact (27B) ออกบ่อยขึ้นเพื่อ edge deployment และผลประกอบการที่ดี

## ☸️ Cloud / DevOps / Infra

- **Kubernetes 1.37 Release** — ปล่อยตัวจริง 3 กันยายน 2026 [official], Dynamic Resource Allocation (DRA) Extended Resource support เข้าสู่ GA, ทำให้ scheduling โหลดงาน GPU และ AI เป็นเรื่องปกติ ([kubernetes.io/blog](https://kubernetes.io/blog/))

- **Horizontal Pod Autoscaling to Zero (Beta)** — API ใหม่สนับสนุนการ scale down workload ลงเหลือศูนย์ replica, เปิดใช้งานแล้วตั้งแต่เริ่มต้น ⚠️, ช่วยประหยัดต้นทุนในสภาวะ bursty traffic ([kubernetes.io/blog](https://kubernetes.io/blog/))

- **AI/ML Operations at Scale (2026 Trend)** — ทีม DevOps เผชิญกับภาระหนึ่งที่ไม่เคยมีมาก่อน: จัดการ bursty machine learning jobs พร้อม continuously running services ในคลัสเตอร์เดียว ([pulumi.com](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))

→ **เกี่ยวกับงาน infra:** DRA GA ช่วยตัดต้นทุน GPU scheduling ลงได้มาก

## 🌐 Web / Frameworks / Languages

- **Rolldown Bundler Reaches v1.0 (May 2026)** — Rust-based bundler สร้างด้วย Rust ทำให้ build เร็วขึ้น 10-30 เท่า [official], ไป live กับ Vite 8 ตั้งแต่มีนาคม 2026 ([vite.dev](https://vite.dev))

- **Next.js + React Server Components (Production)** — Partial Pre-Rendering ลดเวลา initial render จาก 2.4 วินาที เหลือ 0.8 วินาที ⚠️, ตัวเลือกหลักสำหรับทีมที่ต้อง SEO + performance ในคลิกเดียว ([focusreactive.com](https://focusreactive.com/blog/react-frameworks-to-use/))

- **TypeScript Wins — 40% Exclusive** — 40% ของนักพัฒนา JavaScript ใช้ TypeScript exclusively แล้ว [official], ปฐมการณ์ไม่เพียงแต่ type-check แต่ยัง AI tooling เข้าใจโค้ดได้ดีขึ้น ([nucamp.co](https://www.nucamp.co/blog/javascript-framework-trends-in-2026-what-s-new-in-react-next.js-vue-angular-and-svelte))

→ **ภาพรวม:** Rust ยึด build tooling, TypeScript ยึด application dev, Server Components เป็น default thinking
