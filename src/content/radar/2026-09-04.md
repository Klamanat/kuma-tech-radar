## ☸️ Cloud / DevOps / Infra

- **Kubernetes 1.37 autoscaling → zero** — K8s 1.37 API support สำหรับ autoscaling workloads ลงไป zero replicas ขึ้น Beta และเปิด default [official], โมเดลประหยัด cost สำหรับ bursty workload/sandbox ([kubernetes.io/blog](https://kubernetes.io/blog/))
- **GPU ตั้งตัวเป็นแบบต่าง** — Kubernetes เป็น OS layer ของ AI service; CPU/memory เดิม ↓ GPU metrics ↑; ต้องปรับปรุง observability ([Fairwinds — 2026 K8s Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- **Beyond YAML trend** — โปรแกรม automation นอก YAML, Platform Engineering, CI/CD, supply chain security เข้ามาเล่นบทบาท; EU 8 cloud provider สนับสนุน managed K8s control plane ([Pulumi blog](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))
- **AI-assisted DevOps** — FinOps, ความปลอดภัย observability สตอเรจ IDP และเจอว่าประเทศศาสตร์มีส่วน 2026 ⚠️ ([State of DevOps 2026](https://devnewsletter.com/p/state-of-devops-2026/))

→ **เกี่ยวกับงาน tune-keycloak:** autoscaling → zero + GPU metrics ตรงกับปรับ infra edge case

## 🌐 Web / Frameworks / Languages

- **React 19 compiler 25-40% improvement** — React 19 stable ในปี 2566 (19.2.6 ตั้งแต่ พ.ค. 2026) [official], compiler อัตโนมัติจัดการ memoization ลด re-render 25-40% ใช้ production ที่ Meta ([React software — Wikipedia](https://en.wikipedia.org/wiki/React_(software)))
- **Server Components ฝ่าย render time** — React Server Components ลด initial render จาก ~2.4s → 0.8s; server-first architecture กลับมาแรง; metaframework (Next.js/Astro) เป็นจุดเข้า standard ([React in 2026 — DEV Community](https://dev.to/parsajiravand/react-in-2026-start-from-scratch-the-right-way-cheat-sheet-2j9f))
- **TypeScript = table stakes** — TypeScript ชี้ไปว่า baseline สำหรับโปรเจ็คเซอร์เว่ สำเร็จ; AI-assisted tooling (copilot, linters) บ่อยต้องการ TS มีข้อมูลชัดเจน ([Top JS Frameworks 2026 — c-sharpcorner](https://www.c-sharpcorner.com/article/top10-javascript-frameworks-to-watch-in-2026/))
- **Shopify Hydrogen สำหรับ commerce** — Framework ที่สร้างไว้บน Remix, codegen TypeScript อัตโนมัติ, optimize สำหรับ Storefront API ([Best Frontend Frameworks 2026 — quartzdevs](https://quartzdevs.com/resources/best-frontend-frameworks-2026-every-major-javascript-framework))

→ **ภาพรวม:** React 19 + Server Components บังคับการ think server-first; TypeScript/AI tools เป็นการต่อวิวัฒนาการตามธรรมชาติ
