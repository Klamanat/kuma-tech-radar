## ☸️ Cloud / DevOps / Infra

- **KubeCon NA 2026 เสร็จสิ้น** — งาน KubeCon + CloudNativeCon North America จัดในปลายสัปดาห์ที่ผ่านมา 9–12 พ.ย. 2026 ที่ Salt Lake City ตั้งเป้า "AI agents on Kubernetes" เป็นธีมหลัก ([Cloud Native Now - KubeCon Coverage](https://cloudnativenow.com/tag/leanix/))
- **Kubernetes for AI agents** — เจอ initiatives ใหม่ซ่อม K8s architecture เพื่อรองรับ agentic AI workloads เช่น Buoyant's control plane และ CIQ binary packaging (พ.ย. 2–4) ([Cloud Native Now - AI initiatives](https://cloudnativenow.com/))
- **Dapr runtime updated** — Diagrid ปล่อย update เวอร์ชั่น 13 พ.ย. 2026 ให้เหมาะกับ agentic AI era ([Cloud Native Now - Dapr Update](https://cloudnativenow.com/))
- **Wasm on Kubernetes progress** — Cosmonic ชาร์จ sandbox density limit ด้วย WebAssembly บน Kubernetes ทำให้ resource usage ต่ำลง (13 พ.ย.) ([Cloud Native Now - Cosmonic](https://cloudnativenow.com/))

→ **ประมาณ:** K8s ทำให้กลับมาเป็น control plane หลักของ AI workloads ด้วย agent-first architecture

- **React 19.2.x ยังคงเป็นมาตรฐาน** — ที่ล่าสุด React 19.2.8 (ตั้งแต่ กรกฎาคม 2026) ไม่มี major release ใหม่ในเดือนนี้ ⚠️ ([Tech Insider - React vs Vue vs Svelte](https://tech-insider.org/?p=49793))
