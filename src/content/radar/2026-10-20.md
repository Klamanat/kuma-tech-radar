## 🌐 Web / Frameworks / Languages

- **React Compiler Rust edition: March opened, June merged** — ทีม React ยืย port TypeScript logic → Rust เสร็จ หลัง 3 เดือนส่งผลให้ merged ยังเป็น experimental ([Frontend Wrapped H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **TypeScript 6.0 beta ขึ้นดีฟอลต์ strict** — TS6 แนะนำ stricter defaults ส่วน TS7.0 (เป้า late 2026) compiles Go-native สำหรับ ~10x speed boost ⚠️ ([TypeScript 6.0 Beta](https://dev.to/meena_nukala/the-2026-devops-roadmap-what-to-learn-and-what-to-skip-57g7))
- **Vite 8 + Rolldown 1.0 complete Rust shift** — esbuild/Rollup → Rolldown, สิ้นสุด 2-3 นาทีของ build time มีรายงาน อย่างไรก็ตาม ยังต้องวิเคราะห์กรณีใช้จริง ⚠️ ([LogRocket Frontend Wrapped](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))
- **React Foundation officially launched, Yarn 6 preview Rust** — Ecosystem stabilizing + toolchain rewritten ([Reactiflux 2026-02](https://tmir.reactiflux.com/episodes/2026-02))

→ **ภาพรวม:** Rust ยึด production tooling (React Compiler, Rolldown, Yarn) · TS strict-first mindset · RSC + Adapters ป้องกันความปั่นป่วน
