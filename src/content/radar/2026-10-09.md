## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.36 โฟกัส stability และ reproducibility** — เปิดตัวเมื่อเดือนเมษายน 2026 รองรับ GPU scheduling และ fine-grained Kubelet authorization ([Kubernetes releases](https://kubernetes.io/releases/))
- **ingress-nginx retirement เข้าทาง Envoy Gateway** — Kubernetes project ปิด ingress-nginx, CNCF ย้ายไปใช้ Envoy Gateway (เมษายน 2026) ([CNCF announcement](https://www.cncf.io/news/))
- **Kyverno graduated จาก CNCF** — Policy-as-code adoption ขยายตัว เมื่อมีนาคม 2026 ([CNCF news](https://www.cncf.io/news/))
- **AI inference workloads บน Kubernetes เพิ่มขึ้น** — ตลาด GPU scheduling และ cost governance รวมกัน (FinOps convergence) ตลอดภาค 1 2026 ⚠️ ([Cloud Native Now](https://cloudnativenow.com/))

→ **เกี่ยวกับเรา:** Envoy Gateway + Kyverno + GPU scheduling เป็นชุด modern K8s เพื่อ AI/ML workloads

## 🌐 Web / Frameworks / Languages

- **TypeScript 7.0 released** — คอมไพเลอร์เขียนใหม่ (ไม่ได้ Go เหมือนที่คาดไว้), strict-by-default, ตัด ES5 + AMD/UMD + SystemJS ([TypeScript releases](https://www.typescriptlang.org/download/)) [official]
- **React governance restructure** — Pete Hunt และ Nick Schrock เข้า Vercel ดูแล Frameworks/Next และ Agent DX, Leadership Council ใหม่บน React team (กรกฎาคม 2026) ([Reactiflux podcast](https://www.reactiflux.com/)) 
- **Next.js security updates v16.2.11 และ v15.5.21** — ฝ่ายรักษาความปลอดภัยสูง-กลาง หลายประการ, monthly cadence ตั้งแต่ไตรมาส 2 2026 ([Next.js releases](https://nextjs.org/))
- **React stack ปัจจุบัน: React 19.2, Next.js 16, React Router 8** — ESLint v10 ตัด legacy eslintrc, rolldown Rust bundler เริ่มเป็น default ของ Vite ecosystem (สิงหาคม 2026) ⚠️ ([React ecosystem guide](https://www.buildwithmatija.com/))

→ **ภาพรวม:** TypeScript/React พุ่งเข้าสู่ Agent era, security focus ใน Next.js monthly
