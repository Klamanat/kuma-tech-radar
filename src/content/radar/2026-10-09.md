## 🌐 Web / Frameworks / Languages

- **Rust frontend frameworks อดลั่น** — Leptos, Yew, Dioxus ความสาเร็จเท่าเทียม; Leptos fine-grained reactivity (คล้าย SolidJS) ชนะใจ React devs ที่รู้จัก hooks ([Reintech.io Blog](https://reintech.io/blog/leptos-vs-yew-vs-dioxus-rust-frontend-framework-comparison-2026))
- **Rust tooling dominance ต่อเนื่อง** — Rspack, Biome, Turbopack, Bun rewrite พิสูจน์ Rust ยึดชั้น perf-critical tools; Octane (ใหม่, compiled React-like, no VDOM) เข้าม้วนมาหา ([JavaScript Weekly #796](https://javascriptweekly.com/issues/796))
- **noapi: Rust Axum + React fullstack** — type-safe server calls ไม่ต้อง API boilerplate แต่ last release Feb 2025 (0.1.43) สัญญาณว่า small / slow-moving project ([lib.rs](https://lib.rs/crates/noapi))
- **Web framework security spiral:** 52 vulnerabilities ทั่ว Next.js, Remix, React Router เป็นต้น ตั้งแต่ 2025; server logic เสี่ยงสุด ⚠️ ([Netlify 2025 Review](https://www.netlify.com/blog/web-frameworks-2025-year-in-review.md))

→ **ภาพรวม:** Rust framework ecosystem ไม่ได้ "killer React replacement" แต่ niche ตามความเต้น; tooling Rust ปิดช่องว่างกับ JS ecosystem ต่อเนื่อง
