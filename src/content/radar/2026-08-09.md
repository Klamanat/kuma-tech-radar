## ☸️ Cloud / DevOps / Infra

- **Kubernetes = OS สำหรับ AI/ML workloads** — พิมพ์ครั้งแรก เก็บ MLOps platforms, high-volume Services ร่วมกับ Jobs; 80% ขององค์กรคาดว่าจะมี Internal Developer Platforms (IDPs) ในปี 2026 เพื่อลดการดูแลเอง ([2026 Kubernetes Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- **Platform Engineering ทำให้ DevOps chill** — ประเด็นหลักของปี 2026: เรียบง่าย, ปลอดภัยโดยค่าเริ่มต้น, budget mastery; networking ใหม่ (eBPF, Cilium, Istio) เป็นตำแหน่งการแข่งขัน ([Beyond YAML in Kubernetes 2026](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))
- **ภัยครัวเรือน deployment:** 50% DevOps professionals + 1/3 developers เป็น cloud native แล้ว, hybrid/multi-cloud เป็นส่วนแบ่ง ([DevOps Cloud Platform Tools 2026](https://medium.com/@h.stoychev87/devops-cloud-platform-tools-by-category-for-2026-68ed92103c17))

→ **เกี่ยวกับเรา:** K8s + AI workloads หมายถึง infra ต้องรองรับ resource-heavy ML jobs ร่วมกับ traditional services; internal platform docs มีความสำคัญ
