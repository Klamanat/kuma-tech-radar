## 🤖 AI / LLM / Agents

**Kimi K3 จาก Moonshot AI ปล่อยเต็มรูป 27 มิ.ย.** — โมเดล 2.8 ล้านพันล้านพารามิเตอร์ ได้คะแนน Artificial Analysis สูงกว่า Claude Opus 4.8 ที่ release July 16 ตัวน้ำหนัก production ส่งมอบ 27 มิ.ย. ([llm-stats — AI updates](https://llm-stats.com/llm-updates)) ฉันทะว่าต่อเนื่องการปล่อย AI models ทุก 4 วัน โดยแสดงว่าทั้ง Western และ Chinese labs มีความสามารถเพียงพอใกล้เคียงกัน

**Claude Fable 5 พร้อมใช้ 20 มิ.ย. ที่ Max/Team Premium** — Anthropic ขยายโมเดล Fable 5 (รุ่นเล็ก value) ไปยัง Max และ Team Premium แผน 50% ของ usage limits ส่วน Pro/Team Standard ผ่าน credits ([llm-stats — AI news](https://llm-stats.com/ai-news)) กลยุทธ์ของ model specialization ทำให้ผู้ใช้ระดับต่างๆ เข้าถึง frontier tech ที่ cost-efficient

**LLM market acceleration trend** — ทำให้ AI adoption curve เบิกปากกว้าง เพราะ ทีม developer มีตัวจ้าง options มากมาย ([competitive landscape](https://artificialanalysis.ai/models))

→ **เกี่ยวกับเรา:** Fable 5 และ Kimi K3 นำเสนอ trade-off ใหม่ระหว่าง performance vs. cost ที่น่าพิจารณาสำหรับ /learn pathways และ skill generation

## ☸️ Cloud / DevOps / Infra

**KubeCon + CloudNativeCon Japan 29–30 มิ.ย.** — CNCF ประกาศกำหนดการเต็มของงานที่ PACIFICO Yokohama ด้วย 6 track รวม AI, observability, platform engineering [official] ([CNCF Announcements](https://www.cncf.io/announcements/2026/05/13/cncf-debuts-kubecon-cloudnativecon-japan-2026-schedule/)) แสดงว่า CNCF หัวเราะด้าน AI workloads ที่ scale production ซึ่งมี case study จากบริษัท enterprise เช่น Michelin นำ Cilium บน K8s

**Broadcom เป็น Platinum CNCF member 16 มิ.ย.** — ผู้ผลิต infrastructure ใหญ่ระดับแพลตฟอร์มเพิ่มการ commit ให้ Kubernetes ecosystem [official] ([Broadcom CNCF](https://www.hpcwire.com/aiwire/2026/07/16/broadcom-expands-cncf-role-with-platinum-membership/)) แสดงว่า industry consolidation รอบ cloud-native standards ที่ใช้เพื่อปรับแต่ง AI deployment infrastructure

**K8s ecosystem maturity** — GPU scheduling, multi-tenancy, security policies ก่อตัวเป็น production-grade tooling ที่องค์กรเชื่อถือได้

→ **เกี่ยวกับเรา:** tune-keycloak project และ multi-tenant auth patterns อาจนำ Cilium + Kyverno เข้ามาเกี่ยว

## 🌐 Web / Frameworks / Languages

**TypeScript 7.0 General Availability 8 มิ.ย.** — Microsoft release Go-based compiler rewrite ที่ทำให้ VS Code build เร็ว 11.9x (125.7s → 10.6s default, RC shipped 18 มิ.ย.) [official] ([Microsoft TypeScript Blog](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/)) การเปลี่ยนแปลงสถาปัตยกรรมนี้ให้ developer experience ดีขึ้นอย่างกระโดด ประเมิน full-build speedup ทั่วไป 8–12x ข้ามโปรเจกต์

**React 19 patch releases June–July** — React v19.2.7 และ v19.1.8 ออกในเดือน June โดยเน้น bug fixes และ minor improvements ([React versions](https://react.dev/versions)) เสถียรภาพเพิ่มขึ้น ลดความกังวลเกี่ยวกับ regression เมื่อ upgrade

**Web tooling evolution** — Rust-based bundlers (rolldown) และ TypeScript Go compiler เป็นจุดเปลี่ยนจากการอาศัย JavaScript toolchain

→ **ภาพรวม:** TypeScript 7 + React 19 stability = workflow modern ที่เร็วและเชื่อถือได้ เพียงพอสำหรับทั้ง enterprise ใหญ่และ startup

## 🚀 Startups / Products

**Together AI หา Series C $800M, valuation $8.3B** — San Francisco startup ยืนยัน Series C ที่ lead โดย Aramco Ventures (post-money $8.3B) ⚠️ ([Crunchbase Venture](https://news.crunchbase.com/venture/biggest-funding-rounds-ai-energy-biotech-joulent/)) platform สำหรับ deploy open-source AI models ขนาดใหญ่ ทั่วสื่อสารว่า Aramco นำ Series C ใหญ่สุด 2026 ทำให้เห็นได้ว่า energy sector hedge-bet on open models เป็นต่อต้านอำนาจของ proprietary LLMs

**Joulent (energy + AI) หา $1.75B financing** — Houston-based startup ปิด strategic round $1.75B ซึ่งเป็นใหญ่สุดที่มองเห็นในข้อมูล July funding ⚠️ ([Crunchbase](https://news.crunchbase.com/venture/biggest-funding-rounds-ai-energy-biotech-joulent/)) ทุนไหลไปยัง real-world AI applications (grid management, energy optimization) แทนที่จะเป็น pure SaaS ทำให้เห็นว่า venture capital มี operator mindset มากขึ้น

**Investor preference shift** — ทั้งสอง rounds แสดง capital ว่า shift ไปยัง infrastructure (open-source stack) กับ operationally-integrated AI (energy, physical systems) อย่างมากขึ้น

→ **สรุป:** ทุนสตาร์ทอัพ 2026 focus ที่ infrastructure + real-world problems, ไม่ได้แค่ LLM apps
