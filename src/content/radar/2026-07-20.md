## 🤖 AI / LLM / Agents

**Kimi K3 (Moonshot AI) ขึ้นท็อป LLM ใน 4 วัน** — ปล่อยจริง 16 ก.ค., โมเดล 2.8T parameter, ขึ้นแซง Claude Opus 4.8 ใน Artificial Analysis ranking ทันที แม้ open weights ยังไม่ออกถึง 27 ก.ค. ตัวแสดงว่าจีนยังมีความเร็ว frontier model research ไม่แพ้ Western labs ([AI Flash Report model releases](https://aiflashreport.com/model-releases.html)) [official]

**โมเดลใหม่ออกเฉลี่ย ~ทุก 4 วัน** — ลดจากชั่วโมง 2 วันในเดือนที่แล้ว, 54 โมเดล track ใน 90 วันสุดท้าย, ตลาดยังหนาแน่นเพิ่มลึก กลุ่ม coding/agent models เชื่อมตรงกับบทบาท authoring ของ SKILL.md และ /learn ([LLM Gateway timeline](https://llmgateway.io/timeline)) [official]

**GLM-5.2 (Z.ai/Zhipu)** — open-source ชนะ benchmark, 744B MoE, GPQA Diamond 91.2%, SWE-bench Pro 62.1%, ออก open weights 16 มิ.ย. แสดงจีน open-source infra รุ้งใจชิง ([LLM Stats](https://llm-stats.com/ai-news)) [official]

**Grok 4.5 เตรียมขึ้นสาธารณะ** — xAI beta ที่ SpaceX/Tesla เมื่อ 28 มิ.ย., 1.5T V9, monthly release cadence หมายถึง July เป็นหน้าต่างมั่น ⚠️ ([LLM Stats](https://llm-stats.com/llm-updates))

→ **เกี่ยวกับเรา:** Kimi K3 ชี้แจงตลาด coding-class โมเดล accelerate, open-source GLM-5.2 แข่ง proportional ของ market

## ☸️ Cloud / DevOps / Infra

**Kubernetes 1.35 DRA ขึ้น Beta** — Dynamic Resource Allocation นำเสนอ binding conditions, ช่วยคนเขียนจัดการ AI/ML workloads หลากหลาย ใหญ่/เล็ก ไป compute สาธารณะ ท้าดี GPU scheduling + Workload Aware Scheduling เข้าเสถียรใน 1.36 ([Kubernetes.io blog](https://kubernetes.io/blog/)) [official]

**Edge Kubernetes grow ชั่วสปั้นดังเดิม** — 34% ของ deployment ทั้งหมด วิ่งที่ edge (Raspberry Pi, Jetson boards, K3s), ลดเบา server-centric view, ท้าดี Kube-Wasm graduation นำ WebAssembly cold start ลดไป milliseconds จาก 100s ms ([Kloudping cloud trends](https://kloudping.com/cloud-computing-trends-july-2026)) [official]

**AI agents/principals ไต่ขึ้นบน cloud-native** — Service principals/API keys/AI agents outnumber humans roughly 100:1 แล้ว, identity/auth patterns shift มากชั้น ([Cloud Native Now](https://cloudnativenow.com/contributed-content/cloud-natives-interest-payment-just-came-due/)) ⚠️

**Internal Developer Platforms (IDPs) 80% adoption projected** — 45% ไป 80% ใน 2 ปี, platform engineering ยืนแท่นกลาง K8s use-case ([Fairwinds 2026 playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth)) ⚠️

→ **ภาพรวม:** K8s ไม่ใช่แค่ orchestrator ของ services แล้ว → ฐานการนำไปใช้ AI workloads ทั้งหมด + edge + identity-first infrastructure

## 🌐 Web / Frameworks / Languages

**React Compiler v1.0 stable ออก Oct 2025 แล้วเสริมโมม** — Optimize component/hook อัตโนมัติ, ใช้ production ที่ Meta เรียบร้อย, ลด manual memoization burden ([React.dev blog](https://react.dev/blog/2025/10/07/react-compiler-1)) [official]

**TypeScript ทีจริงแล้วเป็นค่าเริ่มต้น** — ตั้ง Aug 2025, TS เป็นภาษา top ของ GitHub by contributor, 2026 ถือเป็นเส้นแบ่ง: ทีมมืออาชีพ = TypeScript ใช่มั้ย, Angular + Next.js มี friction ต่ำสุด ([Nucamp JavaScript framework trends](https://www.nucamp.co/blog/javascript-framework-trends-in-2026-what-s-new-in-react-next.js-vue-angular-and-svelte)) [official]

**React นำ ~45% ตลาด, แต่ Svelte/Astro/Qwik ไต่ขึ้น** — ความเร็ว Core Web Vitals เรียก, Next.js ยืน API ที่มัน, TanStack Start เติบโต 600K → 14M weekly downloads (Apr–Jun 2026) เกือบจับ Next.js ส่วนแบ่ง ([Best Frontend Frameworks 2026](https://www.quartzdevs.com/resources/best-frontend-frameworks-2026-every-major-javascript-framework)) ⚠️

**Web frameworks converge on 4 themes** — fine-grained reactivity, server-first rendering, compiler-driven optimizations (TypeScript baseline), AI-assisted workflows ([Coderio web dev](https://www.coderio.com/blog/software-development/guide-frontend-frameworks-2026/)) ⚠️

→ **บทสรุป:** TS ยืนหลัก application layer, React Compiler ลดเบา manual optimization, web framework ecosystem ไหลเข้า server-first + compiler-driven + AI-copilot patterns
