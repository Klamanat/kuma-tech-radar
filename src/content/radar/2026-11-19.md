## ☸️ Cloud / DevOps / Infra

- **KubeCon + CloudNativeCon North America 9–12 พ.ย. Salt Lake City** — งานใหญ่ CNCF ปีนี้กำลังจะผ่านไป ตอนเข้าวันจันทร์นี้ [official] — focus จะเป็น AI workloads, platform engineering, security ([KubeCon + CloudNativeCon America 2026](https://cloudnativenow.com/tag/leanix/))

- **GKE & AWS EKS แข่งขันบน AI features** — ใครสามารถให้ user วาง LLM inference + training workload ได้ง่ายที่สุด ก็ชนะ; both clouds มี multi-node job support และ spot instance optimization [official] ⚠️ — ส่งผลให้ startup ที่ทำ AI infra tools ต้องเลือกใช้ Kubernetes เป็นแคนวาส ([InfoQ DevOps News](https://www.infoq.com/Devops/news/16/))

→ **ภาพรวม:** AI workload orchestration ผลักดัน Kubernetes adoption ต่อ; control plane ปรับตัวด้วยเร็ว

- **React Compiler ยังเป็นหลัก Meta backend** — ตั้งแต่ production deployment เต็มที่ต้นปี 2025 ก็ยังเป็นมาตรฐาน [official] — component revalidation ตัดได้ 30–50% ระหว่างไป ([react.dev — React Compiler 1.0](https://react.dev/blog/2025/10/07/react-compiler-1))

→ **บทสรุป:** Rust tooling consolidation ชัด; framework landscape ยังอยู่ equilibrium ไม่เข้าทาง one-true-way
