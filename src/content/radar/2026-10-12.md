## 🤖 AI / LLM / Agents

- **Agent Protocol ยืนหยัดเป็นมาตรฐาน** — Meta, Stripe, Shopify ประกาศร่วมกัน (6 ต.ค.) OpenAI และ Mistral ออกอัปเดตเสริมพร้อมกัน เพื่อสร้างมาตรฐานบนการทำงานของ agents ข้าม platforms ([Upcoming AI Updates in October 2026](https://www.thehansindia.com/tech/upcoming-ai-updates-in-october-2026-major-developments-to-watch-1127036) [official])
- **UiPath Agent ต่อโค้ด Python ได้จริง** — Agents สามารถเรียกใช้ฟังก์ชัน Python deterministic เป็น tools พร้อม LLM-as-judge guardrails ตรวจสอบ input/output เพิ่มความปลอดภัยและ controllability ([UiPath Release Notes](https://docs.uipath.com/agents/automation-cloud/latest/release-notes/september-2026.md) [official])
- **โมเดลใหญ่โตออกต่อเนื่อง** — ต้นเดือนนี้: GPT-5.6, Claude Opus 5, Gemini 5.6 Flash · Gemini 4 ในช่วง post-training คาดออกก่อนปีจบ ([September 2026 Global LLM Landscape](https://www.besthub.dev/articles/september-2026-global-llm-landscape-beyond-capability-to-agent-cost-long-horizon-tasks-b71d23a007ac) [official])

## ☸️ Cloud / DevOps / Infra

- **Google Kubernetes 1.34 สิ้นชีวิตวันนี้ 28 ต.ค.** — GKE 1.34 ถึง end-of-life วันนี้ ต้องอัปเกรดไป 1.35+ เพื่อรับ security patches และ support ต่อเนื่อง ([October 2026 End-of-Life Timeline](https://endoflife.date/timeline/2026/10/) [official])
- **Kubernetes v1.36.3 — ความเสถียรสำหรับ production** — released 23 ก.ค. เซ็ทอัปเดต scheduler, kubelet, server-side apply ตัวต่อตัว เหมาะสำหรับการใช้ในเชิงพาณิชย์ ([Kubernetes Release Notes](https://releasebot.io/updates/kubernetes) [official])
- **etcd v3.7.0 ให้บริการ K3s ต่อ** — released กรกฎาคม K3s v1.36.1+k3s1 ขึ้นไป ใช้ etcd 3.7.0 แล้ว สถานะเสถียรและปลอดภัย ([K3s v1.36 Release Notes](https://docs.k3s.io/zh/release-notes/v1.36.X) [official])

→ **ภาพรวม:** ตรวจสอบ K8s version ที่ใช้เพื่อหลีกเลี่ยง EOL · etcd 3.7.0 ใช้ได้เต็มที่ใน K3s

## 🌐 Web / Frameworks / Languages

- **TypeScript 7 โปรแกรมโดย Go — เร็ว 10x** — Project Corsa (Microsoft rewrite) ทำให้ strict mode build เร็วขึ้นในลำดับห้าเท่า เปลี่ยนภาษา compiler จาก TypeScript เป็น Go ([InfoQ TypeScript News](https://www.infoq.com/TypeScript/news/) [official])
- **Nuxt 4.2 + ReScript 12.0 อัปเดต** — Nuxt เพิ่ม native request cancellation สำหรับ data fetching · ReScript 12.0 เปิดตัวระบบ build เขียนใหม่เพื่อให้ performance ดีขึ้น ([InfoQ Web Development](https://www.infoq.com/Web-Development/news/246) [official])
- **React Best Practices + Warper 7.2 virtualization** — Vercel ปล่อย react-best-practices repository เกือบ 40 กฎสำหรับ React/Next.js optimized สำหรับ AI coding agents · Warper 7.2 (React virtualization ด้วย Rust/WebAssembly) พัฒนาต่อ ([React Ecosystem Updates](https://www.infoq.com/Web-Development/news/246) ⚠️)

→ **ภาพรวม:** Go ยึดทางการก่อสร้าง tooling · Rust บ่อน virtualization สำหรับ React · ทำให้ web tooling เร็วขึ้นจริง
