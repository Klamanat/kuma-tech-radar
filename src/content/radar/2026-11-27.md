## 🤖 AI / LLM / Agents

- **Anthropic Claude Haiku 5.5, Sonnet 5.5, Opus 5.5** — ตระกูล Claude ได้รับ update รุ่น 5.5 เมื่อต้นเดือน Fable 5.2 มาพร้อม reasoning และ agent work ขั้นสูง ทำให้จำนวน released models พุ่งขึ้นจนถึง 22 รุ่นในครึ่งแรกของเดือน ([AI Model Releases News Nov 2026](https://blog.mean.ceo/new-ai-model-releases-news-november-2026/))

- **Google Gemini 4 Carbon และ Argon** — Google เปิดตัว Gemini 4 Carbon (10 พ.ย. 2026) และ Argon series ด้วยราคาแข่งขัน $2/$10 เน้นประมวลผลสถาปัตยกรรม carbon-aware ([Capital and Compute — Model Releases](https://capitalandcompute.net/md/new-ai-models-november-2026.md)) ⚠️

- **xAI Grok, DeepSeek, Tencent** — กลุ่ม emerging models ประกอบด้วย Grok 4.7 (Sep 21) DeepSeek V4.1 Flash (Oct 17) และ Tencent Hy4 flash API (Nov 16) แสดงการแข่งขันสูงในตลาด LLM ที่เร่งตัวต่อเนื่อง ([AIBusiness Weekly LLM List](https://aibusinessweekly.net/p/list-of-llms))

→ **เกี่ยวกับเรา:** Fable 5.2 ถูกออกแบบสำหรับ reasoning tasks และ agent loops ที่สอดคล้องกับงาน /learn flow

## ☸️ Cloud / DevOps / Infra

- **Google Cloud 130,000-node GKE cluster** — Google продемонстрирует Kubernetes scalability ด้วย GKE cluster ขนาด 130,000 nodes ซึ่งเป็นข้อมูล significant สำหรับการวางแผน infrastructure ของ distributed systems ([Google Cloud Kubernetes Scale Demo](https://www.infoq.com/Kubernetes/news/)) [official]

- **Kubernetes 1.35 AI-optimized scheduling** — K8s 1.35 มีฟีเจอร์ in-place pod resizing และ AI-oriented scheduling ขึ้นมา สนับสนุนการปรับทรัพยากร compute แบบ dynamic บนคลัสเตอร์ที่มี GPU หรือ accelerators ([InfoQ Kubernetes News](https://www.infoq.com/Kubernetes/news/))

- **Salesforce EKS + Karpenter scale** — Salesforce ย้าย 1,000+ EKS clusters ไปใช้ Karpenter สำหรับการ auto-scaling ที่เร็วขึ้น และประหยัด cost ([Salesforce Kubernetes Migration](https://www.infoq.com/Devops/news/)) ⚠️

- **HashiCorp Terraform MCP Server** — HashiCorp ปล่อย Terraform MCP server (open-source) ให้ LLMs และ agents โต้ตอบกับ infrastructure-as-code ได้มีประสิทธิภาพ ([Terraform MCP](https://www.infoq.com/Web-Development/news/))

→ **ภาพรวม:** Kubernetes scale ถึง 100K+ nodes โดยมี AI scheduling first-class support ทำให้ infrastructure ที่มี accelerators จัดการได้ดีขึ้น

## 🌐 Web / Frameworks / Languages

- **React Compiler: TypeScript → Rust port** — Meta's React team ทำ experimental port ของ React Compiler จาก TypeScript มาเป็น Rust (เริ่มมีนาคม 2026) และ integrate ลงใน main repository แล้ว goal คือเพิ่มอัตราประมวลผล optimization ([LogRocket Frontend Wrapped H1 2026](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))

- **Topcoat: full-stack Rust framework** — Tokio ประกาศ Topcoat (22 กรกฎาคม 2026) framework ใหม่สำหรับสร้าง reactive full-stack apps ด้วย Rust compile ลงเป็น JavaScript หรือ server-rendered reactivity ผ่าน cross-compiled Rust expressions ([Tokio Topcoat Announcement](https://tokio.rs/blog/2026-07-22-announcing-Topcoat)) [official]

- **TypeScript 7.0 native Go compiler** — Microsoft ปล่อย TypeScript 7.0 มีการเขียน compiler ใหม่ด้วย Go แล้ว นอกจากนี้ Rolldown (Rust bundler) และ Vite's Rust-based tooling เข้ามาแทน esbuild/Rollup เรื่อย ๆ ([InfoQ TypeScript News](https://www.infoq.com/Web-Development/news/)) [official]

- **Rust web frameworks เด่น** — Axum และ Actix Web ยังคงเป็นตัวเลือกหลักสำหรับ performance/safety-critical services; Remix 3 Beta ก้าวย่างเข้าสู่ web-standards full-stack framework ที่ไม่เน้นเพียง React ([Sencha Web Dev 2026 Guide](https://www.sencha.com/blog/web-application-development-top-frameworks/)) ⚠️

→ **ภาพรวม:** Rust ยึดเข้ามาคุมการทำงาน compiler/tooling ของ web stack (React Compiler, TypeScript, bundlers) ทำให้ developer experience และ build performance ดีขึ้น
