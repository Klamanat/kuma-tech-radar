## ☸️ Cloud / DevOps / Infra

- **Kubernetes เป็นชั้นสำหรับ AI workloads (MLOps) แบบใหญ่** — แนวโน้ม 2026 Kubernetes cluster ตั้งแต่มี 3 เดือนมา: Heavy-lifting ML training jobs + continuous inference services ทำงานบน K8s ไม่ใช่ dedicated GPU box แล้ว [official](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth) · Infrastructure-as-code + policy enforcement (Kyverno) + AI-driven orchestration ทำงานรวมกัน ([Pulumi + Fairwinds reports](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))
- **GA milestones:** Dynamic Resource Allocation v1.34, In-Place Pod Resize v1.35 — ช่วย MLOps scaling โดยไม่ restart pod [official](https://kubernetes.io/blog/) · อย่างไรก็ตาม **IngressNightmare security bug เผยแพร่ 43% ของ K8s environments ⚠️** ([Fairwinds/The New Stack](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- Agenda Q4 2026: DevOps teams นำเข้า self-healing clusters (AI-native SRE) และ observability-at-scale เพื่อรับมือ MLOps complexity

→ **ระวัง:** K8s ยังเป็นเป้าด้านความปลอดภัย · ก่อนขึ้นสำหรับ MLOps ต้องฉายแบบระวัง + network policy

## 🌐 Web / Frameworks / Languages

- **React Compiler Rust port — 3x ความเร็ว, 10x ในแกนกลาง** — Meta ผ่านการ port logic React Compiler เข้า Rust (compile time, ไม่ runtime) ได้ merged ในต้นปี 2026, @vitejs/plugin-react v6.1.0 ขึ้นแล้ว [official](https://www.infoq.com/news/2026/07/meta-react-compiler-rust/) · Developer รายหนึ่ง report 17.6× speedup บน compiler phase ตั้งแต่เปิด flag ([Rust Bytes, Blog.master.dev](https://weeklyrust.substack.com/p/reacts-compiler-just-went-full-rust))
- **Rust ยึด toolchain deeper** — SWC ไป full Rust, Oxc vendoring releasable crates, Rspack 2.1 native support [official](https://rustify.rs/articles/rust-vs-typescript-full-stack-2026) · Leptos (React-like Rust framework) 1.0 stable ตั้งแต่ปี 2025 หลัง · ทำให้ full-stack Rust หรือ TS app + Rust/WASM module (compute-heavy) มี ecosystem ที่แข็งแรง
- Application layer ยังคง TypeScript เป็นหลัก · Rust ขึ้นต่อ compilation/bundling/transform — ลดโหลด JavaScript ด้าน CPU-bound

→ **สรุป:** React Compiler 3–10× ประกายก่อให้คนลองใช้งาน Rust tooling · TS ยืนแบบ app layer, Rust ยัง infra/perf layer
