- Google Gemini 3.5 Flash, xAI Grok 4.3, Mistral Medium 3.5 / Large 3 เข้าจังหวา ⚠️ ([LLM Stats — rankings](https://llm-stats.com/ai-news))

## ☸️ Cloud / DevOps / Infra

**DataAgent ออกจากแบบปกป้องตัวกับทุน $10 ล้าน pre-seed** — บริษัทใหม่มุ่งระบบ AI-native สำหรับแก้ปัญหา production ใน Kubernetes โดยไม่ต้องรอ SRE ทำความเข้าใจความต้องการก่อน ความเร็วตอบสนองอัตโนมัติคือจุดขาย ([LLM Gateway — startup news](https://llmgateway.io/timeline))

**CrowdStrike ขยายสนาม Supply Chain Security** — บริษัท Falcon ปล่อยเครื่องมือบล็อกแพคเกจ open-source อันตรายตั้งแต่ endpoint ก่อนรันโค้ด ทำให้ลด surface attack ใน dependency chain ([The New Stack — DevOps](https://thenewstack.io/))

- MLOps workloads บน Kubernetes ขยายตัว ต้องประสานงาน bursty Jobs กับ continuous Services ⚠️ ([DevOps playbook 2026](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

## 🌐 Web / Frameworks / Languages

**Rolldown (Rust bundler) v1.0 ขับ Vite 8 เร็ว 10-30x กว่า Rollup [official]** — bundler ใหม่เขียนจาก Rust ที่เปลี่ยน default ใน Vite ecosystem ทำให้ build รวบรวมมีประสิทธิภาพเพิ่มมากขึ้น นักพัฒนา Next.js / Nuxt / SvelteKit / Astro จะได้ประโยชน์ไปไหน ([Vite ecosystem — bundler](https://strapi.io/blog/best-javascript-frameworks))

**TypeScript ยังเป็นภาษา gold standard ของ frontend** — 48.8% ของนักพัฒนา professional ใช้ TypeScript ตามสำรวจปี 2025 ยังไม่มีภาษาไหนชิงชั่งตำแหน่ง ⚠️ ([Stack Overflow survey 2025](https://blog.jetbrains.com/rust/2026/01/27/rust-vs-javascript-typescript/))

- **Leptos** (Rust full-stack) สำหรับ new projects, **Yew** (oldest, 30K+ stars) สำหรับ community, **Dioxus** (write-once-run-everywhere: web/desktop/mobile/terminal) ([Rust Web Frameworks 2026](https://medium.com/@priya.raimagiya/the-5-best-rust-frontend-frameworks-reviewed-for-2026-4694dad8f181))

→ **ภาพรวม:** Rust ยึดชั้น tooling ต้องการสัมฤทธิผล (bundlers, language servers), TypeScript คงเป็นภาษาหลักของ application
