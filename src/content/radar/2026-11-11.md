## ☸️ Cloud / DevOps / Infra

- **KubeCon + CloudNativeCon North America ครั้งที่ 16 เปิดฉากอยู่ (Nov 9–12, Salt Lake City)** — 3,000+ ผู้เข้าร่วม, agenda แน่นกับ AI scheduler + workload identity protocols [official](https://www.cncf.io/page/2/?post_type=post)

- **Kubernetes สำหรับ AI: CIQ เปิดตัว Stratum Engine** — Stratum บรรจุ GPU scheduler + workload orchestration เป็นไบนารีเดียว ต้องการตอบสนองความเร็วในโครงการวิทยาศาสตร์ข้อมูลขนาดใหญ่ [official](https://cloudnativenow.com/tag/gpu-infrastructure/)

- **GPU scheduling ปัญหาสำคัญ ไม่ใช่ AI เอง** — ความจุ GPU นับสิบ พันเมื่อเทียบกับจำนวนจ่อออก: Kubernetes ต้องลำดับงาน affinity ล้ำหน้า ทำงบประมาณทำงานใหญ่ ⚠️ [analysis](https://www.cncf.io/page/2/?post_type=post)

- **Workload identity + multi-cluster GitOps (Argo CD) ข้ามศูนย์ข้อมูล** — องค์กรเคลื่อนจาก ingress-nginx ไป Gateway API ตั้งแต่ Oct 2026, identity federation เชื่อมต่อ Kubernetes ที่ protocol-level [tracker](https://cloudnativenow.com/category/topics/container-ecosystems/)

→ **ภาพรวม:** Kubernetes ปรับตัวให้ AI-ready ผ่าน GPU scheduler + identity federation, อีกด้านหนึ่ง gateway API/Argo CD เป็นหมวดหมู่ production-grade

## 🌐 Web / Frameworks / Languages

- **Tokio Topcoat (Rust full-stack, ก.ค. 2026)** — framework modular ใช้ Rust เรนเดอร์ server-side reactive apps โดยไม่ต้อง WASM ที่ browser; เป้าหมายสำหรับแอปปกติที่ไม่ต้องการ client-side interactivity หนัก [official](https://tokio.rs/blog/2026-07-22-announcing-topcoat)

- **React Compiler ไปทาง Rust (ส.ค. 2026)** — Meta ย้ายตรรมชาติการ optimize hooks/components ไป Rust แทน TypeScript ได้รับโปรแกรมทดลองแล้ว PR (มี.ค.) ยังเผยแพร่อยู่ [tracker](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/)

- **TypeScript 7.0 compiler เขียนด้วย Go** — ออกแบบทำให้ strict-by-default, ตัดความสอดคล้อง ES5 + AMD/UMD/SystemJS, type-check parity ~99.6% เทียบกับ 6.x [official](https://devnewsletter.com/p/state-of-typescript-2026/)

- **React 19.3.0 (ก.ย. 2026) + Rust Leptos/Dioxus/Yew ยังมีส่วน WASM** — React อัดปิด enhancements, Rust frameworks ยังตัวเล็กใน production นี่คือ Leptos/Dioxus ที่ 0.005% market share ⚠️ [tracker](https://www.wmtips.com/technologies/frontend-frameworks/filter/rust/)

→ **ภาพรวม:** Rust ขยายตัวเข้า tooling (TypeScript, React Compiler, Topcoat), JavaScript framework หลักเหมือนเดิม ไฟเพิ่มขึ้นใน server-rendered + edge computing
