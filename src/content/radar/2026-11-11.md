## ☸️ Cloud / DevOps / Infra

- **Kubernetes ยังคงเป็นศูนย์กลางโครงสร้าง AI** — 82% ของผู้ใช้ container รันทำการ Kubernetes ใน production ตอนนี้ และ CNCF พบว่า enterprise มองว่า K8s เป็นรากฐานสำหรับการขยายงาน AI workloads ([CNCF Survey](https://www.devopsdigest.com/hot-topic/containersk8s))
- **AWS ปล่อย Amazon EKS Capabilities** — ชุด Kubernetes-native features ที่ fully managed มาช่วยให้องค์กรลดค่าควบคุมและปรับแต่ง autoscaling ได้ง่ายขึ้น ⚠️ ([InfoQ — DevOps](https://www.infoq.com/Devops/news/))
- **ค่าใช้จ่าย K8s ยังสูง:** 98% ของผู้นำ IT ว่า Kubernetes ขับเคลื่อน cloud spend แต่ 91% ยังพบว่าเพิ่มประสิทธิภาพได้ยาก แม้อัตโนมัติ scaler เช่น Karpenter นิยมขึ้นเรื่อยๆ ⚠️ ([Cloud Native Now](https://cloudnativenow.com/))

→ **ทำเข้า:** K8s cost optimization เป็นจุดเด่นทั่วโลก ทีม DevOps ควรเลือก scaler และ cost-watch tool ให้ถูก

## 🌐 Web / Frameworks / Languages

- **React Foundation อยู่ใต้ Linux Foundation** — ตั้งแต่ 24 กุมภาพันธ์ 2026 React ได้ผู้สนับสนุนอย่างเป็นทางการ หมายถึงความเสถียรและ roadmap ยาวเหนือสำหรับ framework หลัก ([Syncfusion — React 2026](https://www.syncfusion.com/blogs/post/5-react-alternatives-frontend-dev-2026.md))
- **React 19.2.8 + TypeScript 7 ผ่านตัด ES5** — React ได้อัพเดตเสถียรตั้งแต่ 21 กรกฎาคม 2026 ด้วย React Server Components ที่เร็วขึ้น ส่วน TypeScript 7.0 ตัด ES5 target และ AMD/UMD module ให้สะอาดเกินไป ⚠️ ([Builder.io — React AI Stack 2026](https://builder.io/blog/react-ai-stack-2026))
- **Next.js 16 + full-stack TypeScript set:** Next.js 16 นำสัญลักษณ์ frame ภายใน ecosystem ด้วย Payload CMS, TanStack Start, React Router 8 ทำให้ build time เร็วขึ้นกว่าเดิมประมาณ 70% จากรายงาน ⚠️ ([BuildWithMatija — React Ecosystem 2026](https://www.buildwithmatija.com/blog/md/react-ecosystem-2026-frameworks-platforms-typescript-stack))

→ **ภาพรวม:** TypeScript ยังคงหลักของ application, Next.js ครอบงำบ้าน React, ES5 ถูกแล่แหลกในใหม่อย่าง TypeScript 7

→ **ที่เห็น:** venture capital ยังไม่ลดลง แต่หันจาก "demo models" ไป infrastructure (fal), unique markets (Kalshi), และ hard tech อย่างต่อเนื่อง
