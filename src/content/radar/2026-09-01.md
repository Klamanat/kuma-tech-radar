## ☸️ Cloud / DevOps / Infra

- **84% องค์กรใช้ containerized apps ใน production** — Kubernetes และ Docker เป็นปัญหาทั่วไปในสถาน enterprise โดยค่าธรรมชาติ K8s ทำหน้าที่ orchestration ส่วน Docker สร้างและรัน containers ([Container Predictions 2026](https://www.devopsdigest.com/2026-container-predictions))
- **Kubernetes เป็น de facto standard** — ระบบการจัดตั้งค่า scheduling, scaling, networking, health checks, rolling updates อัตโนมัติ องค์กรเกือบทั้งหมดเลือก K8s โดยปี 2026 ([DevOps Guide 2026](https://techjacksolutions.com/cloud-tools/devops/))
- **Containers + Platform Engineering + CI/CD** — Containers คือรากฐาน cloud-native application delivery พร้อม integration ที่สมบูรณ์กับ K8s, platform engineering workflows, CI/CD pipelines, supply chain security ([Kubernetes Production Guide](https://precisionaiacademy.com/blog/kubernetes-guide-2026))
- **K8s และ serverless ครองอันดับ IT roadmap** — องค์กรให้ความสำคัญกับคู่งานนี้เพื่อ innovate nhanh พร้อมปรับใช้ resource อย่างมีประสิทธิ ([DevOps Engineering 2026](https://www.refontelearning.com/blog/devops-engineering-in-2026-navigating-new-trends-tools-kubernetes-k3s-best-practices))

→ **ภาพรวม:** Container orchestration ยังคงเป็นพื้นฐาน K8s โดยไม่มีสิ่งอื่นใด serverless เริ่มเป็นอีกประเด็นหนึ่ง
