## ☸️ Cloud / DevOps / Infra

- **84% องค์กรรัน containerized workloads ใน K8s production** — K8s ขึ้นมาเป็นไม่ใช่ optional tool อีกต่อไป [official] [Fairwinds — 2026 K8s Playbook](https://securityboulevard.com/2025/12/2026-kubernetes-playbook-ai-at-scale-self%E2%80%91healing-clusters-growth/) enterprise standard platform ยิ่ง GPU workloads ออกทั่วไป
- **AI/ML workloads เป็น first-class citizens ใน K8s** — MLOps platforms ต้องประสานงาน resource-intensive training jobs คู่ขนานกับ inference services ที่รันต่อเนื่อง orchestration ต้องเป็น intelligent ไม่ใช่แค่ declarative [Pulumi Blog](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/) พอเข้า production scale
- **Zero-trust + security-first เป็น enterprise mandate** — 2026 shift สำคัญ: integrated policy enforcement, runtime threat detection, identity-based access ไม่ใช่ patch-only [Fairwinds](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth) FinOps (cost visibility) + AI orchestration ต้องคู่ขับเร่ง

→ **ภาพรวม:** K8s อยู่ศูนย์กลาง enterprise AI deployment พร้อม security hardening + cost governance — งาน tune-keycloak ของเรา pinned ตรงตัด

## 🌐 Web / Frameworks / Languages

- **React Compiler ย้ายจาก TypeScript → Rust (June 2026)** — Meta port logic มา Rust ปล่อย shipping ใน Next.js 16.4 ทำให้ build performance เร็ว 40%+ [official] [Meta/InfoQ](https://www.infoq.com/news/2026/07/meta-react-compiler-rust/) Rust version linked directly ใน Turbopack ลด bundler overhead ทุกครั้ง build
- **Next.js 16 ทำครบ transition ไป Turbopack** — Webpack ลาไปแล้ว replace ด้วย Rust-based bundler ที่เสถียรและเร็ว [Vercel — Turbopack](https://vercel.com/blog/turbopack) ecosystem ทั้งชั้น (compiler + bundler) บินเดียวกัน Rust engine ทำให้ consistency ขึ้น
- **Rolldown เป็น default ของ Vite ecosystem** — Nuxt, SvelteKit, Astro switch ไป rolldown (Rust bundler) แทน esbuild/Rollup บาง team report build: 2.5 นาที → 40 วิ ⚠️ [daily.dev](https://daily.dev/posts/rust-on-the-web-is-starting-to-look-quite-good--yfe0t5npg) ยุทธศาสตร์ consolidate tooling ใน Rust runtime
- **TypeScript 48.8% adoption, 84.1% satisfaction** — 2026 developer survey: TS ใช้โดย professional dev ส่วนใหญ่ [Strapi](https://strapi.io/blog/best-javascript-frameworks) TS ยังเป็น app-level default ขณะ Rust ยึด performance-critical tooling

→ **ภาพรวม:** Rust tooling (React Compiler, Turbopack, rolldown) เกาะ high-performance layer · TypeScript/JS ยังเป็นพื้นฐาน business logic — สัญญา tech debt ที่ manageable
