## 🌐 Web / Frameworks / Languages

- **Rust ครองเครื่องมือ JS toolchain** — SWC, Rspack, Biome, Oxc, Turbopack, Rolldown เป็น standard ในปี 2026 แทนที่ Webpack/Babel เพื่อประสิทธิภาพ ([hackernoon — Rust engine](https://hackernoon.com/rust-is-now-the-hidden-engine-behind-javascript-tooling), [dev.to — Rust owns](https://dev.to/agnelnieves/rust-owns-the-javascript-toolchain-in-2026-l9b)) [official]
- **TypeScript 7.0 on the Horizon** — TypeScript 6.0 (มีนาคม 2026) เป็นรีลีส JavaScript-based สุดท้าย ส่วน 7.0 ประสงค์ rewrite compiler ใน Go สำหรับความเร็วสูงขึ้น strict-by-default ([blog.jetbrains — Rust vs TypeScript](https://blog.jetbrains.com/rust/2026/01/27/rust-vs-javascript-typescript/)) ⚠️
- **Node.js 25.2 TypeScript Support (Amaro 1.0)** — Node เข้าสู่ TypeScript native transpilation ผ่าน Amaro 1.0 (SWC compiled to WebAssembly) ตั้งแต่ November 2025 ([pkgpulse — rise of rust](https://www.pkgpulse.com/guides/rise-of-rust-in-javascript-tooling-2026)) ⚠️
- **Rust Web Frameworks (Ecosystem Stable)** — Actix Web, Axum, Rocket, Loco, Leptos ปรับตัวเป็น standard เทียบได้กับ Node/JS stack ([besthub.dev — Rust displacing](https://www.besthub.dev/articles/how-rust-is-displacing-javascript-in-front-end-toolchains-insights-from-rspack-turbopack-and-bun-bcee8f93754f)) ⚠️

→ **เทรนด์:** Rust ยึดชั้นประสิทธิภาพ TypeScript ยังครองแอปพลิเคชัน TS 7.0 with Go compiler มาเร็ว
