## 🤖 AI / LLM / Agents

- **Claude Fable 5.2 มาถึง** — Anthropic ปล่อย Claude Fable 5.2 ตัวแบบ 2 ตัว (ปกติและ Mythos 5.2 แบบจำกัด) วันที่ 9 พ.ย. 2026 [official] โมเดลนี้เน้นความเร็วและ efficiency กว่าเวอร์ชันเก่า ([blog.mean.ceo — November 2026 AI releases](https://blog.mean.ceo/new-ai-model-releases-news-november-2026/))

- **Google ปล่อย Gemini 4 Carbon** — Google เปิดใช้ Gemini 4 Carbon แบบ Generally Available ตั้งแต่ 10 พ.ย. 2026 ด้วยราคา $2 per million tokens (input) และ $10 output ถึงวันที่ 30 พ.ย. แล้วปรับเป็น $4 และ $20 ตั้งแต่ 1 ธ.ค. [official] นี่เป็นการเคลื่อนไปยังโมเดลที่ประหยัดกว่าแต่ยังรักษาประสิทธิภาพ ([nocode.mba — LLM release tracker](https://www.nocode.mba/ai-release-tracker/2026/11))

- **โมเดล open weights ทำให้ระบบสั่นคลอน** — Moonshot ปล่อย Kimi K3.1 Pro ที่ open weights โดยมีพารามิเตอร์ทั้งหมด 2.8T / 104B active parameters รวมถึง Cognition's SWE-2 Flash และ Tencent's Hy4 Flash (API launch 16 พ.ย.) ⚠️ เหล่านี้แสดงว่าตลาด open weights ยังคงเป็นพื้นที่แข่งขันหลัก ([thursdai.news — Everything AI Released November 2026](https://thursdai.news/releases/2026-11))

→ **เกี่ยวกับเรา:** Pricing ลดลงของ Claude/Gemini ลดความเข็ดขาดในการเลือกโมเดล ส่วน SWE-2 Flash อาจช่วยใน agent/automation workflows

## ☸️ Cloud / DevOps / Infra

- **KubeCon + CloudNativeCon North America 2026 ทำวันนี้** — งานนำ Kubernetes และ Cloud Native ครั้งใหญ่จัดขึ้นที่ Salt Lake City ตั้งแต่ 9-12 พ.ย. 2026 [official] คาดว่าจะมีการประกาศเพิ่มเติมเกี่ยวกับ Kubernetes สำหรับ AI workloads ([cloudnativenow.com — KubeCon coverage](https://cloudnativenow.com/tag/leanix/))

- **K8s ได้ control plane ใหม่สำหรับ AI agents** — Buoyant ประกาศเปิดตัว open source control plane สำหรับ AI workloads บน Kubernetes เมื่อ 4 พ.ย. ส่วน Solo.io ขยายการสนับสนุน AI agents บน K8s clusters เมื่อ 13 พ.ย. [official] นี่สำคัญเพราะ Kubernetes ที่เดิมออกแบบสำหรับ traditional containerized services ตอนนี้ขยายสำหรับ AI agents ([CNCF — CloudNativeDevelopment](https://cloudnativenow.com/category/topics/cloudnativedevelopment/kubernetes/page/5/))

- **AWS และ CNCF เสริมด้านความปลอดภัย** — AWS เปิดตัว Nitro Sandboxes สำหรับคอนเทนเนอร์ (17 พ.ย.) ตามด้วย Broadcom ที่นำเสนอ virtual machine API เข้า CNCF (9 พ.ย.) และ Rafay/Fortanix ที่ขยายเทคโนโลยี confidential AI ไปยัง K8s pods ⚠️ วิวัฒนาการนี้สะท้อนความกังวลเพิ่มขึ้นเกี่ยวกับความปลอดภัยของ AI workloads ([cloudnativenow.com — Security updates](https://cloudnativenow.com/category/topics/cloudnativedevelopment/kubernetes/page/2/))

→ **เกี่ยวกับเรา:** K8s กำลังเปลี่ยนจาก container orchestrator ไปเป็น AI agent platform ทำให้งาน tune-keycloak และ infrastructure ต้องพิจารณา AI-aware scheduling

## 🌐 Web / Frameworks / Languages

- **React 19.3.1 มาถึงแล้ว** — เวอร์ชันใหม่ React 19.3.1 (released October 14, 2026) เป็นเวอร์ชันปัจจุบัน ⚠️ React ยังคงเป็นตัวเลือกหลักของทีมส่วนใหญ่ในปี 2026 ด้วยความลึกของแพคเกจ ecosystem และการรองรับจาก meta-frameworks เช่น Next.js ([tech-insider.org — 2026 framework snapshot](https://tech-insider.org/?p=49793))

- **Rolldown (Rust bundler) ถือครองตลาด build tools** — Rolldown เวอร์ชัน 1.0 ออกมาในเดือนพฤษภาคมปี 2026 และตอนนี้เป็น default bundler ของ Vite 8 ทำให้ Vite ถูกใช้เป็นมาตรฐานใน ecosystem ของ Nuxt/SvelteKit/Astro [official] เรื่องนี้เป็นตัวอย่างที่ชัดเจนว่า Rust tooling ยึดครองตลาด JavaScript ecosystem ([sencha.com — 2026 frameworks](https://www.sencha.com/blog/web-application-development-top-frameworks/))

- **Svelte 5 และ Nuxt 4 ไป live** — Svelte 5 จับคู่กับ SvelteKit 3.0 (October 1, 2026) ส่วน Nuxt 4 เป็น major version ที่รองรับ ในขณะที่ Nuxt 3 ประกาศ EOL ตั้งแต่ 31 กรกฎาคม 2026 [official] TypeScript ยังคงเป็นทำเนียบหลักของ web development ((robinwieruch.de — React libraries and ecosystem](https://www.robinwieruch.de/react-libraries/))

→ **ภาพรวม:** Rust tooling ครอบงำตลาด build tools ในขณะที่ React/TypeScript ยังเป็นทำเนียบของ app development หนึ่ง observability ที่ต้องตรวจสอบคือ เมื่อไรจะมีการ shift ไปยัง alternative frameworks

## 🚀 Startups / Products

- **$15.5B+ ไหลเข้า AI startups ในเดือนพฤศจิกายน** — ตัวเลขนี้คือ capital ที่สรุปได้ถึง 12 พ.ย. 2026 จากจำนวน 62 deals ⚠️ Thinking Machines Lab นำหน้าด้วยการระดมทุน $5.0B ในรอบ Seed เมื่อ 6 พ.ย. ตามด้วย robotics, satellites และ semiconductors ([aifunding.me — November 2026 Roundup](https://aifunding.me/insights/november-2026))

- **โมเดลหลักของ funding หันไปสู่ AI agents และ automation** — นอกจาก large language models แล้ว ทุนเริ่มมองเข้าไปยัง AI agents ที่สามารถ execute workflows ได้จริง ตรงกับความสนใจขยายของ Kubernetes ecosystem ในการรองรับ agents ⚠️ นี่สอดคล้องกับเทรนด์ที่เห็นใน HackerNews ของเดือน November ที่เงินหันไปจากแค่ demo ไปยังระบบที่มี practical use cases ([blog.mean.ceo — November 2026 funding](https://blog.mean.ceo/tech-startup-funding-news-november-2026/))

- **Robotics และ hardware ได้ความสนใจเพิ่มขึ้น** — นอกจาก AI deals แล้ว funding ยังไหลเข้า robotics ($600M), satellites ($250M) และ semiconductor companies ⚠️ บ่งชี้ว่าตลาดมองหา AI hardware accelerators และ specialized machines โดยเฉพาะหลังจาก constraint ของ GPU shortage ยังคงอยู่ ([techstartups.com — Funding News November 12](https://techstartups.com/?p=140400))

→ **เกี่ยวกับเรา:** ความสนใจที่เพิ่มขึ้นต่อ AI agents และ automation workflows ตัดสินใจว่า infrastructure ของ Kuma ต้อง optimize สำหรับ agentic patterns
