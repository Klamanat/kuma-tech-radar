## 🤖 AI / LLM / Agents

- **Claude Sonnet 5 & Fable 5 เปิดตัว** — Anthropic เปิด Claude Sonnet 5 วันที่ 3 กรกฎาคม และ Claude Fable 5 ในเดือนนี้ ซึ่งเป็น frontier model ที่ชาญฉลาดที่สุดในสาธารณะ โดยแสดงการกระโดด benchmark ที่มีนัยสำคัญขึ้น (~2x ราคาของโมเดล Opus) ([llm-stats.com — AI Updates](https://llm-stats.com/llm-updates))

- **GPT-5.6 Luna/Terra/Sol ออกจริง** [official] — OpenAI ปล่อยตระกูลโมเดลแฟล็กชิป GPT-5.6 ในสามขนาด โดยราคาตั้งแต่ $1 ถึง $5 ต่อล้านโทเคน input ทุกโมเดลมีหน้าต่างบริบท 1 ล้านโทเคน และ knowledge cutoff เดือนกุมภาพันธ์ 2026 รายงานว่าทำให้ Claude Fable 5 ตก benchmark agentic ระยะยาว ⚠️ และนำเสนอความสามารถ API ใหม่ เช่น programmatic tool calling, multi-agent orchestration, และ prompt cache breakpoints ([llm-stats.com — AI news](https://llm-stats.com/ai-news))

- **เวลส์การปล่อยโมเดลหนา** — Google เปิด Nano Banana 2 Lite และ Gemini Omni Flash ต้นกรกฎาคม Alibaba ปล่อย Qwen-Audio-3.0-TTS Plus (20 กรกฎาคม) Moonshot AI ปล่อย Kimi K3 (16 กรกฎาคม) Meta ปล่อย Muse Spark 1.1 (9 กรกฎาคม) และ xAI ปล่อย Grok 4.5 (8 กรกฎาคม) ([dentro.de — AI News July 2026](https://dentro.de/ai/news/))

→ **เกี่ยวกับเรา:** Claude Fable 5 & GPT-5.6 ขยายขีดจำกัด agentic reasoning — ส่งผลกระทบต่อ agent architecture ใน /learn และ SKILL.md

## ☸️ Cloud / DevOps / Infra

- **AWS EKS Version Rollback ออกจริง** [official] — AWS เพิ่มคุณลักษณะ Kubernetes Version Rollback ให้กับ Amazon EKS ให้ผู้ใช้ "ปุ่ม undo" สำหรับการเปลี่ยนแปลง infrastructure — สาขาย่อย AWS ของ Kubernetes infrastructure management ที่ช่วยลดความเสี่ยง ([Fairwinds — 2026 K8s Playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))

- **AI เป็น first-class citizens ใน K8s** — Kubernetes กลายเป็นชั้นปฏิบัติการ de facto สำหรับบริการที่ขับเคลื่อนด้วย AI รวมถึง microservices แบบดั้งเดิม data pipelines และสำหรับ edge applications ชุมชน cloud-native เน้นมาตรฐาน platform, security, observability, และ cost management รอบ Kubernetes ([Pulumi — Beyond YAML 2026](https://www.pulumi.com/blog/beyond-yaml-kubernetes-2026-automation-era/))

- **GitOps เป็นมาตรฐาน** — GitOps ได้กลายเป็นมาตรฐานสำหรับการจัดการสถานะของแอปพลิเคชันและ infrastructure โดยใช้ Git เป็นแหล่งความจริงเพียงแหล่งเดียวสำหรับการปรับใช้ ภายในปี 2026 แนวทางปฏิบัติเหล่านี้ถือเป็นพื้นฐานสำหรับการจัดการระบบ cloud-native ([InfoQ — Kubernetes News](https://www.infoq.com/Kubernetes/news/))

→ **ภาพรวม:** AI workload + EKS version safety = การเตรียมโครงสร้างพื้นฐานสำหรับยุค agent

## 🌐 Web / Frameworks / Languages

- **Next.js ยังนำ React ecosystem** — Next.js นำร่องการ render ฝั่งเซิร์ฟเวอร์ในระบบนิเวศ React และยังคงผลักดัน boundaries ด้วย React Server Components, Server Actions, และโมเดลการปรับใช้ serverless-first ผ่าน Vercel มีดาวบน GitHub มากกว่า 130,000+ ดวง ([Strapi — Best JS Frameworks 2026](https://strapi.io/blog/best-javascript-frameworks))

- **TypeScript adoption โต 78%** — TypeScript ถึง adoption 78% พร้อมการสนับสนุนรันไทม์เนทีฟ React Server Components กลายเป็น default สำหรับโครงการ React ใหม่ Vite ถูกโหลด 84 ล้านครั้งต่อสัปดาห์ในปี 2026 แซง Webpack ในกรกฎาคม 2025 ([Wasp — Best Full-stack Frameworks 2026](https://wasp.sh/resources/2026/02/24/best-frameworks-web-dev-2026))

- **Rust web frameworks เติบโต** — Actix Web และ Axum เรียงตัวกับบทบาทของ Express หรือ Fastify ในระบบนิเวศ Node.js ขณะที่ Leptos รู้สึกใกล้เคียงกับ React หรือ Svelte ในการจัดโครงสร้างตรรมชาติ UI logic แต่ compiled เป็น WebAssembly เพื่อประสิทธิภาพ Yew เป็นกรอบงาน frontend Rust ที่เก่าที่สุดพร้อมชุมชน โต่ที่สุด มากกว่า 30,000 ดาวบน GitHub ([Medium — Rust Frontend Frameworks 2026](https://medium.com/@priya.raimagiya/the-5-best-rust-frontend-frameworks-reviewed-for-2026-4694dad8f181))

→ **ภาพรวม:** TypeScript ยังคงครอบงำแอปพลิเคชัน แต่ Rust เติบโตเพื่อประสิทธิภาพเมื่อจำเป็น
