## 🤖 AI / LLM / Agents

- **Claude Opus 5.5 — ปล่อยแล้วจากแอนท์โปรพิก** — ตัวจริง 22 กันยายน 2026 [official], แต่เพิ่งจะเห็นในตลาดจริง ๆ เต็มที่ในช่วง October นี้ ท้ายที่สุด Opus 5.5 เป็นโมเดลเรือธง AI ตัวจริง ที่ใช้เข้มข้นแล้วใน production tools เช่น Claude Code ([Anthropic announcement](https://www.anthropic.com/news))
- **Gemini 4 Argon, GPT-6.1 Luna ตี tradeoff กลาง-October** — การค้นหา Google DeepMind's Gemini 4 เข้าช่วง post-training, ส่วน OpenAI ยังไม่ announce GPT-6.1 Luna อย่างเป็นทางการ ⚠️ ([forecasts](https://manifold.markets/prismatic/october-2026-ai-model-releases))
- **Mistral Le Chonk 1T — open weights planning** — open source-first strategy ของ Mistral ดำเนินต่อด้วยโมเดล 1T parameter ที่มี open weights มาเลย ไม่ใช่ closed demo ⚠️ ([reports](https://digg.com/ai/qyieg39r))

→ **เกี่ยวกับเรา:** Opus 5.5 ใช้ผลิตชุด SKILL.md และ /learn flow แล้ว model landscape ยังเปลี่ยน "ถี่" ทั้งที่ closed ถี่ open weights ด้วย

## ☸️ Cloud / DevOps / Infra

- **Kubernetes 1.36 readiness endpoint ปรับใหม่** — API server /readyz endpoint มีการปรับเปลี่ยนเรื่องการ wait for watch cache ที่ทำให้ pod readiness check แม่นยำกว่า [official], ต่อเชื่อม graceful shutdown และ rolling update flow ใน production cluster
- **Helm 4 released — major shift** — Helm 4 นำเสนอการเปลี่ยนแปลงครั้งใหญ่ในวิธี deploy ผ่าน Kubernetes แปลว่า teams ที่ยังใช้ Helm 3 ต้องวางแผนข้ามไปใน 2026-Q4 นี้ [official], ส่วน rollback strategy ต้อง retool ด้วย
- **Carbon-Aware DevOps, Blue-Green Deployments ที่ scale** — โครงสร้าง cloud เพิ่มมากขึ้นที่ตั้งใจ track emissions บน CI/CD runs ขณะเดียวกัน blue-green deployment เจอปัญหาเมื่อ scale โดยถูก discuss ใน community [background](https://cloudnativenow.com/))

→ **เกี่ยวกับงาน:** Helm 4 + K8s 1.36 readiness ต้องมา update deployment scripts ของเรา

## 🌐 Web / Frameworks / Languages

- **React Compiler Rust port — experimental merged** — ทีม React ทำการ port Compiler ไปเขียนด้วย Rust ใน March 2026 แล้ว merge เข้า main branch ใน June [official], ขณะนี้ยังอยู่ experimental แต่สัญญาณชัดว่า Rust คือทิศทางของ React team สำหรับ performance-critical path
- **TypeScript 7.0 released — Go compiler เป็น production** — TS 7.0 ปล่อยจากแท้จริง July 2026 ด้วย compiler เขียนใหม่ด้วย Go แทน Node.js version ความเร็ว compilation boost ขึ้นไป 3-5x ในกรณี common [official], เดิม TS 7 Beta ถูก announce ด้วย strict-by-default และตัด ES5 target
- **Vite 8 + Rolldown 1.0 — Rust build tool wave** — ครึ่งแรก 2026 เห็น Vite 8 และ Rolldown 1.0 ปล่อยมาด้วยความเป็น Rust-powered bundler ที่แทนเดิม esbuild/Rollup ⚠️ ([trends](https://blog.logrocket.com/frontend-wrapped-h1-2026-the-nine-biggest-storylines/))

→ **ภาพรวม:** Rust นำเสนอ performance jump ต่อ web tooling (React, TS, bundler) ในขณะที่ application code ยังคงเป็น TypeScript/JavaScript
