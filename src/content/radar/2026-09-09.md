## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37 released 4 ก.ย. 2026 [official]** — 3 feature ใหญ่: KubeletInUserNamespace (beta, node component รัน non-root user), DRA Extended Resource (GA, GPU scheduling ราบเรียบ), horizontal autoscaling to zero (beta + default enabled) ปัจจุบัน supported versions 1.34, 1.35, 1.36 เท่านั้น K8s ดูแล 3 minor versions ล่าสุด ([kubernetes.dev/resources/release](https://www.kubernetes.dev/resources/release/))

- **K8s 1.37 features drill-down:** DRA Extended Resource ช่วยให้ GPU/accelerator scheduling เป็นมาตรฐาน แนวโน้มรองรับ heterogeneous workload ชัดขึ้น KubeletInUserNamespace beta ลดผิวโปร่งพื้นฐาน node-level security ทำให้ node components ไม่ต้องรัน root ([kubernetes.io/releases](https://kubernetes.io/releases/))

- **K8s 1.38 ขอบฟ้า** — timeline ยังไม่ประกาศชัด แต่คาดว่าจะออก Q4 2026 ตามระยะ 4 เดือนต่างระดับ kubernetes release cycle ([kubernetes.io/blog](https://kubernetes.io/blog/))

→ **ภาพรวม:** K8s ยังคงเป็นบ่อเกาะ container orchestration, DRA GA milestone ใหญ่เรื่อง GPU resource management standardization

## 🌐 Web / Frameworks / Languages

- **React 19.2.0 ลงจรจริง [official]** — 3 hook ใหม่พลังจริง: Activity Component (ควบคุม visibility + pre-load state preservation), useEffectEvent (แยก event จาก effect หลีกเลี่ยง unnecessary re-runs), cacheSignal API (async cleanup สำหรับ Server Component render scope) ทั้งตัวแล้ว render speed เพิ่มและ lifecycle บริหารชาญฉลาดขึ้น ([medium.com/@onix_react](https://medium.com/@onix_react/whats-new-in-react-ecosystem-september-edition-6bd1ec2c10ab))

- **React Server Components from experimental → production standard** — milestone ใหญ่เรื่อง data fetching architecture ไม่ใช่ experimental อีกแล้ว Next.js/Remix/Astro ต่างยึดอยู่แล้ว ([dev.to/this-is-learning](https://dev.to/this-is-learning/javascript-frameworks-heading-into-2026-2hel))

- **React Router 7.9 ปล่อย middleware + type-safe context stable** — การ implement authentication guards กลายเป็นมาตรฐาน, error reporting client-side เพิ่ม ยา typescript support ทำให้ app-scale routing patterns เข้าถึงได้ ([blog.jetbrains.com/webstorm](https://blog.jetbrains.com/webstorm/2026/07/webstorm-2026-2/))

- **TypeScript 7 + WebStorm 2026.2 — full React 19 support** — WebStorm 2026.2 brings React 19 support ใน React Buddy, completion/refactoring เร็วขึ้นบน large project TS 7 compiler tuning ช่วย large-scale codebases performance ([medium.com/@mernstackdevbykevin](https://medium.com/@mernstackdevbykevin/typescript-with-react-best-practices-2026-78ce4546210b))

→ **ภาพรวม:** React ecosystem ติดสาบตัด server-centric thinking เป็นมาตรฐาน · TS มั่นชั่ง · Next.js/React Server Components นำเหนือ SSR landscape
