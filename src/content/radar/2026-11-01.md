## ☸️ Cloud / DevOps / Infra

- **KubeCon + CloudNativeCon North America 2026 — Nov 9-12 Salt Lake City** — อันดับหนึ่งของค่ายสปริงทั่วโลก อยู่บ้านหลัง deployment และ AI infrastructure ([HPE Events](https://www.hpe.com/us/en/events/kubecon.html)) [official]
- **Ingress NGINX เกษียณ, Gateway API ใจสว่าง** — KubeSphere แจ้งว่า NGINX Ingress deprecated ใน 2026 ก็จะขยายเป็น Gateway API standard ([KubeSphere](https://nitter.kareem.one/KubeSphere))
- **Kubernetes 1.36 เสถียรภาพเป้า** — Apr 2026 release มุ่งเน้น stability, reproducibility, compatibility ([CNCF](https://www.cncf.io/mail/u/0/page/13/)) [official]
- **GitOps, FinOps ขึ้นกระแส** — 73% ของทีม DevOps ใช้ GitOps ใน 2026; FinOps ที่คุมต้นทุน Kubernetes เป็นที่สนใจมากขึ้น ⚠️ ([Trends 2026](https://institute.sfeir.com/fr/formation-kubernetes/comparatifs-et-alternatives-kubernetes/tendances-kubernetes-2026-outils-alternatives-evolutions/))

→ **เกี่ยวกับงาน tune-keycloak:** Gateway API vs Ingress มีผลต่อ rollout; GitOps นอก scope แต่น่าติดตามสำหรับ infra อื่น

## 🌐 Web / Frameworks / Languages

- **Rust Axum ยืนหนึ่ง backend** — Oct 2026 guide ชี้ Axum เป็นทางเลือกแรกสำหรับ new API; Actix Web ยังแข็งแรง แต่ครอบนอก mainstream ⚠️ ([Encore](https://encore.dev/articles/best-rust-web-frameworks)) [official]
- **Actix Web ทะลุ 23k req/sec** — single-thread benchmark ล่าสุด ของ Actix Web ทำ ~23,000 req/sec ข้างบน Axum ⚠️ ([dasroot.net](https://dasroot.net/posts/2026/02/rust-web-app-development-performance-safety/))
- **Rust frontend (Wasm): Yew, Leptos, Dioxus** — market อยู่บ้านหลัง Rust Wasm แต่เล็กยาว สำหรับ React/TypeScript ยังไม่มีข่าว major ใน Nov ([WMTips](https://www.wmtips.com/technologies/frontend-frameworks/filter/rust))
- **React, TypeScript ข่าวตามเดิม** — ไม่พบข่าว major ของ React compiler หรือ TypeScript ตั้งแต่ Oct มา ⚠️

→ **ภาพรวม:** Rust backend ยืนหนึ่ง performance; React ecosystem ยังหลัก แต่ดูอยู่ ไม่มี major shift
