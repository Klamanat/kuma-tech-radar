## 🌐 Web / Frameworks / Languages

- **TypeScript ขึ้นแท่นภาษา #1 on GitHub** — แซง Python, JavaScript หลังจาก 78–87% ของ React projects ใช้ TypeScript ใน 2026 ([JavaScript Frameworks in 2026](https://dev.to/exactsolutionofficial/javascript-and-modern-frontend-frameworks-in-2026-what-actually-matters-18g1) [official])
- **React ครอบ 65–91% framework market** — ประมาณต่างแหล่งแต่ React นำเหนือ Angular/Vue/Svelte มากขึ้น; Next.js เป็นเสริม full-stack หลัก ([React Ecosystem 2026](https://www.buildwithmatija.com/blog/md/react-ecosystem-2026-frameworks-platforms-typescript-stack) [official])
- **Vite + React + TypeScript = recommended stack** — Create React App deprecated; Svelte highest on satisfaction, Vue for mid-market, Angular for large-scale enterprise ([Best JavaScript Frameworks 2026](https://strapi.io/blog/best-javascript-frameworks) [official])
- **Rust Axum ยืนหนึ่ง backend, Actix Web ~23k req/sec** — Oct 2026 guide ชี้ Axum เป็นทางเลือกแรกสำหรับ new API; Actix Web ยังแข็งแรง, ~23,000 req/sec ใน benchmark ⚠️ ([Encore](https://encore.dev/articles/best-rust-web-frameworks) · [dasroot.net](https://dasroot.net/posts/2026/02/rust-web-app-development-performance-safety/))

→ **ภาพรวม:** TypeScript/Vite นี้ stack ที่เสถียร ไม่มี major shake-up; React dominance ยังแกร่ง; Rust backend ทีม performance-sensitive นำ
