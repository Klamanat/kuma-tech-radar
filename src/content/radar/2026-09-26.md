## ☸️ Cloud / DevOps / Infra

- **Kubernetes v1.37.0 ออกจริง** — เผยแพร่ 26 สิ.ค. 2026 [official], ยึดตัวไหม่ CEL-based policy mechanisms และลดพึ่งพา external webhook infrastructure ([kubernetes.dev — release notes](https://www.kubernetes.dev/resources/release/))
- **AI สอดแทรกเข้า K8s** — Kubernetes เป็น operating layer มูลฐานสำหรับบริการ AI, MLOps, data pipelines, และ edge; platform team ขอคำแนวทาง Internal Developer Platform (IDP) เพื่อ self-service infrastructure ([fairwinds.com/2026-kubernetes-playbook](https://www.fairwinds.com/blog/2026-kubernetes-playbook-ai-self-healing-clusters-growth))
- **Networking: eBPF, Service Mesh, Gateway API** — CNI Plugin (Cilium), service mesh (Istio, Linkerd), traffic management (Flagger, Gateway API) เป็นต้น; Ingress-NGINX Controller สิ้นสุดชีวิต 2026 ([cloudoptimo.com/inside-kubernetes-2026](https://www.cloudoptimo.com/blog/inside-kubernetes-the-2026-architecture-breakdown/))
- **European Cloud Providers** — 8 ผู้ให้บริการ cloud ท้องถิ่นยูโรปนำเสนอ managed Kubernetes (OVHcloud, Scaleway, Exoscale เป็นต้น) ⚠️ ([qovery.com/eu-cloud-providers-kubernetes-2026](https://www.qovery.com/blog/eu-cloud-providers-managed-kubernetes-2026-sovereignty-checklist))

→ **ภาพรวม:** K8s ส่วนต่อและแนว AI-native infrastructure ฐาน; European sovereign options ร่างหนึ่ง

## 🌐 Web / Frameworks / Languages

- **TypeScript 7.0 & Next.js momentum** — TypeScript นำเป็นภาษาของ JS developers ใน 2026, Next.js (JS/TS/Rust hybrid) ยึด server-side rendering หลักเมตา React Server Components + Server Actions ถูกนำมาใช้ [official] ([strapi.io/best-javascript-frameworks](https://strapi.io/blog/best-javascript-frameworks))
- **React Router v8.3.0** — ลง July 2026 [official] ยึด full-stack web framework trait ของ React ecosystem ([en.wikipedia.org/React_Router](https://en.wikipedia.org/wiki/React_Router))
- **Leptos: Full-stack Rust Web 2026** — Leptos ยึดผู้ใหญ่ที่สุด (SSR, hydration, server functions in one Rust codebase); recommended choice สำหรับโปรเจกต์ใหม่ Rust ใน 2026 [official] ([rustify.rs/leptos-fullstack-web-2026](https://rustify.rs/articles/rust-leptos-fullstack-web-2026))
- **Rust Web Frameworks เสริมทีม** — Axum 0.8.8, Actix Web 4.12.1, Warp, Salvo เป็นอื่น เอกลัก conceptually เจอ JS counterparts ⚠️ ([aarambhdevhub.medium.com/rust-web-frameworks-2026](https://aarambhdevhub.medium.com/rust-web-frameworks-in-2026-axum-vs-actix-web-vs-rocket-vs-warp-vs-salvo-which-one-should-you-2db3792c79a2))

→ **ทำให้เรา:** Rust = tooling, performance-critical; TS/JS = core logic; Leptos = the future of full-stack Rust
