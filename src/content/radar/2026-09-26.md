## ☸️ Cloud / DevOps / Infra

- **Kubernetes ปลดประกาศว่า "default OS สำหรับ AI"** — K8s v1.37.0 released 26 สิงหาคม 2026 [official], CNCF ตั้งหน่วย Certified Kubernetes AI Conformance Program เพื่อ standardize AI/ML workload execution; native histogram support for metrics graduated to Beta (enabled by default); หมายความว่า workload scheduling + GPU resource allocation/DRA เป็นต้นฉบับแล้ว ([Kubernetes Blog](https://kubernetes.io/blog/)) [official]
- **Platform Engineering แทนที่ DevOps** — 80% ขององค์กรมี Internal Developer Platform (IDP) ในปี 2026 เพื่อลดปัญหา cognitive load และ deploy complexity; ความหมายไม่ว่า team อื่นอีกต้อง move จาก IaC SSH-style ไปเป็น GitOps + SelfService Portal ([State of DevOps 2026](https://devnewsletter.com/p/state-of-devops-2026/)) ⚠️
- **K8s 10th Anniversary ฉลองความสำเร็จ** — Kubernetes เป็นแกนหลักของ global digital infrastructure; managed K8s adoption ยิ่งสูงขึ้น และ 8 EU cloud providers (OVHcloud, Scaleway, Exoscale, Infomaniak ฯลฯ) นำเสนอ managed K8s with sovereignty compliance ([Kubernetes Blog](https://kubernetes.io/blog/)) [official]

→ **โอกาส:** K8s AI-native tooling; IDP adoption นำไปสู่ decrease burdensome manual ops; European sovereign cloud ด้วย K8s

## 🌐 Web / Frameworks / Languages

- **Rolldown v1.0 ทำให้ build 10-30 เท่าเร็ว** — Rust-based bundler Rolldown released v1.0 ในเมษายน 2026 และตอนนี้ power Vite 8 (มาร์ช 2026) [official]; Webpack-to-Vite migration เป็น transition ที่ common ที่สุด และ Vite ได้ 98% developer satisfaction ต่อ Webpack 37% negative sentiment ([State of JavaScript 2026](https://devnewsletter.com/p/state-of-javascript-2026/)) ⚠️
- **TypeScript ขึ้นแท่นอันดับ 1 บน GitHub** — TypeScript surpassed Python และ JavaScript เป็น most-used language บน GitHub ตั้งแต่ สิงหาคม 2025; React Compiler v1.0 (ตุลาคม 2025) มีเสถียรภาพเต็มตัวแล้ว optimize component/hook อัตโนมัติ ([Best React Libraries and Tools 2026](https://jsdev.space/react-stack-2026/)) [official]
- **Leptos: Full-stack Rust Web 2026** — Leptos ยึดผู้ใหญ่ที่สุด (fine-grained reactivity, SSR, hydration, server functions in one Rust codebase); recommended choice สำหรับโปรเจกต์ใหม่ Rust ใน 2026 [official] ([Rust Web Frameworks — Leptos](https://yew.rs/))
- **Rust Web Frameworks ได้ momentum** — Actix Web, Rocket, Axum, Warp, Loco gain adoption สำหรับ performance-critical applications ที่ต้อง memory safety + near-C performance without garbage collection ⚠️ ([20+ Must-Know Rust Libraries and Frameworks for 2026](https://medium.com/@gunnar.h.karlsson/20-must-know-rust-libraries-and-frameworks-for-2026-d851aacfd2b2))

→ **ภาพรวม:** Rust ยึด ecosystem tooling (build/bundler), TypeScript solid ใน application layer; fullstack reactive frameworks ทำให้ SSR/hydration ไม่ต้องร้องไห้อีก
