## 🌐 Web / Frameworks / Languages

- **React Compiler Rust Port ⚠️** — Joseph Savona เปิด PR #36173 ในมีนาคม 2026 เพื่อ port React Compiler จาก TypeScript → Rust อยู่ในสถานะ experimental ยังไม่สิ้นสุด ([React Repository PR](https://dev.to/sebastienlorber/this-week-in-react-280-tanstack-remotion-react-router-expo-go-ease-screen-transitions-18mf))
- **TypeScript 7.0 ออก July 2026 [official]** — compiler เขียนด้วย Go, strict-by-default, ตัด ES5 target + AMD/UMD/SystemJS ตามปลาย July podcast transcript ([State of TypeScript](https://devnewsletter-frontend.pages.dev/p/state-of-devops-2026))
- **Rari: Rust-based React Framework** — ประกาศเมื่อ February 2026 เป็นเฟรมเวิร์กใหม่สร้างด้วย Rust รายละเอียดจำกัด ⚠️ ([manyai-ship-lp](https://manyai-ship-lp.pages.dev/en/ai-news/article/2026-02-13-rari-a-new-rust-powered-react-framework-emerges-for-web-development))
- **VoidZero Oxfmt + อื่นๆ** — Oxfmt formatter ที่เขียนด้วย Rust เร็วกว่า Prettier 30x, Prisma 7.0 หันไป Rust-free, Octane เป็น compiled React-like framework (July 2026) ([Netlify blog](https://www.netlify.com/blog/web-frameworks-2025-year-in-review.md))

→ **ภาพรวม:** Rust ยึดชั้นมากขึ้นใน tooling ของ JS ecosystem โดยเฉพาะ React Compiler port ยังในตัวต่อกำลัง experimental
