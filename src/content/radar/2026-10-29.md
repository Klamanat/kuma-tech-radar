## ☸️ Cloud / DevOps / Infra

- **Rust เข้ายึดชั้น Kubernetes tooling** — Axum กลายเป็นตัวเลือกมาตรฐานสำหรับ microservices บน K8s ด้วยประสิทธิภาพ memory ต่ำ (10-30MB RSS) เทียบ Java/Python ([news.lavx.hu — Deploying Rust on Kubernetes](https://news.lavx.hu/article/deploying-rust-services-on-kubernetes-a-practical-guide-to-production-ready-microservices))
- **Kubernetes operators ด้วย Rust** — Krator project ให้ define/manage K8s resources ผ่าน Rust API, Rusternetes คือ reimplementation เต็มตัวของ Kubernetes เขียนด้วย Rust ([dev.to — Rust & Kubernetes trends](https://dev.to/johalputt/how-to-upskill-for-2026-trends-learn-rust-185-and-kubernetes-132-for-high-demand-roles-1ojf))
- **Web framework landscape ต่อเนื่อง** — Actix Web (24,700⭐) และ Leptos (full-stack) ยังเป็น toppers แต่ Axum ได้โปรไฟล์ที่สูงขึ้นบน production K8s deployments ([relatedrepos.com — Rust Web Framework Comparison](https://relatedrepos.com/gh/flosse/rust-web-framework-comparison))

→ **เกี่ยวกับงาน infrastructure:** Rust tooling นี้ align กับเป้า reduce memory footprint และ improve deployment reliability
