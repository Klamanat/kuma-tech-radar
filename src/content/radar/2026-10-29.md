- **KubeCon Europe 2026 + CNCF projects updates** — KubeCon Europe 2026 จัดขึ้นช่วง mid-2026 พูดคุยเกี่ยว SUSE Rancher Prime, VM + container management, FinOps/DevOps convergence ([CNCF news](https://www.cncf.io/news/)) [official]
- **Kubiya Captain Kubernetes, Calico Spring Release** — Kubiya ปล่อย Captain Kubernetes = AI teammate สำหรับ autonomous K8s operations, Calico ปล่อย Spring 2026 release เพิ่มประสิทธิภาพ networking ([cloudnativenow.com](https://cloudnativenow.com/tag/devops-workflows)) [official]
- **AI Spurring Container + Kubernetes Adoption** — CNCF survey 2026 บอกว่า AI workloads ขับเคลื่อน container adoption ขึ้น; ประมาณ 68% enterprises ใช้ K8s ที่ production ([CNCF survey](https://t.me/s/kubernative/321)) ⚠️

→ **ภาพรวม:** GPU scheduling production-ready, AI workloads ทำให้ K8s adoption ต่อ, cost + automation เป็นโฟกัสใหม่

## 🌐 Web / Frameworks / Languages

- **TypeScript 7.0 ออกแล้ว, Go-based compiler** — TypeScript 7.0 shipped by late July 2026, compiler เขียนใหม่ด้วย Go (ตัดสินใจตั้งแต่ต้นปี), ใจกลาง change = speed + stability; TypeScript 6.0 เป็น JavaScript compiler สุดท้าย ([State of TypeScript 2026](https://devnewsletter.com/p/state-of-typescript-2026/)) [official]
- **React 19.2.8 focused on RSC decoding** — React 19.2.8 ออก July 21, 2026 โฟกัสการ optimize React Server Components decoding; ecosystem ตาม React Hook Form 7.81+ และ React Router 8.2+ ([State of JavaScript 2026](https://devnewsletter.com/p/state-of-javascript-2026/)) [official]
- **Solid 2.0 async, Remix 3, Vite+ Beta** — Solid.js เคลื่อน version 2.0 เพิ่ม async primitives, Remix 3 shipped, Vite+ Beta เข้า advanced bundling ([TMiR 2026-07](https://www.reactiflux.com/transcripts/tmir-2026-07)) [official]
- **React Foundation officially launched February 2026** — React Foundation เป็นตัวจริงตั้งแต่ Feb 2026, community governance แล้ว; React ecosystem ~44.7% frontend, TypeScript 48.8% ใช้ / 84.1% satisfaction ([React foundation](https://www.reactjs.org/)) [official]

→ **ภาพรวม:** TypeScript ใจกลาง compiler rewrite, React compound growth + server components, ecosystem diversify (Solid/Remix/Astro)
