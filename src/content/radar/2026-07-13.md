## 🌐 Web / Frameworks / Languages

- **TypeScript 7.0 General Availability [official]** — ทีม Microsoft ปล่อย TypeScript 7.0 เมื่อ 8 ก.ค. 2026 พร้อม compiler เขียนด้วย Go แทน JavaScript ทำให้ type-checking เร็วขึ้น **11.9 เท่า** (VS Code: 125.7s → 10.6s เนื่องจากการ parallel processing) ([TypeScript Blog](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/))
- **Next.js 16.3** — เฟรมเวิร์ก Next.js ปล่อย v16.3 (ประกาศเมื่อ 29 มิ.ย. 2026) พร้อม Turbopack improvements ลด dev-server memory ถึง **90%** และทำให้ production build เร็วขึ้น **5.5 เท่า** ([ecorpit NextJS News](https://ecorpit.com/nextjs-16-3-typescript-7-rust-go-toolchain-2026/)) ⚠️

→ **ภาพรวม:** Rust/Go-native tooling กำลังทำให้ JavaScript ecosystem เร็วขึ้นมากทีเดียว TypeScript 7.0 เป็นจุดเดือดของเทรนด์นี้
